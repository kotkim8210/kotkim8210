# 자동화 개선 노트 (기존 스킬 분석 → 무엇을 더 자동화했나)

기존 osmu-video-builder + script-factcheck-resolver 스킬과 전체 대화를 분석해,
"귀찮은 부분(노가다·반복·잘 까먹는 부분)"을 골라 자동화했습니다.

## 분석: 기존의 귀찮음 6가지
1. **뚱뚱한 config** — segment마다 `image`/`audio` 경로를 손으로 다 적어야 했다.
2. **명령 5개+** — factcheck → ttsfix → promptgen(16:9) → promptgen(9:16) → build 따로 실행.
3. **고증을 자꾸 까먹음** — factcheck는 '검출'만 하고, [수치확인]·[실명위험]은 Claude가
   기억해서 검색해야 했다. 실제로 두 번이나 빠뜨려 지적받음. (가장 큰 불만)
4. **남은 할 일이 안 보임** — 무슨 이미지/음성을 어떤 파일명으로 만들어야 하는지 매번 헷갈림.
5. **같은 숫자 재검증** — 화차마다 동일 수치를 또 확인하라고 보챔(nagging).
6. **이미지/음성 100% 수동** — 비용 때문에 의도한 분업이지만, 확장 여지 없음.

## 개선: 무엇을 바꿨나
| # | 개선 | 어떻게 |
|---|---|---|
| 1 | **lean config** | `osmu_common.py`가 `image=assets/<id>.jpg`, `audio=assets/<id>.mp3` 자동 유도. config엔 id/text/caption만. |
| 2 | **명령 1개** | `auto.py`가 전 단계를 순서대로 실행. **idempotent**(최신 산출물은 건너뜀, `--force`로 재실행). |
| 3 | **고증 작업목록** | factcheck가 `factcheck_todo.json`(기계가 읽는 pending 리스트) 생성. SKILL.md가 "Claude가 web_search로 검증·수정"을 **강제**. 더는 눈으로 안 훑어도 됨. |
| 4 | **현황판** | `auto.py`가 세그먼트별 이미지/음성 ✅/❌ + 정확한 파일명 + "남은 할 일"을 출력. `--status`로 언제든 확인. `image_manifest.json`이 프롬프트↔파일명 매핑. |
| 5 | **재나그 제거** | 검증한 항목을 `factlog.json`에 기록 → 다음 화차부터 같은 숫자는 `done`으로 표시(보채지 않음). |
| 6 | **자동 생성 훅** | `images.py`(openai/gemini)·`voice.py`(elevenlabs/xtts) 백엔드. 기본 OFF, config 한 줄로 ON. API 키만 넣으면 이미지·음성도 자동. |
| + | **게이트 강화** | `--build`는 고증 미검증 or 자산 부족이면 자동 중단 → 검수 없는 무인 발행(슬롭) 구조적 차단. |
| + | **TTS 자동 반영** | build가 음성 합성 시 `tts_text` 우선 사용(ttsfix 결과가 자동 적용). |
| + | **사람용 핸드오프** | `handoff.py` → `voice_script.md`(세그먼트별 음성 복붙 대본 + 전체 한 번에 복사) + `human_tasks.md`(체크박스 한 장). "내가 뭘 해야 하지"가 파일 하나로 끝. |

## 의도적으로 자동화하지 않은 것 (그대로 둔 이유)
- **대본 ★관점 30%** — 자동화하면 슬롭. 사람의 진짜 반응이 수익의 80%를 가른다.
- **[단정표현]·[시대불일치]** 자동 수정 — 맥락 판단 영역이라 제시만, 수정은 사람/Claude 판단.
- **이미지/음성 기본 수동** — 무비용 분업(브루·ChatGPT) 유지. 원하면 백엔드만 켜면 됨.

## 한 줄
> "분석 → 대본 → 고증검색 → TTS → 프롬프트 → 현황판"이 **명령 1개 + Claude 자동 검증**으로 합쳐졌고,
> 사람이 할 일은 **대본 ★승인 / 이미지 저장 / 음성 저장** 세 가지로 줄었다.
