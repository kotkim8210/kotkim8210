# osmu-auto — OSMU 영상 반자동 제작 (대본→고증→TTS교정→프롬프트→현황판)

## 0. 이 스킬이 자동화하는 것 / 사람만 하는 것
| 자동 (Claude + auto.py) | 사람만 (게이트) |
|---|---|
| lean config 대본 작성 | 이미지 생성(ChatGPT/ImageFX) → 파일명대로 저장 |
| 고증 검출 + **[수치확인]·[실명위험] web_search 검증·수정** | 음성(브루) → 파일명대로 저장 |
| TTS 읽기용 교정, 이미지 프롬프트(16:9+9:16) | 대본의 ★관점 30% 최종 승인 |
| 현황판으로 남은 자산/할 일 안내, 영상 조립(build) | 발행 |

> 완전 무인은 금지(슬롭=수익화 차단). "노가다는 자동, 신뢰 20%는 사람"이 원칙.

## 1. 표준 플로우 (사용자가 "만들어줘" 하면 이대로)
1. **lean config 작성** — `examples/*_config.json` 형식. id/text/caption만. 규칙:
   - 12세그먼트 내외, text 합계 **6,400자+ (≈20분, 미드롤 광고 안전)**.
   - 8블록 서사: 콜드오픈 훅→배경→상승→붕괴→신화깨기→**심리(★관점30%)**→교훈→다음편.
   - ★관점 들어가는 세그먼트엔 `"pov": true` 표시 → human_tasks.md 1번에 자동으로 뜸.
   - 비유럽/현대 주제면 `image_style.suffix`(시대·장소 앵커)를 넣고, 필요하면 세그먼트별
     `image_hint`(짧은 장면)로 이미지 프롬프트가 주제에 맞게 나오도록 한다(유럽풍 오출력 방지).
   - 현대 비교/교훈 세그먼트엔 `"era":"modern"` 태그(시대불일치 오탐 방지).
   - OSMU `clips` 3개(반전 훅/충격 팩트/인용형 통찰), 각 독립 `hook`.
   - 안전 레인만: 역사·과거 버블/사기. **현대 실존인물 나락 금지**(명예훼손·초상권).
2. **`python auto.py <config> --era <17c/18c/19c/20c>`** 실행.
3. **factcheck_todo.json 의 pending 항목을 전부 해결**(↓ 2절 — 필수).
4. 해결 후 **`python auto.py <config> --era … --force`** 재실행(검증 반영·tts 갱신).
5. **현황판 + handoff 안내**: auto.py가 만든 **`human_tasks.md`**(체크리스트)와
   **`voice_script.md`**(세그먼트별 음성 복붙 대본 + 전체 블록)를 사용자에게 가리켜,
   "이미지 N개·음성 N개만 파일명대로 저장하면 끝"이라고 안내.
6. 사용자가 자산을 채우면 **`python auto.py <config> --build`** → out/ 에 본편+클립.

## 2. 고증 게이트 — MANDATORY (시키지 않아도 매번)
`auto.py`가 만든 **`factcheck_todo.json`** 의 `status=="pending"` 항목 중
**[수치확인]·[실명위험]** 은 **Claude가 이 세션에서 `web_search`로 직접 검증·수정·확정**한다.
플래그만 남기고 사용자에게 넘기는 것은 **금지**.
- `factcheck.py`(로컬)=탐지만 / **Claude(세션)=검증·수정 책임.** 이게 스킬의 존재 이유.

### A. [수치확인]
1. 각 숫자/연도/금액/비율/인원/배수를 `web_search`로 1차·신뢰 출처(학술·박물관·정부·평판매체) 대조.
2. 정확 → 유지(출처 갈리면 "약/일부 기록은/전해진다"로 완충). 틀림 → `text`·`caption` 수정.
3. 수정했으면 `--force`로 factcheck·ttsfix 재실행.

### B. [실명위험]
1. `web_search`로 **생존·현대 인물 vs 역사·고인 공인** 판정.
2. 생존·현대 → 명예훼손/초상권 위험: 익명화(직함·역할)하거나 공적사실+출처만, 미검증 단정 삭제.
3. 역사·고인 공인(뉴턴·월폴 등) → 유지하되 붙은 주장(직함·일화)도 검색 검증.
4. 애매하면 보수적으로 (생존인물처럼) 처리.

### C. 검증 기록 → factlog.json (재나그 방지)
검증/수정한 항목은 **`factlog.json`** 에 기록해야 다음 화차부터 같은 숫자를 다시 보채지 않는다:
```json
{ "<sid>::<type>::<detail>": { "status": "verified|fixed",
    "source": "출처 URL/명", "note": "근거 한 줄" } }
```
- `<detail>` 은 factcheck_todo.json 항목의 `detail` 문자열을 그대로 사용(키가 일치해야 인식됨).
- 검토 문서(`*_review.md`)가 있으면 '고증 검증 로그' 섹션에 상태·출처·조치를 함께 남긴다.

## 3. 하지 않는 것 / 경계
- **[단정표현]·[시대불일치]·[모호출처]** 는 자동 검색 대상 아님(판단·맥락) → 사용자에게
  "수사적 강조 vs 사실 주장"을 구분해 제시만. 임의 검색·수정 X.
- 검색으로도 확정 불가 → 단정 말고 완충 표현 + factlog에 "불확실" 기록.
- 인용구 진위 불명 → "전해진다"로 처리(예: 뉴턴의 'madness of people').
- 이미지·음성을 Claude가 직접 만들지 않는다(약점·비용). 프롬프트·읽기대본까지만.

## 4. 한 줄 요약
> 사용자가 "만들어줘" → Claude가 대본+auto.py 실행 + **[수치확인]·[실명위험]을 즉시 검색·검증·수정** +
> factlog 기록 → 현황판으로 "사람이 만들 이미지/음성"만 콕 집어 안내. **플래그를 넘기지 않는다.**
