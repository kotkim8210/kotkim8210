# 🌙 /dream — 드림 시퀀스 (Dream Sequence)

> 너는 지금 제2의 뇌의 **백그라운드 정제기(Refiner)** 다.
> 사람이 잠든 사이, 너는 축적된 지식을 스스로 검토하여 **모순을 해소하고, 중복을 통합하고,
> 낡은 지식을 걸러내고, 새로운 통찰을 합성**한다. 이 정제가 반복될수록 지식 베이스의
> 정확도와 검색 성능이 극대화된다. **이것이 이 시스템에서 가장 중요한 작업이다.**

시작 전에 `CLAUDE.md`(특히 §5 안전 규칙)를 반드시 따른다.
`$ARGUMENTS`가 주어지면 그 키워드와 관련된 주제군에 집중하고, 없으면 전체를 대상으로 한다.

## 핵심 안전 규칙 (먼저 내면화)
1. **지식을 절대 영구 삭제하지 않는다.** 구식·중복은 `brain/archive/`로 옮기거나 `status`만 바꾼다.
2. **모든 변경을 `.state/dream-log.md`에 기록한다.** (날짜·무엇을·왜)
3. **보수적으로.** 한 번에 전체를 다시 쓰지 말고, 가장 가치 있는 소수의 변경에 집중한다.
4. 주제를 합쳐도 `sources`는 합집합으로 보존한다.

## 절차 (7단계)

### 1. 조감 (Survey)
`brain/wiki/MAP.md`를 읽고, `brain/wiki/topics/`의 문서 목록과 각 한 줄 요약·`status`·`confidence`를 훑는다. 변경 후보를 머릿속에 정리한다(아직 쓰지 않는다).

### 2. 모순 탐지 (Contradiction)
서로 충돌하는 주장을 가진 문서 쌍을 찾는다.
- 해소 가능하면: 더 **최신**이고 **신뢰도 높은**(또는 출처가 더 확실한) 쪽을 채택하고, 패배한 주장은 해당 문서에 `[구식]`/근거와 함께 남긴다(삭제 아님).
- 판단 불가하면: 양 문서의 "미해결/모순" 섹션에 `[모순]`로 명시하고 MAP의 모순 목록에 올린다.

### 3. 중복 병합 (Deduplicate)
같은 주제를 다루는 문서들을 하나의 **정본(canonical)** 으로 통합한다.
- 정본에 내용·`sources`·`related`를 합치고 `updated` 갱신.
- 흡수된 문서는 `status: merged`로 바꾸고 본문을 `→ [[정본-slug]]로 통합됨`만 남긴 뒤 `brain/archive/`로 이동(또는 그대로 두되 merged 표시). 들어오던 `[[링크]]`들이 깨지지 않도록 정본으로 갱신.

### 4. 구식 정리 (Staleness)
다른 지식에 의해 대체되었거나 더 이상 유효하지 않은 내용을 찾는다.
- 문서 전체가 구식이면 `status: stale`로 표시하고 `brain/archive/`로 이동.
- 일부만 구식이면 해당 항목에 `[구식]` 마커 + 이유, `confidence` 하향.

### 5. 통찰 합성 (Insight Synthesis) 💡 — 가장 창의적인 단계
**2개 이상의 주제를 가로지르는, 개별 문서에는 명시되지 않은 새로운 연결·패턴·함의**를 찾는다.
- 발견한 통찰을 `brain/insights/INSIGHTS.md`에 누적 기록한다:
  `### YYYY-MM-DD — <통찰 제목>` / 본문(무엇을·어떤 문서들을 잇는지·왜 중요한지) / `근거: [[slug]], [[slug]]`.
- 통찰이 충분히 독립적이고 중요하면 새 합성 주제 문서로 승격해도 좋다(`tags`에 `통찰` 추가).

### 6. 재색인 (Re-link & Re-index)
- 끊어진 `[[위키링크]]`를 고치고, 새로 드러난 관계를 `related`에 반영한다.
- `brain/wiki/MAP.md`를 다시 정리한다(통계·주제 색인·연결 그래프·모순 목록 갱신, **작게 유지**).

### 7. 로그 (Audit Log) — 필수
`brain/.state/dream-log.md` 맨 위(또는 시간순 끝)에 항목 추가:
```
## YYYY-MM-DD HH:MM — 드림 시퀀스
- 모순: (해소/표시한 것)
- 중복: (병합한 것)
- 구식: (보관한 것)
- 통찰: (새로 기록한 것 N건)
- 재색인: (MAP/링크 변경 요약)
```
변경이 거의 없었다면 "유의미한 변경 없음"이라고 정직하게 기록한다.
