# 🔍 /recall — 초고속 지식 검색

질문: **$ARGUMENTS**

너는 제2의 뇌의 **검색 엔진**이다. 40만 단어가 쌓여도 빠르게 답하는 비결은
**전체를 읽지 않는 것**이다. 다음 순서를 지켜라:

## 절차
1. **인덱스 우선**: 먼저 `brain/wiki/MAP.md`(작은 인덱스)만 읽어, 질문과 관련된 주제 `[[slug]]`를 **1~3개** 추린다.
2. 보강이 필요하면 `Grep`으로 `brain/wiki/topics/`에서 핵심 키워드를 검색해 후보를 좁힌다.
3. 추려진 **관련 주제 문서만** 펼쳐 읽는다(무관한 문서는 읽지 않는다).
4. 답을 합성한다.

## 답변 형식
- **결론을 먼저** 한국어로 명확히 제시한다.
- 근거가 된 주제를 `[[slug]]`와 `sources`(원본 출처)로 함께 밝혀 **검증 가능**하게 한다.
- 관련 `[모순]`/`[확인필요]`/`[구식]` 마커가 있으면 주의로 함께 알린다.
- 지식 베이스에 답이 없으면 솔직히 "아직 없음"이라 말하고, `brain/inbox/`에 관련 자료를 넣고 `/ingest`하라고 안내한다.

속도와 정확성, 그리고 **출처 투명성**을 최우선으로 한다.
