# Example: Baby Shark Negative Control

## Source

- URL tested: https://www.youtube.com/watch?v=J0_-rkGQbDs
- Title: Baby Shark bermain piano #shorts
- Channel: Lagu Anak - Baby Shark Pinkfong Indonesia
- Visible signals during test: official Pinkfong/Baby Shark IP, YouTube Kids prompt, comments disabled, short duration.

## Decision

Reject.

Why:
- Official/kids character IP and music-centered source.
- CC/permission not confirmed.
- Comments disabled, so no comment-cluster analysis.
- 12-second source is too short to create strong core/support transformation.
- Zoom, flip, subtitles, and translation cannot solve brand/IP/music risk.

Rule reinforced:
- Official character/kids IP, logo/brand-centered visuals, music/song-centered sources, comments disabled, and very short clips are source kill patterns.
