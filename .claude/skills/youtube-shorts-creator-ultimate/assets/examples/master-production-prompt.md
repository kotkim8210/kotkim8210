# Master Production Prompt

이 원본으로 한국·일본 쇼츠 현지화 패키지를 만들어줘.

## 입력

- 원본 URL:
- 원본 제목:
- 채널명:
- Creative Commons 확인 여부:
- 조회수/좋아요/댓글 수:
- 인기 댓글 10~30개:
- 장르:
- 타겟: 한국 + 일본
- 선호 톤: 자동 판단

## 요청 산출물

1. 제작 가능/보류 판정
2. 권리·리스크 체크표
3. 후보 100점 점수표
4. 댓글 클러스터와 주제 방향
5. KR/JP 첫 2초 후킹
6. KR 대본
7. JP 대본 + 9항목 리뷰 + JP v2
8. CapCut 편집 지시서
9. 실질 변형 게이트
10. 업로드 메타데이터 + 출처 표기
11. A/B/C 변형안
12. 업로드 후 체크할 지표

## 필수 조건

- 권리 확인이 불완전하면 제작을 보류해.
- 필수군(C1 해설·C2 정보·C3 재해석) 2개 미만 또는 전체 변형 4개 미만이면 승인하지 마.
- 일본어는 한국어 직역 금지.
- 조회수나 수익화는 보장하지 마.
