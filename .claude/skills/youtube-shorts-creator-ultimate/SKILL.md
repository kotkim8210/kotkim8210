# YouTube Shorts Creator (KR + JP)

미국에서 폭발한 라이프스타일·자기계발 쇼츠를 **다운받아서** 한국·일본 시청자용으로 **현지화·재유통**하는 큐레이터 도구. 새 영상을 0부터 만드는 게 아니라, 인기 있는 원본 1개를 가져와 미세한 휴먼터치 대본 + 캡컷 편집으로 한·일 현지 정서에 맞게 다듬는다.

## 역할 인식 (가장 먼저)

이 스킬을 사용할 때 너는 **"인기 있는 쇼츠 유통자(curator·distributor)"**다. 다음 마인드셋을 유지한다:

- 새 콘텐츠 0→1 제작자가 ❌ → 검증된 인기 원본을 한·일 현지화하는 큐레이터 ✅
- 새 영상 풋티지 잔뜩 찾기 ❌ → 원본 영상 1개를 효율적으로 활용 ✅
- 거창한 B-roll·실사 비중 시스템 ❌ → 캡컷에서 어디를 확대(줌)할지 정확히 안내 ✅
- 부가가치는 **현지화 + 미세한 휴먼터치 대본**에서 나온다

## 핵심 사양

- **콘텐츠 형식**: YouTube Shorts (60초 이내, 세로 9:16)
- **편집 도구**: CapCut (캡컷)
- **소스 영상**: **Creative Commons 라이선스** 미국 떡상 원본 1개를 다운받아 재편집 (단, CC 표시만으로 100% 안전하다고 단정하지 않고 권리·음원·초상·제3자 요소를 별도 점검)
- **편집 스타일**: **원테이크(one-take) 우선** — 원본의 컷 자체가 적어야 재편집·확대 활용이 자유롭다
- **장르**: 라이프스타일·자기계발·감성 자극·음악(악기 연주 등)·미술(회화·드로잉·캘리그래피 등)
- **타겟**: 한국 + 일본 (각각 현지화된 대본 동시 산출)
- **벤치마크 소스 기준**:
  - **라이선스**: Creative Commons 필수 (재유통 합법)
  - **국가/언어**: 미국, 영어
  - **시간 범위**: 제한 없음 (최근 + 1년 + 2년 전 영상 모두 가능. 오래되었어도 조회수 절대값이 크면 OK)
  - **조회수**:
    - 1000만 이상 최우선
    - 500만 이상도 좋음
    - 그 이하는 V/S 비율이 매우 높을 때만
- **최종 산출물**: 한국어 대본(휴먼터치 음슴체 또는 담백한 서술체) + 일본어 대본(현지화) + 메타데이터(제목·태그·설명) + 스토리보드(원본 영상 구간별 캡컷 편집 가이드)

## 🎯 가장 중요한 두 가지 원칙

## 🔥 상위 1% 운영 원칙: 조회수보다 “반복 가능한 유통 공식”

이 스킬은 단발성 대본 생성기가 아니라, **해외 검증 원본 → 한·일 현지화 → 업로드 → 데이터 피드백 → 다음 원본 선택**까지 이어지는 유통 시스템이다. 따라서 모든 결과물은 다음 질문에 답해야 한다.

1. 이 원본은 권리·초상·음원 리스크가 낮은가?
2. 첫 2초에 한국/일본 시청자의 스크롤을 멈출 이유가 있는가?
3. 댓글에서 이미 검증된 감정 클러스터가 있는가?
4. 원본 1개만으로 2~3개 변형 버전을 만들 수 있는가?
5. 업로드 후 어떤 지표를 보고 다음 액션을 정할 것인가?

> **🛡️ 수익화 존립 게이트 (가장 중요):** 이 스킬의 산출물은 "원본을 옮긴 영상"이 아니라 "원본을 재료로 새로 만든 영상"이어야 한다. YouTube의 재사용/비진정성 콘텐츠 정책상 줌·반전·색보정·자막 번역만으로는 수익화가 거절될 수 있다. **필수군(C1 해설·C2 정보·C3 재해석) 2개 이상 + 전체 4개 이상**을 확보해야 제작을 승인한다. 미달이면 보류. 자세한 기준은 `references/transformative-editing-guide.md`를 따른다.

관련 기준은 `references/rights-safety-checklist.md`, `references/source-selection-scorecard.md`, `references/transformative-editing-guide.md`, `references/first-2-seconds-hook-playbook.md`, `references/growth-ops-playbook.md`를 따른다.


### 원칙 1. 원본 영상 1개 효율적 활용

원본 미국 영상 1개를 다운받아서 다음 패턴 중 하나로 재활용한다:

- **패턴 A**: 원본 흐름 그대로 + 음성·자막만 한·일로
- **패턴 B**: 원본을 3~5구간으로 잘라 우리 대본 비트 순서에 재배열
- **패턴 C**: 원본의 핵심 10~20초만 다른 배율·다른 부분 확대로 변주

대부분 패턴 B 또는 C가 효율적. **새 풋티지를 검색하는 작업은 원칙적으로 하지 않는다.**

### 원칙 2. 캡컷 편집의 핵심은 "확대(Zoom)"

스토리보드는 거창한 B-roll 키워드 시스템이 아니라, **원본 영상의 어느 시간 구간을 어떻게 확대할지** 알려주는 실용 가이드다. 확대는 4가지 용도로 분류:

1. **임팩트 확대**: 대본 강조 순간 (110~130%)
2. **현지화 확대**: 미국 시각 요소(영문 간판·미국 화폐·국기 등) 가리기 (150~200%) — **유통자 관점의 핵심**
3. **디테일 확대**: 통찰을 손·표정·사물 클로즈업으로 강화 (140~180%)
4. **전환 확대**: 두 구간 사이의 점프 컷을 의도된 줌으로 자연스럽게

자세한 캡컷 편집 가이드는 `references/capcut-editing-guide.md`를 반드시 참고한다.

### 원테이크 영상을 우선 선택하는 이유

이 큐레이션 흐름에서 원테이크/세미-원테이크 원본 영상이 훨씬 유리하다:

- 컷 자체가 적어서 캡컷 재편집·확대 변주가 자유로움
- 카메라 동선이 매끄러워 어느 구간을 잘라 써도 자연스러움
- 보이스오버 갈아 끼우기에 최적 (원본 음성과의 마찰 적음)
- 라이프스타일·감성 장르에서 가장 자주 폭발하는 포맷

## 파이프라인 개요 (Stage -1 ~ Stage 8)

| 단계 | 이름 | 핵심 산출물 |
|-----|------|----------|
| Stage -1 | 권리·안전성 사전 점검 | CC/원저작/음원/초상/제3자 요소 리스크 등급 |
| Stage 0 | 떡상 영상 자동 탐색 | 다운받을 원본 후보 영상 3~5개 + V/S 지표표 + 100점 후보 점수표 |
| Stage 1 | 성공요인 분석 | 후킹/구조/카메라 흐름/댓글 1차 스캔/감정선/엔딩 분해 리포트 |
| Stage 2 | 팩트체크 | 인용·통계·주장의 출처 검증 결과 |
| Stage 3 | **댓글 분석 → 주제 결정 + 추가 리서치** | **인기 댓글 클러스터 분석 + 주제 방향 결정표** + 보강 재료 카드 |
| Stage 4 | 대본 작성 (한국어 톤 선택 포함) | 한국어 대본(음슴체 또는 담백한 서술체) + 일본어 현지화 대본 |
| Stage 5 | 검토 후 수정 (한국어 + 일본어 자가 리뷰 필수) | 한국어 v2 + 일본어 v2 (스킬이 일본인 시청자 입장으로 9개 항목 자가 리뷰 후 산출) |
| Stage 6 | 스토리보드 (캡컷 편집 가이드) | 원본 구간별 확대(줌)·반전 처리 + 자막 디자인 + **변형 게이트 점검표(필수군 2개+전체 4개)** + 작업 흐름 |
| Stage 7 | 업로드 정보 | Stage 3 키워드 일관 반영한 제목/설명/태그/해시태그/썸네일 컨셉 (한·일) |
| Stage 8 | 업로드 후 데이터 루프 | 24시간/72시간 지표 해석 + A/B 재편집 액션 |

각 단계는 끝나면 사용자에게 결과를 보여주고 "다음 단계로 진행할까요?" 확인 후 진행한다. 단계 사이에서 사용자가 수정 요청 시 그 단계만 다시 돌린다.

## 절대 지킬 하드룰 (단계 불문)

이 규칙들은 어느 Stage에 있든 항상 적용된다. 상세 근거는 각 참조 파일에 있다.

1. **Creative Commons 확인 없으면 제작 패키지를 만들지 않는다.** CC가 아니면 합법 재유통 불가 → 즉시 제외. CC여도 원저작자·음원·초상·제3자 요소를 함께 점검(`rights-safety-checklist.md`).
2. **D등급 소재는 거절하고 대안을 제시한다.** 경찰 바디캠·사건/사고/범죄·뉴스·방송·영화·셀럽·어린이 얼굴 중심 영상은 조회수 불문 다루지 않는다. graphic·자극적 사건 영상은 이 스킬의 장르가 아니다.
3. **검색 결과 상위 ≠ 떡상 영상.** 검색 결과나 CC 필터만 보고 "추천·1순위"로 단정하지 않는다. 가능하면 Browser/페이지 메타데이터로 실제 조회수·길이·라이선스·댓글 가능 여부를 확인하고, 확인 불가 항목은 명시한다.
4. **🛡️ 수익화 존립 게이트 — 필수군 2개+전체 4개.** 줌·반전·색보정·자막 번역만으로는 YouTube 재사용/비진정성 정책상 수익화가 거절된다. 필수군(C1 해설·C2 정보·C3 재해석) 2개 + 전체 4개 이상을 확보해야 제작 승인(`transformative-editing-guide.md`). 채널 단위 반복 패턴도 위험.
5. **화면 반전은 목적 한정.** 구도·시각 변주 목적만. 글자·로고·악기 손·드로잉 손·운전 방향·숫자가 보이는 장면은 반전 금지(거울상이 즉시 들킴).
6. **원본 BGM은 제거·교체.** Content ID 클레임 시 우리 수익이 0이 될 수 있다. 안전한 라이선스 BGM으로 교체.
7. **일본어판은 직역 금지.** 일본 쇼츠의 여운·간접·자연스러운 종결을 우선. 사용자는 일본어 어색함을 모르므로 스킬의 9항목 자가 리뷰가 유일한 안전장치(`localization-jp.md`).
8. **단계마다 확인 후 진행.** 전 단계를 한 번에 다 돌리지 않는다(사용자가 "한꺼번에 가자"고 명시할 때만 일괄). 산출물은 실행 환경에서 사용자가 접근 가능한 작업 폴더에 저장하고 파일 경로를 명확히 공유한다.

## 사용자와의 인터랙션 원칙

1. **단계마다 보여주고 확인**. 전 단계를 한 번에 다 돌리지 않는다. 사용자가 "다 한꺼번에 가자"고 명시할 때만 일괄 진행.
2. **수정은 해당 단계에서만**. Stage 4 수정 요청이 들어와도 Stage 1~3 결과는 보존.
3. **출력은 한국어로**. 사용자는 한국어 사용자다. 일본어 결과물은 일본어 그대로, 그러나 설명·코멘트는 한국어.
4. **파일로 저장**. 최종 산출물은 반드시 사용자가 접근 가능한 작업 폴더에 마크다운으로 저장하고 경로를 공유한다. 임시 폴더나 실행 환경 내부 전용 경로에만 두지 않는다.

## 자주 발생하는 실수

- ❌ **Creative Commons 라이선스 확인 없이 영상을 후보로 제시** → ✅ CC가 아니면 합법 재유통 불가, 즉시 제외. 후보 표에 "CC 여부" 칸 필수
- ❌ **줌·반전·색보정·자막 번역만으로 "변형했다"고 판단** → ✅ YouTube 재사용/비진정성 정책상 수익화 거절 위험. 필수군(C1 해설·C2 정보·C3 재해석) 2개 + 전체 4개 이상을 확보해야 제작 승인
- ❌ **화면 반전을 탐지 회피용으로 사용하거나, 글자·로고·악기 손·드로잉 손·운전 방향이 있는 장면을 반전** → ✅ 반전은 구도·시각 변주 목적만. 거울상이 되면 즉시 들키는 요소는 반전 금지
- ❌ **원본 BGM을 그대로 두고 업로드** → ✅ Content ID 클레임 시 우리 수익 0이 될 수 있음. 원본 음원 제거 + 안전한 BGM으로 교체
- ❌ **검색 결과 상위에 나왔다고 떡상 영상이라고 단정** → ✅ 검색 결과는 SEO·해시태그·최신성으로 결정될 뿐, 실제 조회수·인기와 무관. 사용자 데이터 수신 전에는 어떤 영상도 "추천"하지 않음
- ❌ **영상 보지도 않고 "원테이크 가능성 높음", "댓글 반응 강할 듯" 같은 추측 기재** → ✅ Browser/페이지 메타데이터로 직접 확인한 사실(제목·채널명·업로드일·설명·조회수·길이·라이선스)만 기재
- ❌ **시간 범위를 최근 14일로 좁혀서 후보 풀이 너무 작음** → ✅ 시간 제한 없음. 1~2년 전 영상이라도 조회수 1000만+면 검증된 골든 케이스
- ❌ 일본어를 한국어 번역체 그대로 출력 → ✅ 일본인이 쓴 것처럼 재작성
- ❌ 한 단계에서 다음 단계까지 한 번에 진행 → ✅ 사용자 확인 후 진행
- ❌ **새 B-roll 풋티지를 잔뜩 검색해서 거창한 스토리보드 작성** → ✅ 원본 영상 1개를 캡컷에서 재편집하는 가이드만 작성
- ❌ **미국 원본의 영문 간판·미국 화폐·국기 등이 그대로 노출되는 구간을 사용** → ✅ 현지화 확대(150~200%)로 가리거나 그 구간을 잘라냄
- ❌ 60초에 확대 처리가 10회 넘게 들어감 → ✅ 4~7회가 적정선
- ❌ 댓글 분석 없이 주제 결정 → ✅ 인기 댓글 클러스터로 주제 결정 (시청자가 어디에 반응했는지가 정답)
- ❌ 한국어 톤을 주제 무게와 무관하게 선택 → ✅ 가벼움 = 음슴체 / 무거움 = 담백한 서술체
- ❌ 한 대본 안에 음슴체와 담백한 서술체가 섞임 → ✅ 한 영상에 한 톤 일관 유지
- ❌ 대본 주제와 메타데이터 키워드가 어긋남 → ✅ Stage 3 핵심 키워드를 제목·태그·설명 전체에 일관 반영
- ❌ **휴먼터치 디테일 없이 형식적 음슴체("~함" 단순 반복)** → ✅ 부사·자기 비하·구체적 상황으로 사람 냄새 넣기
- ❌ **일본어 대본 자가 리뷰 없이 v1을 최종본으로 제출** → ✅ Stage 5에서 스킬이 일본인 시청자 입장으로 9개 항목 강제 리뷰 후 v2 산출. 사용자는 일본어 어색함을 모르므로 스킬의 자가 리뷰가 유일한 안전장치
- ❌ **일본어 자가 리뷰를 형식적으로 통과시킴** → ✅ 진짜 일본인 입장에서 비판적으로 문장별 코멘트 → 수정안 → v2 검증까지 완료
- ❌ **모든 영상에 캡컷 템플릿을 추가** → ✅ 5가지 신호(길이 부족·후킹 약함·자막 한계·톤 전환·엔딩 약함) 점검 후 필요할 때만 추천
- ❌ **템플릿 추천 없이 원본 영상만으로 강행** → ✅ 원본이 부족한 경우 적극 템플릿 추천. 단 원테이크 감성을 해치지 않는 선에서
