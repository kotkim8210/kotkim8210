# 댓글 분석 가이드

댓글은 대본의 정답지가 아니라 시청자 욕망의 지도다. 인기 댓글을 모아 감정, 상황, 의문, 반박, 저장 욕구로 나눈다.

## 1. 수집할 댓글

- 좋아요가 많은 댓글 10~30개
- 답글이 많은 댓글
- “I needed this”, “how”, “why”, “this reminds me”, “I tried”처럼 행동/감정이 드러나는 댓글
- 반박 댓글과 논쟁 댓글
- 한국·일본 현지화 시 바꿔야 할 문화 코드가 보이는 댓글

## 2. 클러스터 분류

| 클러스터 | 의미 | 대본 활용 |
|---|---|---|
| 공감 | 나도 그랬다, 위로받았다 | 첫 2초 후킹/엔딩 여운 |
| 욕망 | 나도 하고 싶다, 배우고 싶다 | 정보 레이어/How-to 구조 |
| 의심 | 진짜냐, 과장 아니냐 | 팩트체크/반박 구조 |
| 감탄 | 아름답다, 미쳤다, 천재다 | 비주얼 중심 편집 |
| 추억 | 어릴 때 생각난다, 누군가 떠오른다 | 감성 서사 |
| 문화 차이 | 미국식이라 낯설다 | 한국/일본 치환 포인트 |

## 4. 댓글에서 뽑아야 하는 4가지

1. 첫 2초에 쓸 감정 문장.
2. 본문에서 풀어낼 시청자 질문.
3. 현지화할 문화 코드.
4. 다음 A/B/C 변형의 다른 각도.

## 5. 금지

- 댓글을 그대로 번역해서 자막으로 붙이지 않는다.
- 악성 댓글을 주제의 중심으로 만들지 않는다.
- 원본 댓글의 개인정보나 민감한 경험을 과도하게 재현하지 않는다.
