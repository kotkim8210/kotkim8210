# 최종 품질 게이트

업로드 패키지 승인 전 아래 5개 게이트를 통과해야 한다.

## Gate 1. Rights

- [ ] 라이선스/권리 근거 기록 완료
- [ ] 원본 URL/제목/크리에이터 기록 완료
- [ ] 음원 유지/교체 판단 완료
- [ ] 초상/로고/제3자 저작물 리스크 판정 완료
- [ ] 출처 표기 문구 작성 완료

## Gate 2. Source Fit

- [ ] 후보 점수 75점 이상
- [ ] 댓글 클러스터 3개 이상 도출
- [ ] 한국·일본 시청 이유가 각각 명확함
- [ ] A/B/C 변형 가능성 있음

## Gate 3. Script

- [ ] KR 첫 2초가 구체적이고 짧음
- [ ] JP 첫 2초가 직역투가 아님
- [ ] 한국어 톤이 음슴체/서술체 중 하나로 일관됨
- [ ] 일본어 9항목 리뷰 후 v2 산출됨
- [ ] 과장, 허위, 검증 안 된 주장 없음

## Gate 4. Transformative Value

### 필수군(Core) — 최소 2개 이상

- [ ] C1 해설/관점: 원본에 없던 해설·보이스오버·해석이 충분히 추가됨
- [ ] C2 정보 레이어: 배경지식·데이터·맥락·원리 설명이 추가됨
- [ ] C3 재해석/비교: 원본을 다른 관점, 한국/일본 현실, 비교/리뷰 구조로 재구성함

### 보조군(Support) — 필수군 포함 전체 4개 이상

- [ ] S1 구조 재배열 또는 비트 재설계
- [ ] S2 한국/일본 문화 맥락과 현지화 크롭/줌
- [ ] S3 자막 서사가 단순 번역이 아님
- [ ] S4 사운드/보이스오버/음원 처리 계획 있음

### 채널 단위

- [ ] 같은 출처·같은 구조·같은 템플릿 반복이 아님
- [ ] A/B/C 변형의 시청 이유가 서로 다름
- [ ] 판정: 필수군 2개 이상 + 전체 4개 이상

## Gate 5. Editing & Growth

- [ ] CapCut 타임코드 표 있음
- [ ] 줌/크롭/반전 목적이 명시됨
- [ ] 루프 엔딩 또는 첫 컷 회수 구조 있음
- [ ] 24h/72h/7d 회고 기준 있음
- [ ] Repeat / Modify / Kill 기준 있음

```text
다음 액션:
```
