# 직장인 운영 루틴

하루 종일 붙어 있는 운영이 아니라, 평일 30분과 주말 2시간으로 굴러가게 만든다.

## 평일 30분 루틴

| 요일 | 작업 | 산출물 |
|---|---|---|
| 월 | 후보 5개 수집 | 후보 URL, 조회수, 댓글 수 |
| 화 | 권리/점수표 1차 | 후보 점수표, 보류 후보 제거 |
| 수 | 댓글 클러스터링 | 주제 방향 1~2개 |
| 목 | KR/JP 후킹·대본 초안 | 대본 v1 |
| 금 | CapCut 지시서·업로드 메타 | 편집표, 제목/설명 |

## 주말 2시간 루틴

1. 최종 권리 체크와 출처 표기 보강.
2. CapCut 편집.
3. 한국어/일본어 자막 검수.
4. A/B/C 중 1개 업로드.
5. 지난 업로드 24h/72h/7d 회고.

## 월간 루틴

- 상위 20% 영상의 후킹 패턴만 모은다.
- Kill 판정 영상의 공통 원인을 찾는다.
- 권리 리스크가 낮고 반복 가능한 장르를 2개로 좁힌다.
- 다음 달에는 잘 된 댓글 클러스터만 더 깊게 판다.

## 자동화할 일

- 후보 수집표 작성
- 댓글 클러스터 초안
- KR/JP 대본 초안
- 일본어 자가 리뷰
- CapCut 지시서 초안
- 업로드 메타데이터 초안
- 회고표 작성

## 사람이 반드시 볼 일

- 라이선스와 원저작자 확인
- 음원/초상/로고/제3자 요소 판단
- 최종 영상 시청 품질
- 업로드 전 출처 표기
