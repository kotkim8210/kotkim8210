# 권리·라이선스 안전 체크리스트 (Rights Safety Checklist)

Creative Commons 표시는 **합법 재유통의 출발점**이지, 자동 면책권이 아니다. 이 스킬은 조회수보다 먼저 권리 리스크를 걸러야 한다.

## 1. 반드시 확인할 7가지

| 항목 | 통과 기준 | 실패 시 조치 |
|---|---|---|
| 라이선스 표시 | YouTube 설명/필터에서 Creative Commons 명시 | 후보 제외 |
| 원저작자 신뢰도 | 채널이 직접 촬영·제작한 정황이 있음 | 보류 또는 제외 |
| 제3자 저작물 | TV 화면, 영화, 공연, 음원, 로고 중심 노출 없음 | 해당 구간 제거/무음/후보 제외 |
| 인물권·초상권 | 미성년자·민감 상황·사적 공간 클로즈업 아님 | 후보 제외 우선 |
| 음악 권리 | 원본 BGM이 재사용 가능한지 불명확하면 제거 | 원본 오디오 삭제 + 별도 라이선스 BGM |
| 출처 표기 | 설명란에 원본 제목·채널·URL·라이선스 표기 가능 | 표기 불가 시 보류 |
| 변형성 | 단순 재업로드가 아니라 대본·편집·자막·구조가 바뀜 | 변형 강도 강화 |

## 2. 원본 설명란 출처 표기 템플릿

```text
Original video: [원본 제목]
Creator: [채널명]
Source: [원본 URL]
License: Creative Commons / reused with localization, voiceover, captions, and edited structure.
```

## 3. 절대 피해야 할 원본

- 유명인·셀럽·뉴스·스포츠 경기·방송 화면이 중심인 영상
- 영화·드라마·애니·콘서트·뮤직비디오 일부를 가져온 영상
- 사고·질병·범죄·갈등 현장처럼 당사자 동의가 불명확한 영상
- 어린이 얼굴이 핵심 클로즈업인 영상
- 원본 채널도 남의 영상을 짜깁기한 정황이 큰 영상

## 4. 리스크 등급

| 등급 | 의미 | 사용 여부 |
|---|---|---|
| A | 직접 촬영 가능성 높고, CC 명시, 제3자 요소 거의 없음 | 사용 가능 |
| B | CC 명시, 일부 로고·영문·BGM 리스크 있음 | 편집으로 제거 후 사용 |
| C | CC는 있으나 원저작·초상·음원 불확실 | 보류 |
| D | 방송/영화/음악/유명인/민감 장면 포함 | 사용 금지 |

## 5. 최종 안전 문장

최종 후보 추천 전 반드시 이렇게 말한다:

> “CC 표시만으로 100% 안전하다고 단정하지 않고, 원저작·음원·초상·제3자 요소를 함께 확인했습니다.”
