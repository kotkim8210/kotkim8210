# Browser Verification Runbook

YouTube 후보는 검색 결과만으로 확정하지 않는다. Browser 또는 페이지 메타데이터 접근이 가능하면 아래 순서로 직접 확인한다.

## 1. 후보 상세 페이지 확인

기록할 항목:

- 원본 URL과 Shorts URL
- 제목
- 채널명/채널 ID
- 길이
- 조회수
- 업로드일
- 카테고리
- 설명란 주요 권리 문구
- 댓글 활성/비활성

## 2. Creative Commons 확인

검색 결과의 `Creative Commons` 필터는 1차 필터일 뿐이다. 최종 판정은 영상 상세 페이지에서 확인한다.

통과 문구 예:

- `Creative Commons Attribution license (reuse allowed)`
- 설명란의 `License: Creative Commons Attribution 4.0 International`

CC가 확인되어도 원본 음원, 초상권, 로고, 브랜드, 제3자 저작물은 별도 점검한다.

## 3. 댓글 수집

댓글이 켜져 있으면 상위 댓글 10~30개를 수집해 `comment-mining-guide.md` 기준으로 감정/욕망/반박/저장 욕구를 클러스터링한다.

댓글이 비활성이면:

- 댓글 감정 점수를 낮춘다.
- 영상 타임라인, 교육 가치, 시각적 변화, 검색 수요 기반으로 훅을 설계한다.
- 최종 리포트에 `댓글 비활성`을 명시한다.

## 4. 후보 판정

다음 3개가 동시에 좋아야 테스트 우선순위가 높다.

- 권리 안전성: CC BY 확인 + 출처 표기 가능
- 수요 신호: 조회수/좋아요/댓글 또는 명확한 검색 수요
- 변형 가능성: 필수군(C1~C3) 2개 이상 + 전체 4개 이상을 만들 수 있음

조회수만 높고 권리 확인이 안 되면 보류 또는 허락 요청 후보로 분류한다.
