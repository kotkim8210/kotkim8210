# Final Audit Notes

## 첨부 v3에서 유지한 강점

- Stage -1~8 전체 제작 파이프라인.
- 한국어 톤 분기와 일본어 9항목 자가 리뷰.
- CapCut 줌/크롭/반전 중심의 현실적 편집 지시.
- 권리 체크, 후보 점수표, 성장 루프, 실질 변형성 기준.

## 최종판에서 바꾼 점

- 5만 자 이상 장문 `SKILL.md`를 등록용 메인 파일로 쓰지 않고, 짧은 지휘 파일로 교체.
- 긴 설명은 `references/workflow.md`로 이동.
- “보장”에 가까운 표현을 제거하고 리스크 관리형 문장으로 수정.
- 공식 정책 확인 출처를 `policy-source-notes.md`로 분리.
- 프로젝트 운영 템플릿을 00~11 순서로 정리.
- PowerShell과 Bash 프로젝트 생성 스크립트를 모두 포함.
