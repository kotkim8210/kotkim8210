# 전체 워크플로우 (Full Pipeline Workflow)

SKILL.md의 파이프라인 개요를 실제로 실행할 때 읽는 상세 절차서다. 각 Stage의 목표·단계·산출물·주의점을 담는다. **Stage를 진행하기 직전에 해당 Stage 절을 읽고** 그대로 따른다.

> 운영 철칙(요약): ① 단계마다 사용자에게 보여주고 "다음 단계로 진행할까요?" 확인 후 진행. ② 수정 요청은 해당 단계만 다시 돌리고 앞 단계 결과는 보존. ③ 설명·코멘트는 한국어, 일본어 결과물만 일본어. ④ 최종 산출물은 실행 환경에서 사용자가 접근 가능한 작업 폴더에 저장하고 경로를 공유한다.

## 목차

- **Stage -1**: 권리·안전성 사전 점검
- **Stage 0**: 떡상 영상 자동 탐색
- **Stage 1**: 성공요인 분석
- **Stage 2**: 팩트체크
- **Stage 3**: 추가 정보 검색 + 댓글 기반 주제 결정
- **Stage 4**: 대본 작성 (한국어 톤 선택 포함)
- **Stage 5**: 검토 후 수정 (한국어 + 일본어 자가 리뷰)
- **Stage 6**: 스토리보드 (캡컷 편집 가이드 + 변형 게이트)
- **Stage 7**: 업로드 정보
- **Stage 8**: 업로드 후 데이터 루프

---

## Stage -1: 권리·안전성 사전 점검

**목표**: 조회수 높은 원본을 찾기 전에, 재유통 리스크가 큰 소재를 먼저 제거한다. Creative Commons는 출발점일 뿐이며, 원저작·음원·초상·제3자 요소를 함께 확인한다.

### 필수 체크

`references/rights-safety-checklist.md`를 기준으로 다음을 표로 점검한다.

| 항목 | 확인 결과 | 리스크 | 조치 |
|---|---|---|---|
| CC 표시 |  | A/B/C/D |  |
| 원저작자 신뢰도 |  | A/B/C/D |  |
| 원본 BGM/음원 |  | A/B/C/D |  |
| 인물권·초상권 |  | A/B/C/D |  |
| 제3자 저작물/로고 |  | A/B/C/D |  |
| 출처 표기 가능성 |  | A/B/C/D |  |
| 변형성 확보 가능성 |  | A/B/C/D |  |

### 판정

- A/B: 진행 가능. B는 편집으로 리스크 제거 조건부 진행.
- C: 보류. 더 안전한 원본 우선.
- D: 사용 금지.

### D등급(사용 금지)일 때 대응

한 항목이라도 D면 그 원본은 **즉시 중단**하고 Stage 0(영상 탐색)로 넘어가지 않는다. 단, 거기서 멈추지 말고 사용자에게 **왜 막혔는지 + 안전한 대체 방향**을 함께 제시한다. 예:

> "이 소재는 [초상권/뉴스 사건/저작권] 때문에 합법 재유통이 어렵습니다(권리등급 D). 대신 같은 감정·같은 후킹을 노리되 권리가 안전한 방향을 추천드립니다: [구체적 대안 1~2개]."

특히 다음 소재 요청은 D로 보고 위 방식으로 거절·전환한다 (`rights-safety-checklist.md` 3번 참조):

- 경찰 바디캠·사건/사고/범죄 현장·재난 영상 (초상권·당사자 동의 없음, graphic)
- 뉴스·방송·영화·드라마·뮤직비디오·콘서트 클립
- 유명인·셀럽 중심 영상, 스포츠 경기 화면
- 어린이 얼굴이 핵심인 영상

이 소재들은 조회수가 아무리 높아도 다루지 않는다. "충격적", "실화", "소름" 류의 자극적 사건 영상은 이 스킬의 장르(라이프스타일·자기계발·감성·음악·미술)가 아니며, 사람이 위기·피해 상황에 처한 실제 장면을 오락용으로 재유통하지 않는다.

### 산출물

`rights-check.md` 파일 1개. 최종 후보 추천에는 “CC 확인”뿐 아니라 “권리등급”을 반드시 포함한다.

## Stage 0: 떡상 영상 자동 탐색

**목표**: **Creative Commons 라이선스**가 부여된 미국 떡상 쇼츠 중 다음 조건을 만족하는 후보를 찾는다:

- 조회수 1000만 이상 (최우선) / 500만 이상 (차선)
- 시간 범위 제한 없음 (최근 + 1~2년 전 영상 모두 가능. 오래된 영상이라도 누적 조회수가 크면 그만큼 검증된 콘텐츠)
- 장르: 라이프스타일·자기계발·감성·음악(악기 연주 포함)·미술(회화·드로잉 포함)
- 원테이크 또는 세미-원테이크 우선

### 🔒 대전제: Creative Commons + 직접 검증

**합법 재유통은 Creative Commons(CC BY) 영상에만 가능하다.** 일반 "Standard YouTube License" 영상을 다운받아 쓰면 저작권 침해다. CC가 아닌 영상은 후보에서 즉시 제외한다.

CC 영상 식별 방법: ① YouTube 검색 → Filter → Features → Creative Commons, ② 검색 URL에 `&sp=EgIwAQ%253D%253D` 추가, ③ 영상 상세 페이지 또는 설명란의 "Creative Commons Attribution license (reuse allowed)" / "License: Creative Commons Attribution 4.0 International" 표기.

**Browser/페이지 메타데이터 접근이 가능하면 다음을 직접 확인한다**:

- 실제 조회수, 길이, 업로드일, 채널명/채널 ID
- 영상 상세 페이지의 CC BY 라이선스 표시
- 설명란의 출처/권리/음원 문구
- 댓글 활성/비활성 및 수집 가능 여부

검색 결과의 CC 필터는 최종 증거가 아니다. 반드시 후보 상세 페이지에서 다시 확인한다. 실행 환경에서 댓글이나 라이선스가 로드되지 않으면 그 한계를 명시하고 사용자에게 화면 확인 또는 댓글 복사를 요청한다.

### 🚫 가장 자주 빠지는 함정: "검색 결과에 나왔다" ≠ "떡상 영상"

검색 결과 상위 노출은 SEO·해시태그·최신성으로 결정될 뿐, **실제 조회수·인기와 무관**하다. 검색에 잘 잡힌 영상이 조회수 100회·댓글 0개인 경우가 흔하다.

**스킬이 절대 하지 않는 것:**
- ❌ 검색 결과만 보고 "1순위", "추천", "떡상 후보" 라벨링
- ❌ "댓글 반응 강할 듯", "한·일 공감대 있음" 등 검증 안 된 추측 기재
- ❌ 영상도 안 보고 "원테이크 가능성 높음" 단정

**대신 하는 것:**
- ✅ Browser/페이지 메타데이터로 확인된 사실(채널·업로드일·길이·제목·설명·조회수·라이선스)만 기재
- ✅ 확인 가능한 후보는 실제 데이터로 점수화하고, 확인 불가 항목은 "확인 필요"로 남김
- ✅ 조회수/댓글/CC 상세 확인 후에만 떡상 또는 1순위 판정

### 진행 방식: 시작할 때 옵션 A/B/C 제시

Stage 0 시작 시 사용자에게 다음 세 옵션을 제시한다. Browser 검증이 가능하면 C도 실행할 수 있지만, A·B가 여전히 가장 빠르다.

> "어떻게 후보를 잡을까요?
>
> **옵션 A (가장 빠름)**: 평소 보시는 CC 채널·영상 URL을 직접 주세요. 그 영상 기준으로 시작합니다.
>
> **옵션 B**: YouTube에서 'Filter → Features → Creative Commons'로 검색 후 1~3개 URL을 주세요.
>
> **옵션 C**: 제가 Browser로 후보 5~8개를 모으고, 각 영상 상세 페이지에서 CC·조회수·길이·댓글 가능 여부까지 1차 검증합니다."

옵션 A/B면 그 영상으로 바로 진행한다. 옵션 C면 해시태그 검색으로 후보를 모으고, 영상 상세 페이지에서 직접 검증한 후보표를 작성한다. 댓글이 비활성이거나 로드되지 않는 경우에만 사용자에게 화면 확인 또는 댓글 복사를 요청한다.

### 해시태그 패턴 (옵션 C 진행 시)

**Creative Commons 검색 키워드**:

```
# 방법 1: 검색어에 명시 (메타 콘텐츠가 많이 섞이므로 정확도 낮음)
#piano "creative commons" site:youtube.com

# 방법 2: 사용자가 직접 YouTube에서 검색 (가장 정확)
YouTube 검색창 → "#piano #shorts" 검색 → 필터 → Features → Creative Commons
```

### 1차 출력: 후보 영상 5~8개 제시

스킬이 직접 확인할 수 있는 정보만으로 후보 표를 만든다. **추측은 절대 포함하지 않는다**:

| # | 제목 | 채널 | 업로드일 | 영상 길이 | URL | 주제(설명 기반) |
|---|-----|-----|--------|--------|-----|-----------|
| 1 | Philosopher Who Owned Nothing... | Channel A | 3일 전 | 0:55 | https://... | 디오게네스·자족 |

**칸별 기재 규칙**:
- 제목: 영상 상세 페이지 또는 메타데이터에서 가져온 그대로
- 채널: 영상 상세 페이지 또는 메타데이터로 확인한 채널명만 (확인 안 됐으면 "(확인 필요)")
- 업로드일: 영상 상세 페이지 또는 메타데이터의 publish date 그대로
- 영상 길이: 영상 상세 페이지 또는 메타데이터에서 확인됐을 때만, 안 됐으면 공란
- 주제: 영상 제목·설명 텍스트에서 객관적으로 보이는 주제만

**절대 만들지 않을 칸들**:
- ❌ "원테이크 추정" — 영상을 못 보고 어떻게 단정?
- ❌ "선정 이유" — 검증되지 않은 추측이 들어가기 쉬움
- ❌ "추천 순위", "1순위" — 데이터 없이 매기지 말 것

표 제시 후 다음 문구를 그대로 사용한다:

> "위 후보들은 **검색 결과 노출 순**이지 떡상 순서가 아닙니다. 검색에 잡혔다고 인기 영상이라는 보장이 전혀 없으니, 관심 있는 영상 2~3개를 직접 열어보시고 다음 데이터를 알려주세요."

### 2차 입력 요청: V/S 데이터 수집

사용자에게 다음과 같이 요청한다:

> "위 후보 중 관심 있는 영상 2~3개를 직접 열어보시고, 아래 정보를 알려주세요:
> - 채널 구독자 수
> - 영상 조회수
> - 좋아요 수 (있다면)
> - 인기 댓글 TOP 5~10 (복사·붙여넣기)
>
> 이걸 받으면 V/S 비율을 계산해서 가장 떡상한 영상 1개를 함께 선정하겠습니다."

이 정보 없이는 Stage 0 완료가 불가능하다. 사용자 응답 전에 Stage 1로 절대 넘어가지 않는다.

### 후보 점수화 (필수)

사용자에게 V/S 데이터를 받은 뒤 `references/source-selection-scorecard.md`의 100점 기준으로 후보를 점수화한다. 단순 조회수 순서가 아니라 **권리 안전성 → 수요 검증 → 원테이크 적합도 → 현지화 난이도 → 댓글 감정 밀도** 순서로 판단한다.

| 후보 | URL | 조회수 | CC 확인 | 권리등급 | 원테이크 | 현지화 난이도 | 댓글 감정 | 총점 | 판단 |
|---|---|---:|---|---|---:|---:|---|---:|---|

85점 이상은 1순위, 75~84점은 조건부, 65~74점은 보류, 64점 이하는 제외한다.

### 필터 기준 (사용자 데이터 수신 후 적용)

| 항목 | 조건 |
|-----|------|
| **라이선스** | **Creative Commons 필수** (없으면 즉시 제외) |
| 업로드일 | 제한 없음 (1~2년 전 영상도 가능) |
| 국가/언어 | 미국, 영어 |
| 채널 규모 | 무관 (큰 채널이어도 OK, 절대 조회수가 큰 게 핵심) |
| **조회수** | **1000만 이상 최우선 / 500만 이상도 좋음 / 그 이하는 V/S 비율이 매우 높을 때만** |
| 장르 적합도 | 라이프스타일·자기계발·감성·동기부여·음악 |
| **편집 스타일** | **원테이크 또는 세미-원테이크(컷 1~2번) 영상 우선** |

원테이크 영상을 식별하는 단서:
- 카메라가 한 동선으로 움직이는 영상 (워킹 POV, 패닝, 풀백)
- 컷 전환 없이 보이스오버가 영상 위에 흐르는 영상
- 한 공간·한 인물 중심의 연속 샷
- 악기 연주 영상은 대부분 원테이크 (연주자 한 명을 길게 잡음) — **음악 장르가 원테이크 큐레이션에 가장 적합**
- 미술·드로잉·페인팅 영상도 원테이크에 매우 적합 (캔버스·종이를 고정 카메라로 계속 잡음, 타임랩스 포함)
- "vlog", "POV", "day in my life", "morning routine", "cover", "live performance", "speedpainting", "timelapse" 류 키워드 영상
- 영상 길이 대비 컷이 적은 경우 (사용자가 영상 시청 후 알려주는 것이 가장 정확)

|-----|------|----------|------|-----|--------|-----|-------|-------|
| 1 | ... | ... | ... | ... | ... | ... | ✅ | ✅/△/❌ |

사용자가 이 중 1개를 골라 다음 단계로 진행한다.

> **주의 1**: Creative Commons가 아닌 영상은 표에 절대 포함하지 않는다. 합법 재유통의 대전제다.
> **주의 2**: 조회수 절대값이 크되 1~2년 전 영상이라면, 오히려 "검증된 인기 + 한국·일본 시장엔 아직 안 알려진" 골든 케이스일 수 있다.

## Stage 1: 성공요인 분석

선택된 영상에 대해 다음 6가지 프레임으로 분해한다.

### 분석 프레임

1. **첫 3초 후킹**: 어떤 시각/청각/문장으로 스크롤을 멈췄나?
2. **문제 제시**: 시청자의 어떤 결핍·욕망·고통을 건드렸나?
3. **시간 흐름 구조**: 60초를 어떤 비트로 나눴나? (예: 후킹 3초 → 공감 10초 → 통찰 30초 → 전환 12초 → CTA 5초)
4. **카메라·공간 흐름** *(원테이크 영상의 핵심)*: 원테이크인지 컷이 있는지 먼저 판별. 원테이크라면 카메라 동선(워킹·패닝·풀백·줌인 등)이 어떻게 시간 비트와 연결되는가? 한 공간 vs 이동하는 공간?
5. **보이스오버와 영상의 관계**: 음성과 영상이 같은 내용을 보여주는가, 음성은 통찰이고 영상은 분위기인가? (감성 쇼츠는 후자가 압도적)
6. **인기 댓글 클러스터** *(주제 방향 결정의 핵심)*: 좋아요·답글이 많은 댓글 TOP 5를 골라 무엇에 공감이 폭발했는지 짧게 메모. 이건 Stage 3에서 더 깊이 다루므로 여기서는 1차 스캔만.
7. **감정 곡선**: 어디서 끌어올리고 어디서 떨어뜨렸나?
8. **언어 패턴**: 반복 어구·리듬·말투의 특징
9. **엔딩 처리**: 마지막 5초의 CTA/여운/루프 유도

영상의 자막 또는 영상 페이지에서 얻을 수 있는 텍스트가 있다면 그것을 인용 분석한다. 영상 시청이 불가능하면 제목·설명·댓글로 추론하되 그 한계를 명시한다.

### 산출물

성공요인 분석 리포트 (1~1.5페이지 분량). 표 + 인용 + 짧은 코멘트 형식.

## Stage 2: 팩트체크

성공한 원본 영상이 인용하는 통계·실험·인용문·역사적 사례를 검증한다.

### 체크리스트

- 통계 수치: 출처·발표 연도·표본
- 심리학 실험: 실제 존재하는 연구인지, 메타분석 결과는?
- 명언/인용: 화자가 실제로 한 말인지
- 역사적 일화: 사실 vs 도시전설

웹 검색 또는 사용 가능한 브라우저/검색 도구로 1차 검증하고, 의심스러운 항목은 공식 출처·학술 출처(예: PubMed, Google Scholar, 기관 보고서)로 2차 검증한다.

### 산출물

| 주장 | 원본 영상에서의 진술 | 검증 결과 | 출처 | 권장 처리 |
|-----|------------------|---------|------|---------|
| ... | ... | ✅ 사실 / ⚠️ 부정확 / ❌ 허위 | ... | 그대로 사용 / 표현 수정 / 제외 |

## Stage 3: 추가 정보 검색 + 댓글 기반 주제 결정

**이 단계가 영상 전체의 방향을 결정한다.** 단순한 추가 리서치 단계가 아니라, 우리 영상이 어떤 주제·메시지로 갈지 확정하는 단계.

### Step A. 인기 댓글 수집 및 분석 (먼저)

원본 영상의 **좋아요 또는 답글이 많은 댓글 TOP 10~20**을 가져온다.

- 가능하면 Browser로 영상 페이지에서 직접 추출 시도
- 댓글이 비활성이거나 JavaScript 로딩 문제로 직접 추출이 어려운 경우, **댓글 비활성/확인 불가**로 기록하고 사용자에게 인기 댓글 텍스트를 복사해서 붙여달라고 요청한다
- 댓글이 끝내 없으면 댓글 클러스터 대신 원본 타임라인·교육 가치·검색 의도 기반으로 주제를 정하되, 후보 점수에서 댓글 감정 항목을 감점한다

수집한 댓글은 다음과 같이 클러스터링한다:

| 클러스터 | 댓글 예시 (인용) | 좋아요 수 | 공감 포인트 요약 |
|--------|-------------|---------|-------------|
| C1 | "딱 내 얘기네..." | 12K | 내 상황으로 받아들임 |
| C2 | "엄마한테 보여주고 싶다" | 8K | 가족 관계 환기 |
| C3 | "결국 시간이 답인가" | 5K | 시간·인내 통찰 |

**핵심**: 좋아요·답글 수는 단순 인기를 넘어 "어떤 문장·어떤 통찰에 사람들이 가장 강하게 반응했는가"의 데이터다. 이걸 무시하면 우리 영상은 원본의 핵심을 놓친다.

### Step B. 우리 영상의 주제 방향 결정

댓글 클러스터에서 **가장 인기가 높은 1~2개 공감 포인트**를 우리 영상의 핵심 주제로 삼는다.

| 항목 | 내용 |
|-----|------|
| **메인 주제** | (가장 큰 클러스터의 공감 포인트) |
| **서브 주제** | (두 번째 클러스터, 보조 메시지로) |
| **핵심 키워드 (한국어)** | 3~5개 (대본·메타데이터 공통 사용) |
| **핵심 키워드 (일본어)** | 3~5개 |
| **주제 무게 판별** | 가벼움 / 무거움·여운 (Stage 4 톤 결정의 근거) |
| **타겟 감정** | 공감 / 위로 / 깨달음 / 동기부여 / 따뜻함 등 |

이 표는 **Stage 4(대본)과 Stage 7(메타데이터)의 기준점**이 된다. 나중 단계에서 이 표와 어긋나는 표현이 나오면 다시 이 표로 돌아와 정렬한다.

### Step C. 보강 정보 검색

주제가 정해진 후, 그 주제를 강화할 보강 재료를 찾는다.

- 같은 주제의 학술 근거 (특히 심리학·행동과학)
- 한국·일본 문화권에서 다르게 받아들여질 부분
- 더 강력한 비유·예시·사례
- 댓글에서 보이는 추가 페인포인트

### 산출물

1. 인기 댓글 클러스터 분석표
2. **주제 방향 결정표** (위 Step B 표) ← 가장 중요
3. 대본 작성에 직접 쓸 수 있는 '재료 카드' 5~8개 (각각 1~2문장 요약 + 출처)

이 산출물을 사용자에게 보여주고 "메인 주제와 서브 주제 이대로 가도 될까요?"를 명확히 확인한 후 Stage 4로 넘어간다.

## Stage 4: 대본 작성

### 길이 기준

- 총 60초 이내
- 한국어: 약 220~280자 (말하기 기준 분당 약 250자)
- 일본어: 약 280~340자 (말하기 기준 분당 약 300자, 한국어보다 약간 빠름)

### 🎤 한국어 톤 선택 (필수 선행 단계)

대본 쓰기 **전에** Stage 3 Step B에서 정한 "주제 무게 판별"에 따라 두 톤 중 하나를 선택한다.

| 주제 무게 | 선택할 톤 | 핵심 어미 | 무드 |
|---------|--------|--------|-----|
| **가벼움** (일상·루틴·작은 깨달음·재미있는 통찰) | **휴먼터치 음슴체** | "~함", "~인 듯", "~하더라", "~인 거 같음" | 친근, 옆에서 말 거는 느낌 |
| **무거움·깊은 여운** (인생·이별·후회·자기긍정·치유) | **담백한 서술체** | "~다", "~한다", "~이었다" | 진정성, 절제된 감정 |

> **두 톤의 차이는 단순한 어미 선택이 아니다.** 음슴체는 사람 냄새와 친구 같은 거리감이, 담백한 서술체는 진정성과 정제된 무게감이 핵심이다. 자세한 사용법·예시·체크리스트는 **`references/korean-script-tone-guide.md`를 반드시 먼저 읽고** 대본을 작성한다.

### 첫 2초 후킹 공식

쇼츠 성패는 첫 2초에서 갈린다. 한국어/일본어 모두 첫 문장은 다음 5가지 중 하나로 설계한다.

| 후킹 유형 | 한국어 예시 | 일본어 방향 |
|---|---|---|
| 자기고백형 | “솔직히 이거 나만 그런 줄 알았음” | 「これ、自分だけかと思ってた」 |
| 반전형 | “열심히 살수록 더 망가지는 이유” | 「頑張るほど、しんどくなる理由」 |
| 숫자형 | “30대 되기 전에 알았으면 좋았을 1가지” | 「30歳になる前に知りたかったこと」 |
| 금지형 | “아침에 이거 먼저 하면 하루 망함” | 「朝いちばんに、これをすると…」 |
| 여운형 | “그날 이후로, 조금 달라졌다” | 「あの日から、少し変わった」 |

첫 문장은 자막으로 봐도 이해되어야 하고, 원본 첫 컷의 시각 정보와 충돌하면 안 된다.

> **한국어·일본어 후킹은 반드시 따로 설계한다.** 한국 후킹을 그대로 번역하면 일본에선 과하게 들린다(일본은 한 단계 톤을 낮춘다). 유형별 공식·예시·한↔일 매핑·자가 점검은 `references/first-2-seconds-hook-playbook.md`를 참고한다.

### 한국어 대본 구조

```
[0~3초] 후킹 (질문 또는 충격 진술)
[3~12초] 공감 (시청자 상황 묘사)
[12~40초] 통찰 + 사례 (이 영상의 핵심 메시지)
[40~52초] 전환 (실천 가능한 한 가지)
[52~60초] 여운 또는 CTA
```

각 비트마다 자막용 한 줄 카피 + 화자 톤 노트를 함께 적는다. 톤 노트는 위에서 선택한 톤(음슴체 / 담백한 서술체)이 일관되게 유지되는지 확인하기 위함.

### 일본어 현지화

일본어 버전은 **번역이 아니라 재작성**한다. 자세한 가이드는 `references/localization-jp.md` 참고. 핵심만 요약하면:

- 한국식 직설 어조 → 일본식 간접·여운 어조
- 「〜だよね」「〜じゃない?」 같은 공감 종결 적극 활용
- 한자어 비율 조절 (너무 많으면 딱딱, 너무 적으면 가벼움)
- 일본 쇼츠 특유의 정적인 후킹 (조용한 첫 컷 후 자막 강조) 고려
- 한국 사례·지명을 일본 사례·지명으로 자연스럽게 치환

> **주의**: 한국어가 음슴체든 담백한 서술체든, 일본어판은 일본 쇼츠의 정서적 톤(여운·간접)에 맞춰 별도로 재구성한다. 한국어 음슴체를 일본어 「〜だ」체로 직역하면 너무 무뚝뚝해진다.

### 산출물

`script-ko.md`와 `script-jp.md` 두 파일. 각각 비트별 표 + 풀 스크립트. 한국어판 파일 첫머리에 **선택한 톤(음슴체 / 담백한 서술체)을 명시**한다.

## Stage 5: 검토 후 수정

이 단계는 두 부분으로 구성된다.

- **5A. 공통 검토**: 후킹·정보 밀도·감정 곡선·CTA·톤 일관성·주제 정렬 점검
- **5B. 일본어판 강제 자가 리뷰** (필수): 스킬이 일본인 시청자 입장에서 일본어 대본을 다시 검토

### 5A. 공통 검토

대본 v1을 다음 체크리스트로 자가 검토한다.

| 점검 항목 | 기준 |
|---------|------|
| 후킹 강도 | 첫 3초만 봐도 다음을 보고 싶은가? |
| 정보 밀도 | 60초에 비해 과하거나 부족한가? |
| 감정 곡선 | 평탄하지 않고 기복이 있는가? |
| 시청 유지 | 30초 지점에 흐름이 끊기지 않는가? |
| CTA 자연스러움 | 갑자기 튀어나오지 않고 본문과 연결되는가? |
| **한국어 톤 일관성** | 선택한 톤(음슴체 또는 담백한 서술체)이 전체에 일관되게 유지되는가? 두 톤이 섞이지 않았는가? |
| **주제 정렬** | Stage 3에서 정한 메인 주제·핵심 키워드가 대본에 자연스럽게 녹아 있는가? |

### 5B. 일본어판 강제 자가 리뷰 (필수 단계)

> **사용자는 일본어를 모르거나 어색함을 직접 판별할 수 없다.** 따라서 스킬이 일본인 시청자 입장에서 대본을 다시 검토하는 단계가 반드시 필요하다. 이 단계는 사용자가 "건너뛰자"고 해도 건너뛰지 않는다. 일본어판은 항상 자가 리뷰 후 v2를 산출한다.

#### 리뷰 절차

**Step 1. 일본인 시청자 역할 가정 선언**

스킬은 다음 문장으로 명시적으로 역할 전환을 선언한다:

> "지금부터 일본 도쿄에 사는 30대 여성 쇼츠 시청자 시선으로 일본어 대본 v1을 다시 읽어보겠습니다."

**Step 2. 9개 항목 자가 리뷰**

`references/localization-jp.md`의 자가 검토 체크리스트(7번 섹션)를 기반으로 다음 9개 항목을 한 줄 한 줄 검사:

| # | 점검 항목 | 통과 기준 |
|---|--------|--------|
| 1 | 「あなた」 사용 횟수 | 0~1회 |
| 2 | 「とても」「非常に」「本当に」 강조 부사 남발 | 1회 이하 |
| 3 | 종결어 다양성 | 「です・ます」만 반복되지 않음 / 「~だよね」「~かも」 등 혼용 |
| 4 | 한국 지명·고유명사·문화 코드 잔재 | 모두 일본 컨텍스트로 치환됨 |
| 5 | 문장당 글자 수 | 30자 이하 (자막 호환) |
| 6 | 연속 한자 덩어리 | 4자 이상 한자 연속 없음 |
| 7 | 후킹 톤 | 일본식 톤(한 단계 낮춘 강도)에 부합 |
| 8 | CTA | 직접 구독 요청형 아닌 여운형 |
| 9 | **번역체 냄새 (가장 중요)** | 한국어 직역으로 보이는 일본어 어순·표현 없음 |

각 항목에 ✅ 통과 / ⚠️ 경계 / ❌ 실패 표시.

**Step 3. 문장 단위 줄별 코멘트**

일본어 대본의 각 문장을 줄별로 점검:

```
원문: 「あなたは毎朝、5分早く起きるだけで人生が変わります」
판정: ⚠️ 경계
이유: 「あなたは」 + 「~ます」 형식이 너무 설교조. 일본 감성 쇼츠는 주어 생략 + 여운형이 자연스럽다.
수정안: 「毎朝5分、早く起きるだけ。それだけで何かが変わる気がする」
```

이런 식으로 어색하거나 번역체 느낌이 나는 문장은 모두 짚어내고 수정안을 제시.

**Step 4. v2 생성**

Step 3의 수정안을 통합해서 일본어 대본 v2를 작성. v1과 v2를 나란히 표로 비교해 사용자에게 보여준다:

| 비트 | v1 (원본) | v2 (수정) | 수정 이유 |
|-----|---------|---------|---------|
| 후킹 | ... | ... | 강조 부사 제거, 여운형 종결로 변경 |

**Step 5. 최종 검증**

v2 작성 후 다시 9개 항목 체크리스트를 돌려 모두 ✅이 나오는지 확인. 만약 한 항목이라도 ⚠️ 또는 ❌이면 v3까지 반복.

> **핵심 원칙**: 사용자는 일본어 어색함을 직접 판별할 수 없으므로, 스킬의 자가 리뷰가 일본어판 품질의 유일한 안전장치다. 이 단계를 형식적으로 통과시키지 말고 진짜 일본인 입장에서 비판적으로 검토할 것.

### 산출물

- 한국어 대본 v2 (5A 결과)
- 일본어 대본 v2 (5B 결과)
- 일본어 v1 vs v2 비교표
- 일본어 자가 리뷰 9개 항목 체크리스트 결과

## Stage 6: 스토리보드 (캡컷 편집 가이드)

> 이 단계의 핵심: 사용자가 캡컷에 다운받은 원본 영상을 올려놓고 **시간 구간별로 자르고 확대해서** 우리 한국어/일본어 대본에 맞게 재구성할 수 있도록 정확한 편집 지시를 만드는 것.

거창한 B-roll 시스템도, 새 풋티지 검색도 없다. **원본 영상 1개의 어느 구간을 어떻게 확대할지**가 전부다.

**자세한 캡컷 편집 기법·확대 용도·자막 디자인은 `references/capcut-editing-guide.md`를 반드시 먼저 읽고 작성한다.**

> **🛡️ 스토리보드 완성과 동시에 변형 게이트를 통과시킨다.** 편집 지시표가 나오면 `references/transformative-editing-guide.md`의 변형 게이트 점검표를 함께 작성한다. 통과 조건은 **필수군(C1 해설·C2 정보·C3 재해석) 2개 이상 + 전체 4개 이상**이며, 미달이면 제작을 보류한다. 화면 반전을 쓰려면 같은 가이드 3번 섹션의 금지 조건(글자·로고·악기 손·드로잉 손·운전 방향)을 반드시 지킨다. 그리고 이 영상이 채널의 기존 영상과 출처·구조·톤이 충분히 다른지(채널 단위 리스크)도 함께 점검한다.

### Step 1. 원본 활용 패턴 선택

다음 3가지 중 하나를 선택해서 사용자에게 명시:

| 패턴 | 설명 | 추천 상황 |
|-----|-----|-------|
| **A. 동일 흐름** | 원본의 시간 흐름 그대로 + 음성·자막만 한·일 | 원본 호흡과 우리 대본 호흡이 잘 맞을 때 |
| **B. 구간 재배열** | 원본을 3~5구간으로 잘라 우리 대본 비트 순서에 맞게 재배치 | 원본과 우리 대본 흐름이 다를 때 (대부분) |
| **C. 핵심 구간 변주** | 원본의 인상적인 10~20초만 사용, 다른 배율·다른 부분 확대로 4~6번 변주 | 원본 일부만 강렬할 때 |

선택 이유를 한 줄로 설명한다.

### Step 2. 비트별 편집 지시표 작성

대본의 5개 비트(후킹/공감/통찰/전환/CTA)를 행으로 하고, 각 비트마다 다음 정보를 채운다:

| 비트# | 시간 (우리 영상) | 대본 한 줄 | 원본 영상 구간 | 캡컷 편집 처리 | 자막 위치 |
|------|-------------|---------|-----------|-----------|--------|
| B1 | 0~3s | "..." | 원본 00:32~00:35 | 110% 임팩트 확대 (인물 얼굴) | 화면 중앙 큰 자막 |
| B2 | 3~12s | "..." | 원본 00:00~00:09 | 150% 현지화 확대 (영문 간판 가리기) | 하단 자막 |
| B3 | 12~40s | "..." | 원본 00:09~00:30 (3구간 분할) | 100% → 130% 줌인 → 100% 복귀 | 상단·중앙 분산 |
| B4 | 40~52s | "..." | 원본 00:48~01:00 | 100% 그대로 | 하단 자막 |
| B5 | 52~60s | "..." | 원본 00:30~00:38 (재사용) | 180% 디테일 확대 (창문·빛 등 분위기) | 자막 없음, 여운 |

**각 비트의 "캡컷 편집 처리" 칸에 반드시 포함할 것**:
1. 배율 (100%, 130%, 150% 등)
2. **확대 용도** (임팩트 / 현지화 / 디테일 / 전환 중 하나)
3. **확대 중심** (인물 얼굴 / 손 / 사물 / 풍경 / 영문 간판 가리기 등)
4. 키프레임 필요 시: 시작 → 끝 배율 변화

### Step 3. 현지화 체크

이 표를 완성한 후 다음을 점검:

- [ ] 미국 원본에 한·일 시청자가 알아챌 시각 요소(영문 간판·미국 화폐·국기·영문 책 표지 등)가 있는 구간을 사용하는가? 그렇다면 모두 **현지화 확대(150~200%)**로 가렸는가?
- [ ] 백인 인물 클로즈업이 너무 많지 않은가? 손·뒷모습·풍경 위주 구간을 우선 활용했는가?
- [ ] 영문 자막·텍스트가 보이는 구간은 잘라냈거나 가렸는가?

이 체크는 **유통자 관점의 핵심**이다. 미국 원본 티가 나면 한·일 시청자 몰입이 깨진다.

### Step 4. 확대 횟수 점검

60초 기준 **4~7회 확대**가 적정선. 너무 적으면 정적이고 너무 많으면 어지럽다. 각 확대는 1~3초 유지.

### Step 5. 자막 디자인 명시

비트별로 자막의 폰트 분위기, 위치, 효과를 짧게 명시:

- 휴먼터치 음슴체 → 손글씨 느낌 폰트(야놀자 야체 등), Slide-in 효과
- 담백한 서술체 → 정제된 폰트(KoPub 돋움 등), Fade-in 효과

자세한 폰트·색·크기는 `references/capcut-editing-guide.md` 5번 섹션 참고.

### Step 6. 캡컷 템플릿 필요성 판단 및 추천

원본 영상 1개만으로 60초 채우기 어렵거나, 특정 효과(자막 박스, 인트로 임팩트, 트랜지션 등)가 필요할 때 **캡컷 무료 템플릿을 추가**하는 것이 효율적이다. 스킬은 스토리보드를 작성한 후 다음 기준으로 템플릿 필요성을 판단하고, 필요하면 어떤 종류의 템플릿을 추가할지 알려준다.

#### 템플릿 추가가 필요한 5가지 신호

| 신호 | 상황 | 권장 템플릿 종류 |
|----|----|----------|
| **원본 영상 길이 부족** | 원본이 30~40초인데 우리 영상은 60초 | "60초 전체 구조 템플릿" (인트로 + 본문 + 아웃트로) |
| **후킹 임팩트 부족** | 원본 첫 3초가 약해서 스크롤을 못 멈춤 | "Hook 인트로 템플릿" (강한 자막 등장 + 빠른 컷) |
| **자막 디자인 한계** | 단순 텍스트로는 메시지가 안 살아남 | "감성 자막 박스 템플릿" (반투명 박스 + 페이드인) |
| **분위기 전환 필요** | 가벼움 → 무거움 또는 그 반대로 톤 전환 | "톤 전환 트랜지션 템플릿" (페이드 + 색 보정) |
| **CTA·엔딩 약함** | 마지막 5초가 그냥 끝나서 여운이 없음 | "엔딩 카드 템플릿" (자막 + 페이드아웃) |

#### 템플릿 추천 출력 형식

스토리보드 표 하단에 별도 섹션으로 정리:

```
🎬 추천 캡컷 템플릿

### 추천 1: Hook 인트로 템플릿
- 추천 이유: 원본 첫 3초가 정적이어서 후킹 임팩트가 약함
- 적용 위치: 비트 B1 (0~3초) 앞에 삽입 (1~2초)
- 검색 키워드: "hook intro template", "viral hook shorts"
- 캡컷 템플릿 탭 → 검색창에 입력 → "사용 수 100만+" 인기 템플릿 선택
- 대본 변경 필요: 첫 자막을 인트로 자막으로 분리

### 추천 2: 감성 자막 박스 템플릿
- 추천 이유: 비트 B3의 통찰 문장이 단순 흰 자막으로는 무게가 안 살아남
- 적용 위치: 비트 B3 (12~40초)의 핵심 한 줄에 적용
- 검색 키워드: "aesthetic subtitle box", "soft caption template"
- 캡컷 템플릿 탭 → 검색
```

#### 템플릿이 필요 없는 경우

다음 상황에서는 템플릿을 추가하지 않고 원본 영상만으로 진행한다:

- 원본 영상이 60초 가까이 되고 자체 후킹·엔딩이 충분히 강한 경우
- 원본 영상의 미장센·색감이 이미 감성적이어서 추가 효과가 오히려 방해되는 경우
- 원테이크 영상의 자연스러움을 살리고 싶은 경우 (템플릿이 원테이크 느낌을 해칠 수 있음)

이 경우 스킬은 "이 영상은 템플릿 추가 없이 원본의 자연스러움을 살리는 것이 더 효과적입니다. 자막과 BGM만으로 충분합니다."라고 명시한다.

자세한 캡컷 템플릿 종류·검색 키워드·적용 팁은 `references/capcut-editing-guide.md`의 템플릿 섹션 참고.

### Step 7. 작업 흐름 안내

스토리보드 끝에 사용자가 캡컷에서 진행할 작업 순서를 짧게 첨부:

1. 원본 영상 임포트
2. **추천 캡컷 템플릿 다운로드** (Step 6에서 추천된 경우)
3. 비트별로 Split (자르기)
4. 불필요 구간 삭제 + 재배열
5. **템플릿 적용** (인트로·자막 박스·엔딩 카드 등)
6. 각 클립에 확대 적용
7. 한국어/일본어 자막 입력
8. BGM 추가
9. 보이스오버 녹음 또는 TTS 입력
10. 9:16 세로 비율 확인 후 내보내기

### 산출물

`storyboard.md` 파일 1개. 한국어판·일본어판 모두 같은 영상 편집 지시를 공유하되, **자막 텍스트와 폰트만 언어별로 분리**해서 명시한다. 파일 끝에 **변형 게이트 점검표**(필수군 C1~C3 중 몇 개·전체 몇 개 ✅, 각각 무엇을 했는지)를 함께 넣어 필수군 2개+전체 4개 이상을 확보했음을 명시한다.

## Stage 7: 업로드 정보

> **핵심 원칙**: Stage 3 Step B에서 정한 "메인 주제 + 핵심 키워드"를 제목·설명·태그 전체에 일관되게 반영한다. 댓글 인기 클러스터에서 추출한 공감 포인트가 곧 검색에 노출될 키워드이자 시청자가 자기 이야기로 받아들이게 만드는 단서다.

### 제목

| 언어 | 자수 가이드 | 패턴 |
|-----|----------|-----|
| 한국어 | 20~30자 | 후킹 질문형 또는 충격 단정형 — Stage 3 핵심 키워드 1개 이상 포함 |
| 일본어 | 25~35자 | 여운형 또는 호기심 자극형 — Stage 3 일본어 핵심 키워드 1개 이상 포함 |

각각 3개씩 후보 제시. 각 후보가 Stage 3에서 정한 핵심 키워드 중 어떤 것을 담고 있는지 표로 명시.

### 설명

- 한국어판 / 일본어판 각각
- 첫 줄에 후킹 한 문장 (검색 노출 시 잘림 고려) — Stage 3 메인 주제의 핵심 감정을 압축
- 중간에 핵심 메시지 1~2줄
- 마지막에 해시태그

### 해시태그

- 한국어: 5~8개 (Stage 3 한국어 핵심 키워드 + 일반 해시태그 조합)
- 일본어: 5~8개 (Stage 3 일본어 핵심 키워드 + 일반 해시태그 조합)
- 공통 영문: #Shorts #shortsfeed

### 썸네일 아이디어 (쇼츠 첫 프레임)

쇼츠는 별도 썸네일을 거의 안 쓰지만, 첫 1초가 사실상의 썸네일. 다음을 명시:

- 첫 컷의 비주얼 한 문장 설명
- 첫 컷에 얹을 자막(있다면) 한국어/일본어 — Stage 3 메인 주제의 가장 강한 한 문장
- 색감·구도 가이드

### 출처 표기

설명란 하단에 원본 출처를 표기한다. 자세한 문구는 `references/rights-safety-checklist.md`의 출처 표기 템플릿을 따른다.

### 2~3개 변형 업로드안

같은 원본으로 A/B 테스트할 수 있도록 다음을 제시한다.

| 버전 | 다른 점 | 후킹 문장 | 권장 길이 | 목표 지표 |
|---|---|---|---:|---|
| A | 원본 감성 유지 |  | 55~60초 | 완주율 |
| B | 첫 2초 자막 강화 |  | 35~45초 | 초반 유지율 |
| C | 댓글 클러스터 각도 변경 |  | 45~55초 | 댓글/저장 |

## Stage 8: 업로드 후 데이터 루프

> **핵심 원칙**: 업로드 후 성과를 보고 다음 원본과 다음 대본 각도를 정한다. 감으로 계속 만들지 않는다.

### 72시간 판단

- 초반 유지율 낮음: 첫 2초 자막/첫 컷 교체 후 B버전 재업로드
