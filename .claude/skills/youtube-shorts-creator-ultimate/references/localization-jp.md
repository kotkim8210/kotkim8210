# 일본 현지화 가이드 (Japan Localization Guide)

한국어 대본을 일본어로 옮길 때 **번역이 아니라 재작성**해야 한다. 한국인이 번역한 티가 나는 일본어 쇼츠는 일본 시청자가 첫 5초에 이탈한다. 다음 가이드를 단계별로 적용한다.

---

## 1. 어조 차이의 핵심

### 한국어 vs 일본어 감성 쇼츠 어조 비교

| 측면 | 한국어 감성 쇼츠 | 일본어 감성 쇼츠 |
|------|--------------|--------------|
| 단정성 | 직설·단정형 강함 ("이게 진짜야") | 여운·완곡 ("〜かもしれない") |
| 청자 호명 | "당신", "여러분" 자주 | 호명 자체를 줄이고 1인칭 독백조 많음 |
| 감정 표현 | 격앙·강조 부사 ("진짜", "완전") | 침묵·여백·말줄임으로 표현 |
| 종결 | "~해야 해", "~하세요" | "~してみて", "~してもいいかも" |
| 문장 길이 | 짧고 임팩트 | 약간 더 길고 흐르는 듯 |

### 자주 쓰는 일본 감성 쇼츠 종결어

- `〜だよね` — 부드러운 공감
- `〜じゃない?` — 동의 유도
- `〜かもしれない` — 단정 회피
- `〜してみて` — 부드러운 권유
- `〜という話` — 거리감 있는 통찰
- `〜気がする` — 주관적 느낌 표현

> 한국어 "이렇게 해야 합니다" → ❌ 「こうしなければなりません」 (딱딱) → ✅ 「こうしてみるといいかも」

---

## 2. 일본인이 안 쓰는 한국어 번역체 패턴

### ❌ 피해야 할 표현 → ✅ 자연스러운 일본어

| 한국어식 (어색) | 자연스러운 일본어 |
|--------------|--------------|
| あなたは〜です | 주어 생략 + 자연 흐름 |
| 〜することができます | 〜できる |
| とても/非常に 남발 | すごく、ちょっと 등 회화체 부사 |
| 〜と思います 반복 | 〜かな、〜じゃないかな |
| そして 빈번 사용 | 접속사 생략, で、それで |
| 〜してください 명령조 | 〜してみて、〜してね |
| 私は〜と思います | 主語 생략하고 흐름으로 |

### 한국식 강조 부사 → 일본식 표현

- "진짜" → 「本当に」보다 「マジで」(쇼츠 톤) 또는 그냥 생략
- "완전" → 「めっちゃ」「すっごく」 또는 강조 자체를 빼고 여운으로
- "대박" → 직역 금지. 문맥에 따라 「やばい」「すごい」또는 침묵

---

## 3. 문화 코드 치환

한국 사례를 그대로 두면 일본 시청자는 거리감을 느낀다. 다음 표를 참고해 치환한다.

| 한국 사례 | 일본 대응 |
|---------|--------|
| 한강 산책 | 鴨川沿い (교토) / 多摩川 (도쿄) 산책 |
| 카페에서 노트북 작업 | 同上 (단 일본 카페는 노트북 작업 금지인 곳 많아 「コワーキング」가 자연스러움) |
| 출근길 지하철 2호선 | 山手線 (도쿄) / 御堂筋線 (오사카) |
| 편의점 (CU·GS25) | コンビニ (브랜드 언급은 セブン이 가장 안전) |
| 김치찌개·삼겹살 사례 | お味噌汁·焼き魚 또는 일반화 |
| 수능 | 受験·センター試験·共通テスト |
| 회식 | 飲み会 |
| 카카오톡 | LINE |

### 일본 시청자에게 친숙한 라이프스타일·자기계발 모티프

- 朝活 (아침 활용)
- 手帳術 (수첩 활용법)
- ミニマリスト (미니멀리스트)
- 自己肯定感 (자기긍정감) — 일본에서 매우 트렌디한 키워드
- 整える (정돈하다) — 라이프스타일 톤의 핵심 동사
- 丁寧な暮らし (정중한 삶)

## 4. 한자어와 히라가나 비율

쇼츠 자막은 한자가 너무 많으면 답답하고, 너무 적으면 가벼워 보인다.

### 권장 비율

- 한자: 30~40%
- 히라가나: 50~60%
- 가타카나: 10% 내외 (외래어·강조어)

### 자막 가독성 팁

- 한 줄에 14~16자 이하
- 한자가 연속 3자 이상 붙으면 의도적으로 히라가나 풀기
  - 예: 「重要事項確認」 → 「大事なポイント」
- 영어 외래어는 가타카나로 자연스럽게 (モチベーション、ルーティン 등)

## 5. 일본 쇼츠 특유의 후킹 스타일

일본 감성 쇼츠는 한국·미국과 후킹 톤이 다르다.

### 한국·미국식 후킹

- "Stop scrolling right now."
- "이거 모르면 평생 후회합니다"

### 일본식 후킹 (자주 보이는 패턴)

1. **조용한 첫 컷 + 자막 강조형**
   - 첫 1초: 무음, 흐릿한 풍경
   - 큰 자막: 「実は、〇〇な人ほど〜」
2. **질문 던지기형**
   - 「最近、こんなことありませんか?」
3. **숫자·단정 시작형**
   - 「3年前の私に、これだけは伝えたい」
4. **고요한 1인칭 독백형**
   - 「気づいたら、もう30歳になっていた」

> 한국어 후킹을 그대로 직역하면 보통 일본인에게 과하게 들린다. 일본 버전 후킹은 한 단계 톤을 내린다고 생각하면 됨.

---

## 6. CTA·엔딩 차이

### 한국 쇼츠 CTA

- "구독·좋아요 부탁드려요"
- "다음 영상도 기대해 주세요"

### 일본 쇼츠 CTA

- 직접 구독 요청은 오히려 거부감
- 자연스러운 끝맺음 + 채널 컨셉 어필
- 예시:
  - 「またこんな話、シェアしていくね」
  - 「気になった人は他の動画も覗いてみて」
  - 「今日も、ちょっといい一日を」

여운형 엔딩이 일본 쇼츠에서 훨씬 효과적.

---

## 7. 일본어 대본 자가 검토 체크리스트

대본 v1을 만든 후 다음 항목을 점검한다.

- [ ] 「あなた」가 3회 이상 나오지 않는가? (1회 이하 권장)
- [ ] 「とても」「非常に」가 남발되지 않는가?
- [ ] 한국 지명·고유명사가 그대로 남아 있지 않은가?
- [ ] 종결어가 「です・ます」 일변도가 아닌가? (회화체 종결 섞기)
- [ ] 한 문장이 30자를 넘기지 않는가? (자막 호환성)
- [ ] 한자 연속 4자 이상 덩어리가 없는가?
- [ ] 후킹이 일본식 톤 (한 단계 낮춘 강도)인가?
- [ ] CTA가 직접 구독 요청형이 아닌 여운형인가?

체크리스트 모두 통과하면 자연스러운 일본어 쇼츠 대본에 가깝다.

## 8. 빠른 참고: 라이프스타일·자기계발 쇼츠에서 자주 쓰이는 일본어 표현

- 自分らしく生きる — 자기답게 살다
- 心が整う — 마음이 정돈되다
- 小さな習慣 — 작은 습관
- 朝の過ごし方 — 아침을 보내는 법
- 頑張りすぎない — 너무 애쓰지 않는다
- 自分を大切にする — 자기 자신을 소중히 하다
- 比較しない — 비교하지 않는다
- 一日一つだけ — 하루에 하나만
- 流されない生き方 — 휩쓸리지 않는 삶
- 心地よい暮らし — 편안한 일상
