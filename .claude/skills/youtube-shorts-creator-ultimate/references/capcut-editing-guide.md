# 캡컷 편집 가이드 (CapCut Editing Guide)

이 스킬은 미국 원본 쇼츠 1개를 **다운받아서** 한국·일본 시청자용으로 **현지화·재편집**하는 흐름이다. 새 영상 소스를 잔뜩 찾지 않는다. 원본 영상의 시간 구간을 골라 쓰고, 캡컷에서 확대·자막·속도 등으로 우리 대본의 호흡과 현지 정서에 맞춘다.

이 가이드는 스토리보드 작성 시 사용자에게 **"어디를 어떻게 편집하라"**를 정확히 알려주기 위한 도구다.

---

## 1. 캡컷 편집의 핵심 기법

| 기법 | 캡컷 메뉴 | 용도 |
|-----|--------|-----|
| **클립 자르기 (Split)** | Edit → Split | 원본 영상을 구간으로 쪼개기 |
| **확대/축소 (Zoom)** | Adjust → Scale 또는 키프레임 | **현지화·임팩트의 핵심** |
| **속도 조절 (Speed)** | Edit → Speed | 빠르게/느리게로 감정선 조정 |
| **자막 (Text)** | Text → Add Text | 한국어/일본어 자막 입히기 |
| **좌우 반전 (Mirror/Flip)** | Edit → Mirror | 구도 조정·시각 변주 (목적 한정, 아래 주의) |

이 기법들로 90% 이상의 작업을 처리한다. 트랜지션·필터·음악은 보조.

> **반전(Flip) 주의 — 반드시 읽기:** 반전은 탐지 회피용이 아니라 **구도 개선·시각 피로 감소·같은 구간 재사용 변주** 목적으로만 쓴다. 반전 자체는 "실질적 변형"으로 인정되지 않으므로 단독으로 의존하지 말 것. 그리고 **글자·로고·악기 연주 손·글씨 쓰는 손·운전 방향·숫자가 보이는 장면은 절대 반전하지 않는다**(거울상이 되어 즉시 들킴). 자세한 기준은 `transformative-editing-guide.md` 3번 섹션 참고.

## 2. 🔍 확대(Zoom)의 4가지 용도 — 가장 중요

확대는 단순히 화면을 키우는 게 아니라 **편집의 의도**를 만든다. 4가지 용도로 구분해서 스토리보드에 명시한다.

### 2.1 임팩트 확대 (Impact Zoom)

대본의 강조 순간에 영상도 확대해서 시청자의 시선을 집중시킨다.

- **언제**: 대본의 핵심 문장, 감정 피크 순간
- **배율**: 110~130%
- **타이밍**: 강조 문장 시작과 동시에 1~2초 안에 확대
- **예**: "그 5분이 진짜 컸음" 자막이 뜨는 순간 인물 얼굴 또는 손에 110% 확대

### 2.2 현지화 확대 (Localization Zoom) — **유통자 관점의 핵심**

미국 원본 영상에 한·일 시청자가 "이거 미국 영상이네"라고 알아챌 요소를 가리기 위한 확대.

가려야 할 시각 요소:
- 영문 간판·도로 표지판
- 미국 화폐·신용카드 디자인
- 미국 국기·미국식 인테리어
- 백인 인물의 클로즈업 (덜 가리지만 톤 조정용)
- 영문 자막·노트·책 표지

**처리 방법**:
- 해당 요소가 작게 보이는 부분으로 **150~200% 확대**해서 그 요소를 프레임 밖으로 밀어내거나
- 인물의 일부(손·발·옷자락)에만 집중하도록 확대
- 풍경·하늘·식물 등 국적 없는 요소만 보이게 확대

### 2.3 디테일 확대 (Detail Zoom)

대본의 통찰을 강화하는 디테일을 강조한다.

- **언제**: 대본이 추상에서 구체로 내려갈 때
- **배율**: 140~180%
- **예**: 대본이 "작은 습관 하나"라고 말할 때 → 노트에 펜이 닿는 손 클로즈업으로 확대

### 2.4 전환 확대 (Transition Zoom)

컷과 컷 사이의 자연스러운 흐름을 만든다.

- **언제**: 원본의 두 구간을 이어 붙일 때 어색한 점프 컷이 생길 때
- **배율**: 시작 100% → 끝 120% 또는 그 반대 (키프레임 사용)
- **효과**: 점프 컷을 의도된 줌 인/아웃으로 보이게 함

## 3. 원본 영상 구간 활용 패턴

미국 원본 쇼츠 60초를 그대로 가져다 우리 한국어/일본어 대본 60초에 맞추는 게 아니다. 다음 패턴 중 하나를 선택:

### 패턴 A: 동일 흐름 (가장 단순)

원본 영상의 시간 흐름을 그대로 따라가되, 음성만 한국어/일본어로 갈아 끼움. 자막도 우리 언어로.

- **장점**: 작업 빠름, 원본의 동선 그대로 활용
- **단점**: 우리 대본 호흡이 원본과 안 맞을 수 있음

### 패턴 B: 구간 재배열

원본 영상을 3~5개 구간으로 자른 뒤, 우리 대본의 비트 순서에 맞게 재배열. 같은 구간을 두 번 쓰는 것도 허용.

- **장점**: 우리 대본 흐름에 영상이 따라옴
- **예**: 원본 [0~10s] [10~25s] [25~45s] [45~60s] → 재배열 [25~30s] [0~10s] [45~60s] [10~25s] [55~60s]

### 패턴 C: 핵심 구간 집중 + 확대 변주

원본의 가장 인상적인 10~20초만 사용하되, 같은 영상을 다른 배율·다른 부분 확대로 4~6번 변주.

- **장점**: 원본 활용도 극대화, 시청자가 같은 영상인 줄 모름
- **예**: 원본 [30~40s] 구간을 → 100%로 한 번, 150% 인물 손 확대로 한 번, 180% 인물 얼굴 확대로 한 번, 좌상단 확대로 한 번 사용

대부분의 감성 쇼츠는 **패턴 B 또는 C**가 효율적이다.

## 4. 스토리보드 표 형식 (캡컷 친화적)

| 비트# | 시간 (우리 영상) | 대본 (한국어) | 원본 영상 구간 | 캡컷 편집 처리 | 자막 위치 |
|------|-------------|------------|-------------|-----------|--------|
| B1 | 0~3s | "30대 되니까 아침 5분이 다르더라" | 원본 00:32~00:35 | 110% 임팩트 확대 (인물 얼굴 중심) | 화면 중앙 큰 자막 |
| B2 | 3~12s | "그냥 5분만 일찍 일어났을 뿐인데" | 원본 00:00~00:09 | 150% 현지화 확대 (영문 알람시계 가리기) | 하단 자막 |
| B3 | 12~40s | "처음엔 미친 짓인 줄 알았음 / 근데 일주일 해보니까 / 커피 마실 시간이 생기더라" | 원본 00:09~00:30 (3구간으로 분할) | 첫 구간 100% → 두 번째 130% 줌인 → 세 번째 100% 복귀 (전환 확대) | 비트별 상단·중앙·하단 분산 |
| B4 | 40~52s | "뭐 거창한 거 아님 / 그냥 알람 5분 당기면 됨" | 원본 00:48~01:00 | 100% 그대로 사용 | 하단 자막 |
| B5 | 52~60s | "해보면 알 듯" | 원본 00:30~00:38 (재사용) | 180% 디테일 확대 (창문·빛 등 분위기 컷) | 자막 없음, 여운 |

**각 비트의 캡컷 편집 처리에 반드시 포함되어야 할 정보**:
1. 배율 (100%, 130%, 150% 등)
2. 확대 용도 (임팩트 / 현지화 / 디테일 / 전환)
3. 확대 중심 (인물 얼굴 / 손 / 사물 / 풍경)
4. 키프레임 필요 시: 시작 → 끝 배율 변화 명시

## 5. 자막 디자인 가이드 (한국어/일본어)

캡컷 자막은 영상의 정서와 톤을 결정한다.

### 5.1 폰트 선택

| 톤 | 한국어 폰트 (캡컷 기본) | 일본어 폰트 |
|----|----------------------|----------|
| 휴먼터치 음슴체 | 야놀자 야체, 나눔손글씨 펜 류 (손글씨 느낌) | しねきゃぷしょん、851チカラヨワク |
| 담백한 서술체 | KoPub 돋움, 나눔명조 (정제된 느낌) | 游明朝、ヒラギノ明朝 |

### 5.2 자막 위치

| 위치 | 사용 시점 |
|-----|--------|
| 화면 중앙 큰 자막 | 후킹·핵심 통찰 강조 (0~3초 후킹, CTA) |
| 하단 자막 (Default) | 일반 보이스오버 자막 |
| 상단 자막 | 인물 얼굴이 하단에 있을 때 |
| 좌상단·우상단 작은 자막 | 부가 정보 (출처·인용 등, 거의 안 씀) |

### 5.3 자막 크기·색

- 본문: 48~60px, 흰색 + 검정 외곽선
- 강조: 60~80px, 흰색 + 진한 배경(검정 또는 단색)
- 여운/엔딩: 작게(40~48px), 회색 또는 옅은 색

### 5.4 자막 등장 효과

- 음슴체 대본: Slide-in (옆에서 슬쩍 들어오는 효과) — 친근
- 담백한 서술체: Fade-in (페이드인) — 정제됨
- 강조 순간: Pop (튀어나오는 효과) — 임팩트

## 6. 음악·BGM 가이드 (짧게)

캡컷의 무료 BGM 라이브러리에서 선택. 톤별 가이드:

| 한국어 톤 | 추천 BGM 분위기 |
|---------|------------|
| 휴먼터치 음슴체 (가벼움) | Lo-fi, Chill Acoustic, Soft Piano (밝지만 차분) |
| 담백한 서술체 (무거움) | Ambient, Cinematic Soft, Piano Solo (잔잔하고 여운) |

- BGM 볼륨: 보이스오버 대비 -15~-20dB (배경에 깔리도록)
- BGM 시작 타이밍: 영상 시작 0.5초 후 페이드인
- BGM 종료: 마지막 2초 페이드아웃

## 7. 트랜지션은 거의 안 쓴다

감성 쇼츠에서 화려한 트랜지션은 정서를 깨뜨린다. 사용해도 되는 것:

- **Fade (페이드)**: 비트 사이의 부드러운 전환
- **Cross Dissolve (디졸브)**: 두 컷이 천천히 겹쳐 사라지는 효과
- **줌 전환 (Zoom Transition)**: 확대 키프레임으로 자연스럽게 다음 컷으로

피해야 할 트랜지션: Glitch, Spin, Flash, Whip — 감성 쇼츠와 안 맞음.

## 8. 60초 안에서의 확대 횟수 권장

| 영상 길이 | 권장 확대 횟수 |
|---------|----------|
| 30초 이하 | 2~3회 |
| 30~45초 | 3~5회 |
| 45~60초 | 4~7회 |

너무 많으면 어지럽고, 너무 적으면 정적인 영상이 된다. 60초 쇼츠 기준 평균 **5회 정도**의 확대가 적정선.

각 확대는 1~3초 유지. 너무 짧으면 어색하고 너무 길면 정적.

## 9. 작업 흐름 요약

스토리보드를 작성한 후 사용자가 캡컷에서 진행할 작업 순서:

1. **원본 영상 임포트** → 타임라인에 올림
2. **비트별로 Split (자르기)** → 스토리보드의 원본 영상 구간대로 분할
3. **불필요 구간 삭제 + 재배열** → 우리 대본 순서에 맞게
4. **각 클립에 확대 적용** → 스토리보드의 배율·중심·용도대로
5. **자막 입력** → 한국어/일본어 자막 위치·크기대로
6. **BGM 추가** → 톤에 맞는 BGM
7. **보이스오버 녹음 또는 TTS 입력**
8. **세부 조정** (속도, 페이드, 미세한 타이밍)
9. **9:16 세로 비율 확인 후 내보내기**

## 11. 캡컷 템플릿 종합 가이드

원본 영상 1개만으로 60초 채우기 어렵거나, 특정 효과가 필요할 때 캡컷의 무료 템플릿을 활용한다. 캡컷에는 **'템플릿' 탭**이 있어 다른 크리에이터가 만든 템플릿을 그대로 가져다 쓸 수 있다.

### 11.1 캡컷 템플릿이란

- 캡컷 앱·웹의 '템플릿' 탭에서 검색 가능
- 다른 크리에이터가 만든 인트로·트랜지션·자막 효과 묶음
- 클립 슬롯에 내 영상을 넣으면 자동으로 효과 적용
- 사용 수(=인기) 표시되므로 검증된 템플릿 선택 가능

### 11.2 템플릿 추가가 필요한 5가지 신호 (상세)

| # | 신호 | 진단 질문 | 권장 템플릿 종류 |
|---|----|------|----------|
| 1 | **원본 영상 길이 부족** | 원본이 30~45초인데 우리는 50~60초 채우고 싶다? | 60초 전체 구조 템플릿 (인트로+본문+아웃트로) |
| 2 | **후킹 임팩트 부족** | 원본 첫 3초가 정적이거나 약한가? | Hook 인트로 템플릿 (자막 등장 + 빠른 컷) |
| 3 | **자막 디자인 한계** | 단순 흰 자막으로는 메시지의 무게가 안 살아남? | 감성 자막 박스 템플릿 (반투명 박스 + 페이드) |
| 4 | **분위기 전환 필요** | 톤이 바뀌는 지점에 자연스러운 다리가 필요한가? | 톤 전환 트랜지션 템플릿 |
| 5 | **CTA·엔딩 약함** | 마지막 5초가 그냥 끝나는 느낌인가? | 엔딩 카드 템플릿 (자막 + 페이드아웃) |

### 11.3 장르별 추천 템플릿 카테고리

| 장르 | 어울리는 템플릿 카테고리 | 캡컷 검색 키워드 |

### 11.5 템플릿 사용 시 주의사항

1. **사용 수 100만+ 검증된 템플릿 우선** — 신뢰도와 안정성이 다르다
2. **저작권 음악 자동 삽입 주의** — 일부 템플릿은 저작권 있는 음악 자동 삽입. 사용 전 음악 라이선스 확인. 안전한 무료 BGM으로 교체 권장
3. **템플릿 슬롯 수와 우리 영상 컷 수 매칭** — 슬롯이 8개인 템플릿을 컷 3개짜리 원테이크 영상에 강제로 적용하면 어색해진다
4. **원테이크 감성 유지 우선** — 화려한 템플릿은 원테이크의 자연스러움을 깬다. 최소한의 보조 역할로만
5. **한·일 모두 자연스럽게** — 영어 디폴트 텍스트가 들어간 템플릿은 한·일 자막으로 모두 교체

### 11.6 템플릿이 오히려 방해되는 경우

다음 상황에서는 템플릿을 추가하지 않는다:

- 원본 영상이 이미 60초 가까이 되고 자체 후킹·엔딩이 충분히 강함
- 원본 영상의 미장센·색감이 이미 완성도 높음 (특히 시네마틱 라이프스타일)
- 원테이크의 자연스러움이 핵심 매력인 경우
- 음악 연주 영상에서 연주의 흐름이 끊기지 말아야 할 때

이 경우 스킬은 사용자에게 "이 영상은 템플릿 없이 자막·BGM만으로 충분합니다"라고 명시한다.

### 11.7 템플릿 적용 워크플로우

1. 캡컷 앱 실행
2. 하단 메뉴 → '템플릿' 탭
3. Stage 6에서 추천한 검색 키워드 입력
4. 사용 수 많은 순으로 정렬
5. 마음에 드는 템플릿 미리보기 → '템플릿 사용' 버튼
6. 슬롯에 우리 원본 영상의 해당 구간 삽입
7. 자막 텍스트를 우리 한국어·일본어로 교체
8. BGM은 안전한 무료 BGM으로 교체
9. 저장 후 메인 프로젝트에 합치기

## 12. 첫 2초 유지율용 편집 체크

쇼츠는 첫 2초에서 대부분의 승부가 난다. 스토리보드 작성 시 첫 비트는 반드시 아래 중 2개 이상을 포함한다.

- 화면 중앙 큰 자막으로 “내 이야기” 느낌 만들기
- 원본에서 가장 움직임이 큰 구간을 첫 컷으로 당겨오기
- 110~125% 빠른 임팩트 줌으로 정지감 제거
- 첫 0.5초 무음 금지. 보이스오버나 효과음 즉시 시작
- 미국색이 강한 화면은 첫 컷으로 쓰지 않기

## 13. 루프 엔딩 설계

마지막 1~2초는 첫 문장으로 다시 이어지게 만든다.

예시:

- 첫 문장: “아침 5분이 하루를 바꾸더라”
- 마지막 문장: “그래서 내일도, 딱 5분만 먼저 일어나보려고”

이렇게 끝내면 시청자가 자연스럽게 첫 장면으로 돌아가도 어색하지 않아 반복 시청 가능성이 높아진다.
