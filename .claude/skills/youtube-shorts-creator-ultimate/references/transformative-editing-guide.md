# 실질적 변형 가이드 (Transformative Editing Guide)

해외 원본을 한·일로 현지화·재유통할 때 **이 스킬의 수익화 존립 조건**은 단 하나다.
"원본을 그대로 옮긴 영상"이 아니라 **"원본을 재료로 새로 만든 영상"**이어야 한다는 것.

줌·반전·색보정·자막 번역만으로는 이 조건을 만족하지 못한다. 이 가이드는 Stage -1(권리 점검)과 Stage 6(스토리보드) 사이에서 **변형 강도를 정량적으로 확보**하기 위한 도구다.

---

## 1. 왜 이게 가장 중요한가 — YouTube 정책 현실

YouTube의 채널 수익화 정책은 재사용 콘텐츠를 허용하더라도, 시청자가 원본과 내 영상 사이의 **의미 있는 차이**를 명확히 느낄 수 있어야 한다는 방향이다. 또한 대량 생산·반복·저부가가치 패턴은 수익화 리스크가 된다. 정확한 최신 문구는 `policy-source-notes.md`의 공식 링크를 다시 확인한다.

### YouTube가 명시적으로 "수익화 불가"로 드는 예시 (공식 기준)

| 금지 유형 | 우리 작업에서 걸리는 지점 |
|---|---|
| 타인이 만든 자료(웹 텍스트·뉴스피드 등)의 단순 낭독 | 원본 음성을 그대로 두고 자막만 번역 |
| 음정·속도만 바꾸고 사실상 동일한 음원/영상 | 속도 변경·색보정만으로 "변형했다"고 착각 |
| 변형·해설·서사가 거의 없는 반복적 유사 콘텐츠 | 같은 원본을 자막만 바꿔 A/B/C 양산 |
| 동일 템플릿을 대량 적용한 콘텐츠 | 모든 영상에 같은 캡컷 템플릿·같은 구조 |
| 서사·해설·교육 가치 없는 이미지 슬라이드/스크롤 텍스트 | 원본 위에 자막만 얹은 정적 영상 |

> **2026년 추가 사항(확인된 사실):** 위 기준은 AI 생성 오디오(AI 보이스오버·AI 음악)에도 명시적으로 적용된다. AI TTS 보이스오버를 쓰더라도 "원본 + AI 음성 + 자막"만으로는 변형으로 인정받기 어렵다. **사람의 큐레이션·서사·해설 레이어**가 반드시 들어가야 한다.

> **불확실성 표시:** YouTube는 정확한 enforcement 임계값(예: "해설 비율 몇 % 이상")을 공개하지 않는다. 일부 매체가 "commentary ratio", "yellow Shorts는 green 대비 약 60~70% 낮은 수익" 같은 수치를 언급하지만 이는 비공식 2차 출처이므로 절대 기준으로 삼지 말 것. **제작 직전 항상 공식 정책 페이지(support.google.com/youtube)를 재확인**한다.

### 결론

이 스킬이 살아남는 길은 "탐지를 회피하는 것"이 아니라 **"실제로 다른 영상을 만드는 것"**이다. 아래의 변형 요소를 정직하게 채운다.

## 2. 변형 강도 정량 게이트 (Hard Gate)

변형 축은 7개지만 **무게가 다르다.** "원본 없이는 만들 수 없는 가치"를 만드는 축(필수군)과, 그것을 거드는 축(보조군)을 구분한다. 단순히 4개를 세는 게 아니라 **필수군에서 반드시 채워야** 게이트를 통과한다.

### 필수군 (Core) — 여기서 최소 2개 ✅ 필수

이 축들이 "재사용 콘텐츠"와 "재해석 콘텐츠"를 가르는 핵심이다. 보조군만 잔뜩 채우고 필수군이 비면 **정책상 여전히 재사용 콘텐츠**로 본다.

| # | 변형 축 | 무엇인가 | 인정 기준 (이 정도는 되어야 ✅) |
|---|---|---|---|
| **C1** | **해설형 내레이션** | 원본 음성을 우리 보이스오버로 교체하고, 단순 번역이 아니라 **우리 관점·통찰을 더한** 대본 | 원본에 없던 문장·관점·해석이 대본의 50% 이상 |
| **C2** | **정보 레이어** | 원본에 없던 맥락·통계·문화 비교·실천 팁을 얹음 | Stage 2(팩트체크)·Stage 3(보강) 재료가 영상에 2개 이상 반영 |
| **C3** | **비교/리뷰·재해석 구조** | "원본은 이렇게 말하지만 한국·일본 맥락에선…" 같은 메타 관점 | 해설·비교·재해석 프레임이 영상의 뼈대로 존재 |

### 보조군 (Support) — 게이트 통과를 거들지만 단독으론 불충분

| # | 변형 축 | 무엇인가 | 인정 기준 |
|---|---|---|---|
| S1 | **스토리라인 재구성** | 원본 시간 흐름을 우리 비트로 재배열 | 캡컷 패턴 B/C 적용, 구간 순서가 원본과 다름 |
| S2 | **현지화 크롭/줌** | 미국색 제거 + 한·일 정서 프레이밍 | 현지화 줌 최소 1회 + 미국색 노출 0 |
| S3 | **자막 스토리텔링** | 자막이 번역 자막이 아니라 서사 장치 | 후킹·강조·여운 자막이 비트별로 설계됨 |
| S4 | **사운드 재설계** | 원본 BGM 제거 + 안전 BGM/효과음 + 보이스오버 믹싱 | 원본 오디오 의존 0, 우리 사운드 레이어 존재 |

### 통과 조건 (둘 다 만족해야 제작 승인)

1. **필수군(C1~C3)에서 2개 이상 ✅**
2. **필수군 + 보조군 합계 4개 이상 ✅**

> 왜 이렇게 나눴나: YouTube가 보는 건 "편집을 얼마나 했나"가 아니라 **"사람의 편집적·해설적 손길로 새 가치를 더했나"**다. 사운드 교체(S4)·현지화 줌(S2)은 기술적 처리라 그것만으로는 "원본을 재료로 새로 만들었다"고 인정받기 어렵다. 반면 해설(C1)·정보(C2)·재해석(C3)은 원본에 없던 콘텐츠를 더하는 것이라 정책이 요구하는 "significant original value"에 직접 대응한다.

### 출력 형식 (스토리보드 단계에서 함께 산출)

| 군 | 변형 축 | 적용 | 구체적으로 무엇을 했나 |
|---|---|---|---|
| 필수 | C1 해설형 내레이션 | ✅/❌ | |
| 필수 | C2 정보 레이어 | ✅/❌ | |
| 필수 | C3 비교/재해석 | ✅/❌ | |
| 보조 | S1 스토리라인 재구성 | ✅/❌ | |
| 보조 | S2 현지화 크롭/줌 | ✅/❌ | |
| 보조 | S3 자막 스토리텔링 | ✅/❌ | |
| 보조 | S4 사운드 재설계 | ✅/❌ | |
| | **필수군** | **n / 3** | **2 미만이면 보류** |
| | **합계** | **n / 7** | **4 미만이면 보류** |

## 3. 화면 반전(Flip)에 대한 명확한 입장

화면 좌우 반전(수평 미러링)은 **추가 가능한 편집 기법**이지만, 목적과 금지 조건을 반드시 지킨다.

### 반전은 이 목적으로만 쓴다 (탐지 회피 ❌)

- **시각 피로 감소**: 같은 원본을 여러 번 보는 시청자/알고리즘에게 변주를 줌
- **구도 개선**: 시선 방향·여백을 우리 자막 위치에 맞게 조정
- **같은 구간 재사용 변주**: 패턴 C에서 같은 10~20초를 다르게 보이게 함

> 반전은 "원본을 다르게 보이게 만드는 꼼수"가 아니다. **그 자체로는 변형 축에 포함되지 않는다.** 반전만으로 변형을 채웠다고 판단하지 말 것. 반드시 필수군(C1~C3) 2개 이상을 포함한 4개 이상과 함께 쓴다.

### 절대 반전하면 안 되는 장면

| 금지 대상 | 이유 |
|---|---|
| **글자·자막·간판이 보이는 장면** | 글자가 거울상이 되어 즉시 부자연스러움 |
| **로고·브랜드 마크** | 좌우 뒤집힌 로고는 어색하고 신뢰도 하락 |
| **악기 연주 손 위치** | 피아노·기타 운지가 거울상이 되면 연주자가 위화감 (왼손잡이로 보임) — **음악 장르 핵심 주의** |
| **운전 방향·도로** | 좌측통행/우측통행이 뒤집혀 비현실적 |
| **글씨 쓰는 손 / 드로잉 방향** | 미술·캘리그래피에서 펜 잡은 손이 뒤집히면 어색 — **미술 장르 핵심 주의** |
| **숫자·시계·텍스트가 있는 사물** | 거울상 숫자는 바로 들킴 |

### 반전 적용 시 캡컷 처리

- 캡컷: 클립 선택 → Edit → Mirror(미러) 또는 Flip horizontal
- 반전 후 **위 금지 요소가 프레임에 안 들어오는지** 한 번 더 확인
- 반전한 구간은 스토리보드 "캡컷 편집 처리" 칸에 `좌우 반전 (목적: 구도 조정)`처럼 목적을 명기

## 4. 채널 단위 리스크 (영상 1개만 잘 만든다고 끝이 아니다)

가장 자주 놓치는 함정이다. YouTube의 재사용/비진정성 콘텐츠 정책은 **영상 1개가 아니라 채널 전체를 단위로 심사**한다. 즉 영상마다 변형 게이트를 통과해도, **채널 전체가 "같은 원본 출처·같은 구조·같은 템플릿의 반복"으로 보이면 채널 단위로 수익화가 거절**될 수 있다. 정책 문구와 심사 관점은 바뀔 수 있으므로, 이런 반복 패턴은 항상 보수적으로 피한다.

### 채널 단위로 위험한 패턴

| 위험 패턴 | 왜 위험한가 |
|---|---|
| **한 해외 채널만 계속 우려먹기** | "그 채널 영상을 옮기는 채널"로 보임. 출처 채널이 다양해야 함 |
| **모든 영상이 같은 템플릿·같은 구조** | 정책이 명시한 "동일 템플릿 대량 적용"에 정확히 해당 |
| **같은 원본의 A/B/C를 전부 정식 업로드** | "minimal variation across videos"(영상 간 변형 미미)로 묶임 |
| **인트로·자막·BGM·편집이 영상마다 판박이** | 사람의 편집적 손길이 없는 자동화로 보임 |

### 채널 단위 안전 운영 기준

- **출처 원본 채널을 분산한다.** 한 채널·한 크리에이터에 집중하지 말고 여러 출처에서 가져온다. 같은 출처 비중이 채널의 30%를 넘지 않게.
- **A/B/C 변형은 "테스트용"이지 "업로드 수 늘리기용"이 아니다.** 같은 원본의 변형은 **동시에 다 올리지 말고**, 가장 반응 좋은 1개를 본편으로 남기고 나머지는 내리거나 다른 날 각도를 크게 바꿔(C3 재해석 추가) 올린다. → 자세한 운영은 `growth-ops-playbook.md`
- **구조에 변주를 준다.** 후킹 유형(자기고백/반전/숫자/금지), 톤(음슴체/담백), 길이(35~60초)를 영상마다 섞는다. 30개가 다 "후킹→공감→통찰→CTA 55초 음슴체"면 위험.
- **채널 자체의 정체성을 만든다.** "해외 영상 현지화 채널"이 아니라 "○○를 다루는 채널"로 보이게. 일관된 주제·관점·해설 스타일이 채널 전체에 흐르면 그 자체가 "original value"의 증거가 된다.

> 핵심 전환: 이 스킬의 목표는 "영상 1개를 잘 만드는 것"을 넘어 **"이 채널은 사람이 큐레이션·해설하는 채널"이라는 인상을 채널 전체에서 주는 것**이다. 영상별 게이트(섹션 2)와 채널 패턴(이 섹션)을 둘 다 통과해야 장기 수익화가 안전하다.

## 5. 음원·Content ID 주의 (수익화 직결)

원본 영상의 BGM은 거의 항상 위험하다. 처리 원칙:

- **원본 BGM은 기본적으로 제거**한다. CC 영상이어도 그 안에 쓰인 음악은 별도 라이선스일 수 있다.
- 캡컷 무료 BGM 라이브러리, YouTube 오디오 보관함, 또는 명시적 라이선스 음원으로 **교체**한다.
- **Content ID 클레임 ≠ 저작권 경고(strike).** Content ID 클레임은 채널을 삭제하진 않지만, 해당 영상 수익이 원저작권자에게 가거나 광고가 제한될 수 있다. 즉 **클레임 = 우리 수익 0**이 될 수 있으므로 음원은 항상 안전한 것으로.
- 캡컷 템플릿에 자동 삽입되는 음악은 저작권 음원인 경우가 있다. 템플릿 사용 시 음악은 반드시 안전한 BGM으로 교체한다.

## 6. 장르별 변형 포인트

| 장르 | 가장 쉽게 채우는 변형 축 | 특히 주의할 점 |
|---|---|---|
| **라이프스타일·자기계발** | C1(해설)·C2(정보 레이어)·S1(재구성) | 미국식 사례를 한·일 사례로 치환(S2·C2) |
| **감성·인생 통찰** | C1(재해석)·S3(자막 서사)·S4(사운드) | 담백한 서술체 + 여운 자막으로 원본과 다른 정서. 필수군이 C1뿐이면 C2(맥락)·C3(재해석)을 1개 더 채울 것 |
| **음악·악기 연주** | C2(연주 배경·곡 해설)·C3(비교)·S3(자막 스토리) | **반전 금지(손 위치)** + 원곡이 저작권 음악이면 사용 불가 |
| **미술·드로잉·페인팅** | C1(과정 해설)·C2(기법·작가 맥락)·S3(라벨 자막) | **반전 금지(그리는 손)** + 타임랩스에 해설·정보 레이어 필수 |

> 음악·미술은 원테이크 적합도가 높아 매력적이지만, **반전 금지 + 음원 권리**라는 두 함정이 있다. 게다가 이 장르는 영상 자체에 말이 적어 해설(C1)을 넣기 어려우므로, **C2(정보 레이어)·C3(비교/재해석)으로 필수군을 채우는 것이 가장 안전하다.** 연주·그림 위에 "이 곡의 배경", "이 기법의 역사", "원작자 의도 vs 우리 해석" 같은 정보·메타 레이어를 얹는다.

## 7. 빠른 자가 점검 (스토리보드 직후)

- [ ] 변형 축 중 **필수군(C1~C3) 2개 이상 + 합계 4개 이상** ✅인가?
- [ ] 원본 음성/BGM에 의존하지 않는가? (사운드 재설계 완료)
- [ ] 미국색 시각 요소 노출이 0인가?
- [ ] 자막이 단순 번역이 아니라 서사 장치로 기능하는가?
- [ ] 반전을 썼다면 금지 요소(글자·로고·악기 손·드로잉 손·운전 방향)가 들어가지 않았는가?
- [ ] **(채널 단위)** 이 영상이 채널의 기존 영상들과 출처·구조·톤이 충분히 다른가? (같은 출처 우려먹기·판박이 구조 아님)
- [ ] "이 영상을 원작자가 봐도 표절이 아니라 재해석이라고 느낄까?"에 자신 있게 ✅인가?

마지막 질문에 ❌이면, 변형 강도가 부족한 것이다. 필수군(C1 해설·C2 정보·C3 재해석)을 더 채운다.

## 8. 이미 수익화 거절·정지를 당한 경우 (복구)

"재사용 콘텐츠"로 이미 거절·정지(suspension)를 받았다면, 새 영상을 잘 만드는 것과 별개로 **채널 복구 절차**가 필요하다. 이건 사용자가 "수익화 거절됐는데 어떻게 고치냐"고 물을 때 안내하는 흐름이다.

### 먼저 원인을 정확히 확인

YouTube가 보낸 이메일/Studio 알림에 **어떤 정책**인지 명시되어 있다. 스크린샷으로 보관한다 — 항소 작성 시 그 정책을 정확히 짚어야 한다. "재사용 콘텐츠(reused)"인지 "저작권 클레임(Content ID)"인지 "커뮤니티 가이드 위반"인지에 따라 대응이 다르다.

### 복구 순서 (재사용 콘텐츠 케이스)

1. **문제 영상 식별**: 변형 게이트 점검표(섹션 2)로 기존 영상을 전수 점검. 필수군 0~1개짜리(자막만 바꾼 영상 등)가 범인일 가능성이 높다.
2. **항소 vs 정리, 순서 판단**: 일반적으로 항소를 먼저 넣고, 거절되면 그때 대대적으로 정리·보강한 뒤 재신청하는 흐름을 권하는 견해가 많다. 단 명백히 문제인 영상(자막만 바꾼 재업로드)은 정리가 빠를 수 있다.
3. **기존 영상 보강 또는 삭제**: 살릴 수 있는 영상은 해설(C1)·정보(C2)·재해석(C3)을 사후에 추가(예: 인트로/아웃트로 해설 구간 삽입, 설명란·자막 보강). 살리기 어려운 단순 재업로드는 삭제.
4. **채널 방향 전환 증명**: 재심사 때 사람 리뷰어가 "이 채널은 이제 원본 가치를 더한다"고 느끼도록, 새 영상을 필수군 충실하게 올린다.
5. **대기 기간 준수**: 거절·정지 후 재신청에는 대기 기간이 있다(공식 기준상 보통 거절 후 30일, 항소 거절 후 추가 대기). 이 기간을 "같은 걸 더 올리는" 데 쓰지 말고 **포맷 자체를 개편**하는 데 쓴다.

> **불확실성 표시:** 항소 영상 제출 방법, 정확한 대기 일수(30일/90일 등), 항소 창 마감일은 시기와 케이스에 따라 다르고 비공식 출처마다 수치가 엇갈린다. **반드시 YouTube Studio의 실제 알림과 공식 정책 페이지(support.google.com/youtube)에서 본인 케이스의 정확한 절차·기한을 확인**하게 안내한다. 이 가이드의 숫자는 일반적 경향일 뿐이다.

> **핵심:** 복구의 본질은 "항소 문구를 잘 쓰는 것"이 아니라 **채널이 실제로 재사용에서 재해석으로 바뀌었음을 보여주는 것**이다. 섹션 2(영상별 게이트)와 섹션 4(채널 단위)를 둘 다 충족하는 방향으로 채널을 다시 세운다.
