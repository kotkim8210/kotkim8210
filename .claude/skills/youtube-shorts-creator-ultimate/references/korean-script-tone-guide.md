# 한국어 대본 톤 가이드 (Korean Script Tone Guide)

이 스킬의 한국어 대본은 **두 가지 톤 중 하나**를 선택해서 작성한다. 톤은 주제의 무게에 따라 결정되며, **한 영상 안에서 두 톤이 섞이면 안 된다**.

| 톤 | 적용 주제 | 핵심 어미 | 무드 키워드 |
|---|---------|--------|---------|
| **휴먼터치 음슴체** | 가벼운 주제 | ~함, ~인 듯, ~하더라, ~인 거 같음 | 친근, 옆에서 말 거는 느낌, 일상 감각 |
| **담백한 서술체** | 무거움·깊은 여운 | ~다, ~한다, ~이었다 | 진정성, 정제된 무게, 절제된 감정 |

---

## 1. 주제 무게 판별 기준

Stage 3 Step B에서 결정한 "타겟 감정"을 기준으로 판별:

### 가벼움 → 음슴체

- 일상 루틴·아침 시간 활용·작은 습관
- 사소한 깨달음·관찰·관계 팁
- 재미있는 자기관찰·MBTI·일상 농담
- 카페·산책·공부 같은 라이프스타일 묘사
- 가벼운 자기계발 (예: "5분 일찍 일어나봤더니")

### 무거움·깊은 여운 → 담백한 서술체

- 이별·후회·상실·치유
- 인생·시간·죽음·관계의 본질
- 깊은 자기긍정·자기 수용
- 부모·가족·사랑하는 사람에 대한 회상
- 묵직한 메시지가 있는 자기계발 (예: "30대가 되어서야 알게 된 것")

### 경계가 모호할 때

대부분의 쇼츠는 명확히 한쪽으로 떨어진다. 모호하다면:

1. 댓글에서 "딱 내 얘기네", "공감", "ㅋㅋ" 류가 많다 → 가벼움 → 음슴체
2. 댓글에서 "울었다", "엄마 생각났다", "치유됐다" 류가 많다 → 무거움 → 담백한 서술체
3. 그래도 모르겠다면 → 사용자에게 명시적으로 물어본다

## 2. 휴먼터치 음슴체 상세

### 무엇인가

단순히 "~함", "~임"으로 끝내는 형식적 음슴체가 아니다. **사람 냄새**가 나는, 친구가 옆에서 일기 읽어주는 듯한 음슴체.

### 핵심 어미·표현

| 어미 | 예시 | 효과 |
|-----|-----|-----|
| ~함 | "오늘 아침에 일찍 일어났음" | 기본 |
| ~인 듯 | "이게 진짜인 듯" | 확신 피하고 여운 |
| ~하더라 | "해보니까 다르더라" | 경험 공유 |
| ~인 거 같음 | "나만 그런 거 같음" | 공감 유도 |
| ~었음 | "어제 깨달았음" | 회상 |
| ~ㄴ데 | "해봤는데" | 자연스러운 흐름 연결 |
| ~ㄹ 듯 | "다 비슷할 듯" | 일반화 |

### 휴먼터치를 살리는 디테일

- **부사 적극 활용**: "그냥", "왠지", "막", "약간", "솔직히"
- **반어·자기 비하 한 스푼**: "근데 또 안 함 ㅋㅋ", "역시 작심삼일임"
- **구체적 상황 묘사**: 추상이 아니라 "오늘 아침 7시에"처럼 콕 집어서
- **감탄 짧게**: "어이없음", "신기함", "좋더라"

### 음슴체 대본 예시 (가벼움: 모닝 루틴)

```
[0~3초] 30대 되니까 아침 5분이 다르더라
[3~12초] 그냥 5분만 일찍 일어났을 뿐인데
        하루 전체가 안 쫓김
[12~40초] 처음엔 미친 짓인 줄 알았음
         근데 일주일 해보니까
         커피 마실 시간이 생기더라
         핸드폰 안 보고 창문 한 번 보는 시간
         그 5분이 진짜 컸음
[40~52초] 뭐 거창한 거 아님
         그냥 알람 5분 당기면 됨
[52~60초] 해보면 알 듯
```

### 음슴체에서 피해야 할 것

- ❌ "~합니다", "~해요" 등 존댓말 혼입
- ❌ "~인 것이다" 같은 문어체 (책 같음)
- ❌ 너무 형식적인 "~함" 남발 (영혼 없는 보고서 느낌)
- ❌ 진지한 비유·은유 과다 (음슴체와 안 맞음)

## 3. 담백한 서술체 상세

### 무엇인가

감정을 과장하지 않고 사실과 통찰을 차분하게 전달하는 서술체. **진정성이 어조의 무게에서 나오는** 글. 감성을 폭발시키지 않고 절제할 때 오히려 더 깊이 닿는다.

### 핵심 어미·표현

| 어미 | 예시 | 효과 |
|-----|-----|-----|
| ~다 | "그날도 비가 왔다" | 기본, 절제된 진술 |
| ~한다 | "나는 자주 그 길을 걷는다" | 현재 시제, 정적인 무게 |
| ~이었다 | "그게 마지막이었다" | 회상, 결정적 순간 |
| ~었다 | "오래 망설였다" | 과거의 사실 |
| ~인다 | "조용히 흐른다" | 묘사, 시적 톤 |
| ~다는 것 | "어떤 이별은 천천히 온다는 것" | 깊은 통찰의 마무리 |

### 담백한 서술체의 핵심

- **수식어 절제**: "정말", "너무", "진짜" 같은 강조 부사 거의 안 씀
- **짧은 문장**: 한 문장이 너무 길어지면 무게가 풀린다
- **여백**: 모든 걸 설명하지 않고 비워둠
- **구체에서 추상으로**: 작은 사물·장면에서 시작해 통찰로 빠짐
- **결론을 단정 짓지 않음**: 통찰을 던지고 시청자가 마무리하게

### 담백한 서술체 대본 예시 (무거움: 이별의 시간감)

```
[0~3초] 어떤 이별은, 천천히 온다
[3~12초] 그날도 우리는 평소처럼 통화를 했다
         아무 말도 다르지 않았다
[12~40초] 그런데 어느 순간부터 전화가 짧아졌다
         답장이 늦어졌다
         약속은 미뤄졌다
         이별은 한 번에 오지 않는다
         조금씩, 아주 조금씩 멀어진다
[40~52초] 끝났다고 느꼈을 땐 이미 오래 전에 끝나 있었다
[52~60초] 어떤 것은 그렇게 지나간다
```

### 담백한 서술체에서 피해야 할 것

- ❌ "정말 너무 슬프다" 같은 직설 감정 표현 (감성이 가벼워짐)
- ❌ "~인 것 같아요" 등 존댓말·구어체 혼입
- ❌ "ㅋㅋ", "ㅠㅠ" 같은 이모티콘·자모 (무게 깨짐)
- ❌ 음슴체 어미(~함, ~인 듯) 섞기
- ❌ 너무 많은 비유·은유 나열 (한 영상에 핵심 비유 1~2개로 충분)
- ❌ 결론 단정 ("그러니까 우리는 이래야 한다") — 여운으로 끝내야 함

## 4. 두 톤 비교: 같은 메시지, 다른 톤

같은 주제 "혼자 있는 시간의 가치"를 두 톤으로 써본다.

### 가벼운 버전 (음슴체)

```
혼자 있는 시간이 의외로 좋더라
처음엔 외로울 줄 알았는데
막상 해보니까 핸드폰도 잘 안 보게 됨
머릿속이 그냥 조용해짐
약속 안 잡고 집에 있는 토요일
생각보다 괜찮은 듯
```

### 무거운 버전 (담백한 서술체)

```
혼자 있는 시간은 빈 시간이 아니다
사람들 속에 있을 때는 들리지 않던 것이
혼자 있을 때 들린다
내 진짜 생각, 진짜 감정
그것들은 시끄러운 곳에서는 숨어 있다
조용함은 비어 있는 것이 아니라
가장 가까운 나와 마주하는 시간이다
```

같은 메시지지만 톤이 다르면 시청자에게 닿는 깊이가 완전히 다르다.

## 5. 톤 일관성 자가 검토 체크리스트

대본 v1을 작성한 후 다음 항목을 점검한다.

### 공통

- [ ] 대본 첫머리에 선택한 톤(음슴체 또는 담백한 서술체)이 명시되어 있는가?
- [ ] 한 톤이 처음부터 끝까지 일관되게 유지되는가?
- [ ] 존댓말("~요", "~습니다")이 섞이지 않았는가?

### 음슴체 선택 시

- [ ] 휴먼터치 디테일(부사·자기 비하·구체적 상황)이 들어 있는가?
- [ ] 형식적인 "~함"만 반복되어 영혼 없는 보고서가 되지 않았는가?
- [ ] 가벼움이 가벼움답게 끝까지 유지되었는가? (중간에 갑자기 무거워지지 않았는가)

### 담백한 서술체 선택 시

- [ ] "정말", "너무", "진짜" 같은 강조 부사를 거의 쓰지 않았는가?
- [ ] 결론을 단정 짓지 않고 여운으로 마무리했는가?
- [ ] 한 문장이 30자를 넘어가는 일이 자주 발생하지 않는가?
- [ ] 감정을 직설로 쓰지 않고 사물·장면으로 보여주고 있는가?

## 6. 일본어판과의 관계

한국어 톤이 무엇이든, **일본어판은 일본 쇼츠의 정서적 톤(여운·간접·완곡)에 맞춰 별도로 재구성**한다.

- 한국어 음슴체 → 일본어로 직역하면 「〜だ」체로 너무 무뚝뚝해짐 → 「〜だよね」「〜じゃない?」 같은 일본식 회화체로 변환
- 한국어 담백한 서술체 → 일본어로는 「〜である」「〜だ」체 + 시적 여운으로 변환 (자세한 건 `localization-jp.md` 참고)

| 한국어 톤 | 일본어 매핑 톤 |
|---------|------------|
| 휴먼터치 음슴체 | 「~だよね」「~かも」 회화체 + 여백 |
| 담백한 서술체 | 「~である」「~だ」 + 시적 여운 + 짧은 행 |

## 7. 빠른 결정 트리

```
Stage 3에서 정한 타겟 감정이 무엇인가?
│
├─ 공감·재미·일상의 작은 깨달음·동기부여 (가벼움)
│   → 휴먼터치 음슴체
│
├─ 위로·치유·깊은 통찰·이별·인생 (무거움)
│   → 담백한 서술체
│
└─ 헷갈리면 → 댓글 톤 확인
    │
    ├─ "ㅋㅋ", "공감", "딱 내 얘기" 다수
    │   → 음슴체
    │
    └─ "울었다", "치유됐다", "감동" 다수
        → 담백한 서술체
```
