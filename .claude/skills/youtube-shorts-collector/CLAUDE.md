# CLAUDE.md — YouTube Shorts 큐레이션 시스템 (수집 자동화)

> 이 파일은 Claude Code가 세션마다 자동으로 읽는 컨텍스트 앵커다. 새 세션에서도 이 파일만 읽으면 전체 맥락을 이해하고 바로 실행할 수 있게 작성됨.
>
> **설계 배경·의사결정 이유가 궁금하면 `CONTEXT.md`를 먼저 읽을 것.** (왜 이렇게 만들었는지, 새 세션이 오해하기 쉬운 지점 정리)

---

## 0. 한 줄 요약

**미국 떡상 쇼츠(Creative Commons)를 한국+일본용으로 현지화·재유통하는 2단 스킬 시스템**의 앞단(데이터 수집 자동화)이다. 이 레포는 **수집**을 담당하고, 수집 결과를 **큐레이션 스킬(youtube-shorts-creator)**에 넘긴다.

---

## 1. 전체 시스템 구조 (2개 스킬)

```
[1] youtube-shorts-collector  ← 이 레포 (Claude Code 전용)
    yt-dlp로 조회수·구독자·라이선스·댓글을 자동 수집
        │  (인수인계 마크다운 생성)
        ▼
[2] youtube-shorts-creator     ← 별도 스킬 (기획·대본·편집)
    Stage 0.5(장르 분기)부터 이어받아 대본·현지화·스토리보드·업로드정보 생성
```

- **왜 수집을 분리했나**: 일반 채팅(claude.ai)의 Claude는 유튜브 조회수·댓글을 직접 못 긁는다(JS 렌더링). Claude Code는 터미널에서 `yt-dlp`를 실행할 수 있어서 이 수집 자동화가 가능하다.
- 두 스킬은 **인수인계 마크다운**(`output/collected_*.md`)으로 연결된다.

---

## 2. 사용자 컨텍스트 (누구를 돕고 있나)

- 한국의 1인 디지털 크리에이터. 쇼츠를 **직접 0→1 제작하는 게 아니라**, 검증된 CC 영상을 **한·일 현지화해 재유통**하는 큐레이터 포지션.
- 편집 도구는 **캡컷(CapCut)**. 새 영상 소스를 찾지 않고 **원본 1개를 재편집**한다.
- 부가가치는 **현지화 + 미세한 휴먼터치 대본**에서 나온다.
- 한국어로 소통. 결과물 설명·코멘트는 한국어, 일본어 대본은 일본어 그대로.
- 간결·직설·표 중심 커뮤니케이션 선호. 군더더기 인사말 생략.

---

## 3. 이 레포로 무엇을 하나 (수집기 역할)

`yt-dlp` 기반으로 다음을 자동 수집:

- ✅ 조회수 / 채널 구독자 수 / 좋아요 / 업로드일 / 영상 길이
- ✅ 라이선스 (Creative Commons 여부 판정)
- ✅ **인기 댓글 (좋아요순 정렬)** — 큐레이션 Stage 3 주제 결정의 핵심 재료
- ✅ V/S 비율(조회수÷구독자) 자동 계산
- ✅ CC 필터 검색으로 후보 URL 발굴

→ 결과를 `output/`에 JSON + 인수인계 마크다운으로 저장.

### 실행법 (자세히는 SKILL.md)

```bash
# 최초 1회: 의존성 설치 (setup.md 참고)
pip install -U yt-dlp

# 검색 모드: CC 필터로 후보 발굴 + 상위 8개 상세 수집
python scripts/collect.py --query "#piano #shorts" --min-views 5000000 --top 8

# 시드 모드: 사용자가 URL 직접 줄 때
python scripts/collect.py --urls "URL1" "URL2" "URL3"
```

생성된 `output/collected_*.md`를 큐레이션 스킬 **Stage 0.5**로 넘긴다.

---

## 4. 큐레이션 스킬(youtube-shorts-creator)의 핵심 — 수집 결과를 어디에 쓰나

수집이 끝나면 큐레이션 스킬로 넘어간다. 그 스킬의 파이프라인:

| Stage | 이름 | 수집 데이터 활용 |
|-------|------|--------------|
| 0 | 떡상 영상 탐색 | **이 수집기가 대체** (V/S·조회수·CC 이미 확보) |
| 0.5 | **장르 분기** | 유형 힌트(M/P)를 확정 |
| 1 | 성공요인 분석 | 영상 구조·후킹 분해 |
| 2 | 팩트체크 | Type M만. Type P는 곡명·작가명만 확인 |
| 3 | **댓글→주제 결정** | **수집한 인기 댓글**로 주제·후킹 결정 |
| 4 | 대본 작성 | 한국어(음슴체/담백체)+일본어, 후킹 라이브러리 활용 |
| 5 | 검토+일본어 자가리뷰 | 일본어 9개 항목 강제 리뷰 |
| 6 | 스토리보드 | 캡컷 확대 지시 |
| 7 | 업로드 정보 | **수집한 원본 채널·설명**으로 CC BY 크레딧 작성 |

---

## 5. 반드시 지킬 원칙 (LOCKED — 시스템 전체)

1. **Creative Commons 필수** — CC 아니면 재유통 불가, 즉시 제외
2. **CC BY 크레딧 의무** — 업로드 설명란에 원저작자·원URL·라이선스 명시 (안 하면 위반)
3. **임베디드 저작권 주의** — 영상 속 배경음악·삽입물이 제3자 것이면 CC여도 침해. BGM은 무료 음원 교체, 음악은 클래식·자작곡 위주
4. **검색 결과 ≠ 떡상** — 노출 순위는 인기와 무관. 실제 조회수·댓글 데이터로만 판정 (이 수집기가 그 데이터를 제공)
5. **장르 분기** — Type M(메시지형: 라이프스타일·자기계발·철학) / Type P(퍼포먼스형: 음악·미술). 유형에 따라 팩트체크·대본·보이스오버가 달라짐
   - Type P는 원본 연주음 유지, 나레이션 없음, 자막 5~7줄, 팩트체크 스킵
6. **댓글 기반 주제 결정** — 인기 댓글에서 공감 폭발 지점을 찾아 주제·후킹·메타데이터에 일관 반영
7. **한국어 톤 이원화** — 가벼움=휴먼터치 음슴체(~함/~하더라), 무거움=담백한 서술체(~다/~한다). 한 영상에 한 톤
8. **일본어=재작성+강제 자가리뷰** — 번역 아님. Claude가 일본인 시청자 입장 9개 항목 리뷰 후 v2 (사용자가 일본어 어색함 판별 불가하므로 필수)
9. **캡컷 확대(Zoom) 4용도** — 임팩트/현지화(영문·미국요소 가리기)/디테일/전환
10. **원테이크 우선** — 컷 적은 원본이 재편집·확대에 유리. 음악·미술이 원테이크에 최적

---

## 6. 수집기의 한계 (사람이 채워야 할 것)

- **배경음악 저작권**: yt-dlp가 라이선스는 알려줘도, 영상 안 BGM이 상업 음원인지는 판단 못 함 → 사람이 확인
- **댓글 정렬**: 'top' 정렬 후 like_count로 재정렬하지만 유튜브 API 특성상 완벽하진 않음
- **유형 분류**: 카테고리·태그로 M/P 힌트만 줌. 확정은 Stage 0.5에서 사람이
- **연령제한·비공개 영상**: 수집 실패할 수 있음 → 에러 메시지 확인 후 다른 영상

---

## 7. 새 세션 시작 시 행동 지침

1. 사용자가 "쇼츠 수집" 또는 URL·해시태그를 주면 → `scripts/collect.py` 실행
2. 결과 `output/collected_*.md`를 사용자에게 요약 제시
3. 사용자가 후보 1개 선택하면 → 큐레이션 스킬 흐름(Stage 0.5~7) 안내
4. 큐레이션 스킬 파일이 이 레포에 없으면, 사용자에게 youtube-shorts-creator 스킬을 함께 로드하도록 안내
5. 항상 **§5 LOCKED 원칙** 준수. 특히 CC 크레딧·저작권·일본어 자가리뷰는 생략 금지
