# CONTEXT.md — 이 시스템이 만들어진 배경과 결정들

> CLAUDE.md가 "무엇을·어떻게"라면, 이 파일은 "왜"다. 새 세션이 설계 의도를 이해해 엉뚱한 방향으로 안 가게 하는 배경 브리핑. (원 대화: claude.ai에서 스킬을 함께 설계·테스트한 세션)

---

## 1. 어쩌다 이걸 만들게 됐나 (여정)

1. 사용자가 skill-creator로 **YouTube 쇼츠 큐레이션 스킬**을 만들기 시작
2. 처음엔 "미국 떡상 쇼츠를 한·일 현지화"라는 큰 그림 → 요구가 점점 구체화됨:
   - 원테이크 영상 위주 (요즘 쇼츠 트렌드)
   - 캡컷 편집 기준: 거창한 B-roll 시스템 ❌ → **원본의 어느 구간을 확대할지**만 알려주기
   - 유통자 포지션 (0→1 제작자 아님)
   - 한국어 톤 이원화 (가벼움=음슴체 / 무거움=담백체)
   - 댓글 인기순으로 주제 결정
   - Creative Commons만, 시간 제한 없이 조회수 1000만+ 우선
   - 음악(#piano 등)·미술(#painting) 장르 추가
   - 일본어 자가 리뷰 (사용자가 일본어 어색함 판별 불가)
   - 캡컷 템플릿 추천 기능
3. 실제 큐레이션을 테스트하다가 **결정적 한계**를 발견:
   - 일반 채팅 Claude는 유튜브 조회수·구독자·댓글을 **직접 못 긁는다** (JS 렌더링)
   - 검색 결과 상위 ≠ 떡상 영상 (실제로 댓글 0·좋아요 1 영상이 상위에 잡힘)
   - YouTube CC 필터 URL도 직접 호출 불가
4. 그래서 스킬을 **v2로 업그레이드**: 장르 분기, 후킹 라이브러리, CC BY 크레딧 의무, 도구 한계 명시
5. 그래도 "URL 찾고 댓글 복사"가 수동이라 번거로움 → **이 수집 자동화 레포(Claude Code 전용)**를 분리 제작. yt-dlp로 데이터를 긁어 큐레이션 스킬에 넘김.

## 2. 핵심 설계 결정과 그 이유 (재론 금지)

| 결정 | 왜 |
|-----|---|
| 수집을 Claude Code로 분리 | 일반 채팅은 yt-dlp 실행 불가. 터미널만 가능 |
| 유통자 포지션 | 0→1 제작보다 검증된 CC 영상 현지화가 효율적. 부가가치=현지화+휴먼터치 |
| 원본 1개 재편집 (새 풋티지 검색 안 함) | 캡컷에서 확대·재배열로 충분. 소스 찾기가 비효율 |
| CC만 + 크레딧 의무 | 합법 재유통 대전제. CC BY는 저작자 표시 안 하면 위반 |
| 조회수 절대값 중시 (1~2년 전 OK) | 오래됐어도 조회수 크면 검증된 콘텐츠 + 한·일엔 미노출 골든 케이스 |
| 장르 분기 (M/P) | 음악·미술에 "통찰 30초+보이스오버" 구조는 안 맞음. 완전히 다른 대본 필요 |
| 댓글 기반 주제 결정 | 시청자가 어디에 반응했는지가 정답. 추측보다 데이터 |
| 한국어 톤 이원화 | 가벼운 주제와 무거운 주제는 어미·무드가 근본적으로 달라야 함 |
| 일본어 강제 자가 리뷰 | 사용자가 일본어를 몰라 어색함을 못 잡음. Claude가 유일한 안전장치 |
| 검색결과 ≠ 떡상 (추측 금지) | 노출은 SEO·해시태그로 결정. 실제 데이터 없이 "추천" 금지 |

## 3. 두 스킬의 역할 분담

- **youtube-shorts-collector (이 레포)**: 데이터 수집. "무엇이 실제로 떡상했나"를 yt-dlp로 팩트 확보
- **youtube-shorts-creator (별도)**: 그 데이터로 기획·대본·현지화·편집 지시 생성

수집기는 **판단하지 않는다** — 사실(조회수·댓글·라이선스)만 모아 넘긴다. 창작·현지화 판단은 큐레이션 스킬에서.

---

## 4. 새 세션이 흔히 오해할 만한 것 (미리 방지)

- ❌ "검색으로 떡상 영상을 골라줘" → 검색 노출은 인기와 무관. 반드시 조회수·댓글 데이터로 (수집기가 제공)
- ❌ 음악·미술 영상에 긴 대본·보이스오버 → Type P는 최소 자막, 원본 연주음 유지
- ❌ CC라서 그냥 재업로드 → 크레딧 필수 + 배경음악 저작권 별도 확인
- ❌ 일본어 대본을 번역으로 처리 → 재작성 + 자가 리뷰 필수
- ❌ 새 영상 소스를 잔뜩 찾기 → 원본 1개 재편집이 원칙
