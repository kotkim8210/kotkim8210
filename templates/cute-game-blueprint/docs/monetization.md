# Monetization — 〔게임 이름〕 (포털 광고)

> v1은 포털 광고만. 인앱 결제·구독·서버 없음.

## 1. SDK 이벤트 (어댑터가 감싼다 — 본 코드는 어댑터만 호출)
| 이벤트 | 호출 시점 |
|---|---|
| `init()` | 부트 1회 |
| `loadingStart()/loadingStop()` | 스플래시 시작/끝 |
| `gameplayStart()/gameplayStop()` | 판 시작/끝 + 일시정지 진입/해제 |
| `happytime()` | 〔최고 순간 3곳만. 예: 시그니처 폭발·퍼펙트·신기록〕 — 남발 금지 |

## 2. 광고 지점 (유저 흐름을 깨지 않는 위치만)
- **인터스티셜**: 게임오버 **2회당 1회**, 반드시 결과 화면이 뜬 **후**에만. 판 도중 금지.
- **리워드**: ① 게임오버 부활 1회 ② 〔예: 데일리 재도전 1회〕. 골드 버튼은 화면당 1개만(옵트인 희석 방지).
- 광고 전 `gameplayStop()`, 후 `gameplayStart()` 짝 맞춤.

## 3. 빌드 분기
- `VITE_ADS=off`(기본): 콘솔 로그 + 즉시 콜백 — 개발·테스트용.
- `VITE_ADS=〔포털명〕`: SDK 삽입 지점 주석 처리해 두고, 실제 스니펫 부착은 포털 승인 후 발주자가 결정.

## 4. 심사 체크
- 광고 없이도 게임 전체 플레이 가능해야 함(리워드는 보너스일 뿐).
- 외부 요청 0 원칙과 충돌 금지 — SDK는 포털이 iframe 밖에서 주입.
