# UI Spec — 〔게임 이름〕 귀여움 스타일 가이드

> "귀여움"을 취향이 아니라 **검수 가능한 규칙**으로 만든 문서. 구현은 전부 이 토큰을 참조한다.

## 1. 무드 방향 (하나 선택 후 나머지 삭제)
- **A. 파스텔 키치**: 크림 배경 + 파스텔 조각 + 진한 초콜릿색 텍스트. 예시 팔레트는 §2.
- **B. 코스믹 큐트**(Block Nova 계열): 다크 남색 + 보석 조각 + 골드 포인트. 밤하늘 감성.
- **C. 캔디 팝**: 화이트 배경 + 채도 높은 캔디색 + 두꺼운 라운드 테두리.
- 결정: 〔선택 + 한 줄 이유. 타깃이 "밝고 아기자기"면 A/C, "세련+귀여움"이면 B〕

## 2. 디자인 토큰 (CSS 변수로 고정 — 임의 색 사용 금지)
```css
@theme {
  --color-bg:      〔예: #FFF7EE  /* 크림 */〕;
  --color-panel:   〔예: #FFFFFF 〕;
  --color-ink:     〔예: #5B4A43  /* 초코 브라운 — 검정 금지, 부드럽게 */〕;
  --color-dim:     〔예: #A79A92 〕;
  --color-accent:  〔예: #FF9EC3  /* 시그니처 핑크 */〕;

  /* 조각 색 6종 — 파스텔이어도 서로 대비 확보 (명도 차이 검증 필수) */
```

## 3. 형태 언어
- 모든 모서리 라운드(토큰만 사용), 조각에는 **윗면 하이라이트 점**(사탕 광택).
- **색+무늬 이중 코딩**: 조각 색마다 마이크로 글리프 1종(하트·발도장·눈·별·점 2개·리본 등 귀여운 무늬).
  → 색약 유저도 무늬만으로 구분 가능 + 귀여움 상승. (필수, Phase 1부터)
- 그림자는 부드럽고 짧게. 날카로운 각·금속 질감·네온 원색 금지.

## 4. 마스코트 & 감정 레이어
- 마스코트: 〔예: 보드 옆 슬라임 1마리 — idle 숨쉬기, 콤보 시 환호, 게임오버 시 시무룩→응원〕
- 표정 상태 최소 3종: 평상 / 기쁨(콤보·클리어) / 아쉬움(게임오버) — 이모지 금지, 자체 드로잉(SVG/픽셀).
- 빈 상태 규칙: 게임오버·일시정지·로딩 화면에 반드시 표정+한 줄 메시지+마이크로 모션이 있어야 한다.
- 응원 카피 톤: 짧고 다정하게. 〔예: "아깝다! 한 판이면 넘어요!" / "오늘도 왔네요, 반가워요!"〕

## 5. 주스 팩 (전 항목 필수 — Phase 2 수용 기준)
| 순간 | 연출 | 사운드 |
|---|---|---|
| 배치 | 스쿼시&스트레치(0.92→1.05→1, 120ms) | 낮은 팝 |
| 클리어 | 셀 파티클(예산 ≤24) + 밝아지는 플래시 | 상승 아르페지오 |
| 콤보 | 칭찬 문구 사다리 〔예: 좋아요!→굉장해요!→멈출 수 없어!→최고!!〕 | 콤보당 피치업(반음씩, 상한 12) |
| 점수 | 카운트업 트윈 + 플로팅 "+N" | — |
| 신기록 | 콘페티 + 골드 플래시 | 팡파르 |
| 시그니처 트위스트 | 〔전용 연출 — 게임 최고의 3초〕 | 〔전용 사운드〕 + happytime() |
| 터치 | 햅틱 15ms(지원 기기) | — |

- 모든 연출은 transform/opacity만. `prefers-reduced-motion` 시 대체(정적 표시) 필수.
- 저사양 자동 감지 시 파티클 절반, blur 해제.

## 6. UI 원칙 & 금지 목록
- 터치 타깃 **≥44px**, 버튼은 크고 문구는 짧게(≤2어절), 눌림 효과(scale 0.96) 필수.
- 안내는 말풍선 톤(꼬리 달린 툴팁), 시스템 알림처럼 차가운 사각 배너 금지.
- 화면당 정보 덩어리 ≤3개(HUD/보드/트레이). 380px 폭에서 스크롤 0.
- **금지**: 텍스트 과밀, 원색 나열, 모달 중첩, 색만으로 상태 구분, 3초 안에 이해 안 되는 첫 화면.

## 7. 화면 목록 (와이어프레임과 1:1)

③ 게임오버 시트(근접실패 응원 포함) ④ 〔수집/도감〕 ⑤ 〔데일리〕 ⑥ 통계/설정
