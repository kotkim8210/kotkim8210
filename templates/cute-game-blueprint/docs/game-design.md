# Game Design — 〔게임 이름〕 (GDD)

> 이 문서가 규칙의 단일 진실 공급원. 여기 적힌 판정 케이스가 곧 vitest 수용 기준이 된다.

## 1. 보드·요소
- 보드: 〔예: 9×9 그리드 / 6열 버블 필드〕
- 조각/요소: 〔종류 수·모양 정의. 데이터는 `data/*.json`으로 분리〕
- 생성 규칙: 〔예: 가중치 뽑기, 직전 조합 반복 금지, 항상 배치 가능한 조각 1개 보장〕

## 2. 조작
- 〔예: 트레이에서 드래그해 보드에 배치 / 탭-탭(선택→배치) / 키보드 커서〕
- 미리보기: 배치 가능 위치 = 〔예: 초록 고스트〕, 불가 = 〔예: 빨간 표시 + 짧은 흔들림〕

## 3. 판정 (vitest 케이스 — Phase 1 수용 기준)
정확히 3케이스를 명시한다. 예(Block Nova):
① 〔예: 8칸 찬 행에 마지막 조각 → 9셀 제거〕
② 〔예: 행+열 동시 완성, 교차 셀은 1회만 제거 → 17셀〕
③ 〔예: 남은 조각 전부 배치 불가 → 게임오버〕

## 4. 점수
- 기본: 〔예: 배치 = 셀 수 ×1, 클리어 = 줄당 10 × 동시배수(1줄×1 / 2줄×2.5 / 3줄+×4)〕
- 콤보: 〔예: 연속 클리어 +1, 무클리어 배치 시 0, 클리어 점수 ×(1+콤보×0.5)〕
- 퍼펙트(전부 비움): 〔예: +1000 + happytime〕

## 5. 시그니처 트위스트 (게임의 정체성 — 반드시 1개)
〔예: "노바 게이지" — 클리어 셀 수만큼 충전, 만충 후 다음 클리어 시 폭발: 추가 제거 + 그 턴 점수 ×3 + 전용 연출 + happytime. 이 게임에서는: …〕

## 6. 난이도 (DDA)
- 〔예: 초반 200점까지는 쉬운 조각 가중치 상향, 이후 표준 분포〕
- 저사양/연패 배려: 〔예: 3연속 게임오버 시 시작 보드 완화〕

## 7. 첫 실행 후킹 — 골든 퍼스트 무브 (Phase 2 수용 기준)
- 프리셋 상황: 〔예: 1수에 더블 클리어가 나오는 보드 + 게이지 50% 선충전〕
- 코치마크 ≤3개: 비주얼 중심, 스킵 가능, 실제 게임플레이 안에서 진행(별도 튜토리얼 화면 금지)
- 목표: 첫 30초 안에 "우와" 순간 1회 보장

## 8. 리텐션 시스템 (Phase 3)
- **스트릭**: 일 단위 연속 플레이, 7일마다 실드 1개(최대 2), 결손일 자동 소모
- **레벨/XP/랭크**: L1은 30% 선충전 상태로 시작(제로 스타트 금지), 랭크명은 테마에 맞게 〔예: 새싹→…〕
- **주간 퀘스트 3종**: ISO 주 번호 시드로 결정적 생성(같은 주엔 모두 같은 퀘스트), 진행 바 마지막 10% 글로우
- **수집 요소**: 〔예: 플레이 누적으로 마스코트 도감이 한 칸씩 공개(픽셀아트 리빌)〕
- **근접실패 게임오버**: "Best까지 −N" + 〔예: 다음 조각 3개 공개〕 + 베스트의 15% 이내면 특수 응원 카피
- **데일리 챌린지**: 날짜 시드 결정적 〔예: 50조각 고정 세트, 별점 1~3, 리워드 광고로 1회 재도전〕

## 9. 저장 (localStorage, 접두사 `〔예: bp:〕`)
| 키 | 내용 |
|---|---|
| `best` | 모드별 최고점 |
| `flags` | firstRunDone, mute, fx(auto/lite) |
| `streak` | current, max, lastDay, shields |
| `meta` | xp, level |
| `quests` | week, progress[3], done[3] |
| `stats` | games, totalScore, … |
| 〔수집〕 | 〔예: pets: cells〕 |

모든 접근은 try/catch 가드(샌드박스 iframe에서 localStorage가 throw할 수 있음).

## 10. vitest 목록 (최소)
- §3 판정 3케이스 + 게임오버
- 생성 규칙(가중치 빈도·조합 금지·배치 가능 보장)
- 점수·콤보 계산식
- XP 임계 함수, 주간 퀘스트 시드 결정성
- 골든 퍼스트 무브 프리셋 성립(1수 성공 보장)
