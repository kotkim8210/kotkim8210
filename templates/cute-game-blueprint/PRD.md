# PRD — 〔게임 이름〕 (한 장 요약)

## 1. 무엇을 만드는가
- **장르**: 〔예: 8×8 블록 매칭 퍼즐 / 머지 퍼즐 / 팝 슈터〕
- **한 문장 정의**: 〔"조각을 끌어다 놓아 줄을 지우는, 3초 만에 이해되는 귀여운 퍼즐"처럼 — 처음 본 사람이 3초 안에 이해할 문장〕
- **플랫폼**: 웹(모바일 브라우저 + 데스크톱), 〔포털명. 예: CrazyGames〕 제출
- **세션 길이 목표**: 1판 〔예: 2~4분〕, 하루 〔예: 3판 이상〕 재방문 유도

## 2. 누구를 위해
- **타깃**: 〔예: 귀엽고 아기자기한 감성을 중시하는 20~40대 캐주얼 유저, 짧은 휴식 시간에 플레이〕
- 타깃이 중요하게 여기는 것: **첫인상(귀여움) → 즉시 이해 → 조작 쾌감 → 수집/기록 욕구** 순.
- 하지 말 것: 복잡한 튜토리얼, 계정 가입, 과한 팝업.

## 3. 왜 이기는가 (차별점)
- **시그니처 트위스트**: 〔이 게임만의 정체성 1가지. 예: 게이지가 차면 화면 전체 폭발 — Block Nova의 "노바"에 해당하는 한 방〕
- **귀여움 축**: 〔마스코트/테마 콘셉트. 예: 디저트 왕국 슬라임들〕
- 벤치마크: 〔예: Block Blast!(색감·피드백), Woodoku(규칙 명료함)〕 — 베끼지 말고 "색 사용·피드백 방식·버튼 톤"만 참고.

## 4. 성공 지표 (출시 후 확인)
- 첫 세션 완주율(첫 게임오버까지 도달) 〔예: ≥ 70%〕
- 재방문(다음날) 〔예: ≥ 20%〕
- 평균 세션 〔예: ≥ 5분〕
- 포털 심사: 1회 통과

## 5. 범위
- **v1 포함**: 코어 룰, 입력 3종, 점수/베스트, 첫 실행 후킹, 주스 팩, 스트릭/퀘스트/수집, 광고 어댑터
- **v1 제외(비범위)**: 계정/서버 저장, 멀티플레이, 푸시 알림, 인앱 결제, 3D
- 제약: 백엔드 금지 · 외부 요청 0 · 번들 ≤ 2MB

## 6. 리스크
- 〔예: 장르 포화 — 시그니처 트위스트와 귀여움 축으로 차별화〕
- IP: 기존 게임과 이름·아이콘·규칙 혼동 금지(낙하식 테트로미노 클론 금지)
- 〔기타〕
