# 플롯 아웃라인 + 연재 로그 — 「죽은 헌터의 유언을 집행합니다」

## 전체 구조 (3부)
- **1부 「검성의 유언」 (1~100화)**: 백무혁 살해 사건의 진상 규명. 적: 제천길드 서일국 → 배후 협회 이사장 염제강. 클라이맥스: 무혁의 완전 상속과 성불, 서린이 진실을 손에 쥠. 마지막 문장에서 '서초 게이트' 재개방 예고.
- **2부 「수확자들」 (101~230화)**: 게이트=수확 장치라는 세계의 진실. 시스템이 한겸을 '오류: 집행인'으로 인식, 회랑과의 전면전. 손목시계 봉인 해방(코어 각성). 염제강의 재평가(볼모였던 자).
- **3부 「서초, 열리다」 (231~최종)**: 은폐된 서초 게이트. 부모의 마지막 유언 대면. 수확 시스템의 주인과의 결전. 주제 회수: '떠나보내는 일'의 완성.

## 아크 설계 원칙
- 1아크 = 죽은 헌터 1인의 유언 집행(8~15화). 매 아크: 사연(눈물) + 집행(사이다) + 장기 떡밥 전진 1칸.
- 유언 집행이 곧 파워업(상속)이므로 **스토리 진행 = 성장**이 기계적으로 동기화된다. (AI 강점: 아크 템플릿 반복에 강함)

## 화별 상세 (A1: 1~7화) — 집필 + 2차 구조 편집 완료분
- **001 「S급의 유품」**: 게이트 내부 수습 콜드오픈 → 시신 인도 + 유족(박정후 아내)에게 반지·정산 이관 약속(F17 씨앗) → 사무실(곽두철 1세대 복선: 단체 사진·쇠지팡이) → 백무혁 유품 낙찰(F02) → 백야 접촉 → 목소리. 절단A: 시스템 최초 기동.
- **002 「유언 청취」**: 무혁 잔영 첫 대화 → 모순된 유언(F01) → 상속 안내는 1~3항+유류분만 공개(4항은 5화로 이동) → 일섬 가상속, "어깨부터" 첫 등장 → 절단B: 침입자.
- **003 「회수팀」**: 제천 회수팀 3인 → 강파식의 하청 협박(고구마) → **전투: 승리 아님** — C급 1인 기습 성공 후 제압당함(갈비·손목 부상), 봉인 경보로 3분 벌어 철수 유도. 강파식이 궤적을 목격(F18). 출동반의 '관리 부주의' 종결(협회 불신 질감) → 수정구 발견 → 절단A: "이 게이트는… 비어 있다."(F12)
- **004 「비어 있는 게이트」**: 영상 분석(공략 일지 축약) + 공격대 40인을 물린 이유의 기억 봉인(F15) → 서린 등장·대치 → 무예서 메모 교류(F14 환기) → 무혁 침묵(F04) → 절단C: 백야 공명(F03)
- **005 「집행 조건」**: 조건 1 산정(증거와 함께 전달) → 서린 임시 보관 동의서 서명(+제1보고 조건 — 7화 질책의 근거) → 반출 → **박정후 유언 청취·집행·첫 성불(F17 회수)**: 정산 확정+반지 인도+전언, 보상 [버팀—하급]. 무혁의 『저렇게 가는 건가』 → 곽 "또냐"(F05) + 포기 고민 순간 4항 공개 → 문자 비트 → 절단A: 이사장 전결(F06)
- **006 「사망 등급 F」**: 밤샘 규정 준비 → 규정전: 하자 5건 인정받았으나 **차도윤의 43조 긴급 봉인 반격 — 이틀 유예만 획득, 유품 못 박힘** → 밤, 제3세력 방화(무혁: "셋째 패거리") → 곽두철 '철벽' 공개(1화 복선 회수) → 일섬 첫 완성+과부하 각혈, 시계 발열(F11 환기) → 절단B: 문양(F07)=8년 전 그 문양(F08)
- **007 「여덟 해 전」**: 문양 회상(0.5p) → 도윤의 재해 조항 지원(조력 씨앗) → 반찬통 생활 비트 → 서린의 질책 = **한겸의 결함(독단) 첫 대가 자각** → 무혁 "협회 안에 놈들의 귀" → 절단A: "서초 게이트는 아직 닫히지 않았다."(F10). ※대기열(F09)·40분 단서(F16)는 8화로 이월.

## 8~15화 (A2) 초안 메모
- **008 「대기열」 ✅집필 완료**: 무혁의 서초 근거 공개(미열 관측·좌천 관측관 F19, 소문 수준으로 한계 명시) → 수신 범위 확장·대기열 2건(F09) + '희망' 내면 문단 재사용 → 한겸의 '먼저 보고' 실천(결함 성장 1단계 조기 착수, 전화 못 끊는 티키타카) + 서린의 40분 단서(F16, 반쪽 증거) + 도윤의 사적 수사 전언 → 유민재 어머니 의뢰(청람길드의 유품 압류) → 절단A: 유민재 유언 활성화("유품 접촉 시 청취 개시" = 유품 회수가 선결 퀘스트).
- 9화: 유품 회수 교섭 — 청람 방문. 대여금 계약서의 하자 찾기(임시 계약 정산 조항 취소선 = 근로 서면 미비) + 길드의 벽. 유품 일부(하급 장비)만 회수 → 첫 청취(파편적): "엄마… 김치냉장고…" 절단.
- 10화: 유민재 사망 경위의 진상 접근 = 미끼 운용 정황(같은 조 생존자의 증언 거부) → 분노 축적. 유민재 잔영 첫 형성(또렷한 편 — 젊은 미련), 며칠 동행 개시.
- 11~12화: 정산금·유품 반환 소송전(도윤의 규정 지식 합류 계기 — 8화 사적 수사와 접선) + 제천 회수팀 2차 압박(강파식, F18 진전). 서린 '먼저 보고' 루틴은 8화에 조기 착수했으므로 여기서는 **서린이 한겸에게 먼저 기대는 역방향 비트**로 발전시킬 것.
- 13~14화: 소액이지만 완전한 승리(김치냉장고 할부 완제) → **관계가 쌓인 첫 대형 집행·성불** = 정서 코어 증폭 회차(박정후 5화가 '조용한 증명'이었다면 여기는 '정면 승부'). 유민재 퇴장 대사 확정: "형, 우리 엄마 김치… 맛있는데. 한 번은 얻어먹지 그랬어요."
- 15화: 상속 완료 보상(신속 보법) 시연 + A3 훅(오갑수 선배의 부고).
