# 플롯 아웃라인 + 연재 로그 — 「죽은 헌터의 유언을 집행합니다」

## 전체 구조 (3부)
- **1부 「검성의 유언」 (1~100화)**: 백무혁 살해 사건의 진상 규명. 적: 제천길드 서일국 → 배후 협회 이사장 염제강. 클라이맥스: 무혁의 완전 상속과 성불, 서린이 진실을 손에 쥠. 마지막 문장에서 '서초 게이트' 재개방 예고.
- **2부 「수확자들」 (101~230화)**: 게이트=수확 장치라는 세계의 진실. 시스템이 한겸을 '오류: 집행인'으로 인식, 회랑과의 전면전. 손목시계 봉인 해방(코어 각성). 염제강의 재평가(볼모였던 자).
- **3부 「서초, 열리다」 (231~최종)**: 은폐된 서초 게이트. 부모의 마지막 유언 대면. 수확 시스템의 주인과의 결전. 주제 회수: '떠나보내는 일'의 완성.

## 아크 설계 원칙
- 1아크 = 죽은 헌터 1인의 유언 집행(8~15화). 매 아크: 사연(눈물) + 집행(사이다) + 장기 떡밥 전진 1칸.
- 유언 집행이 곧 파워업(상속)이므로 **스토리 진행 = 성장**이 기계적으로 동기화된다. (AI 강점: 아크 템플릿 반복에 강함)

## 화별 상세 (A1: 1~7화) — 집필 완료분
- **001 「S급의 유품」**: D급 게이트 앞 시신 인도(직업·세계관·태도 소개) → 국가급 의뢰: 백무혁 유품 정리 낙찰(대형 업체 전부 사퇴 F02) → 서재에서 부러진 검 '백야' 접촉 → 목소리. 절단A: 시스템 최초 기동.
- **002 「유언 청취」**: 무혁 잔영과 첫 대화(티키타카 개시) → 모순된 유언(F01) → 상속 시스템 설명, 일섬 가상속 → 절단B: 서재 침입자.
- **003 「회수팀」**: 제천 회수팀 3인 무단 진입(합법 가장) → 무혁 코칭 + 환경 이용으로 제압(첫 사이다, 개연성: 기습+협소 공간+상대 방심) → 그들이 찾던 것 = 기록 수정구 → 절단A: 영상 속 무혁 "이 게이트는… 비어 있다."(F12)
- **004 「비어 있는 게이트」**: 영상 분석(단독 클리어의 진상 의혹) → 백서린 등장, 유품 도둑 오해로 대치 → 무혁, 동생 앞에서 침묵(F04) → 절단C: 백야가 한겸의 손에서 공명 — "오빠 검이 왜 당신한테 반응하죠?"(F03)
- **005 「집행 조건」**: 반신뢰 동맹(팩트만 교환) → 시스템, 집행 조건 1 고지: "진상을 증거와 함께 백서린에게 전달하라" → 곽두철, 수정구 보고 "…또냐."(F05) → 절단A: 협회 압류 통보서의 직인 = 이사장 전결(F06)
- **006 「사망 등급 F」**: 차도윤과 규정 대결 — 한겸이 유품관리규정·상조사법으로 역공(전투 없는 사이다) → 밤, 사무실 방화 습격 → 곽 사장의 1세대 실력 편린 + 한겸 일섬 첫 실전 발동(과부하 각혈로 한계 명시) → 절단B+정보: 습격자 목의 문양(F07) = 8년 전 부모 장례식장의 그 문양(F08)
- **007 「여덟 해 전」**: 습격 뒷수습, 문양 회상(0.5p) → 무혁이 서초 게이트를 캐물음 → 시스템: 대기 중인 유언 2건(F09) → 절단A(대형): 무혁 "서초 게이트는 아직 닫히지 않았다."(F10)

## 8~15화 (A2) 초안 메모 — 다음 세션용
- 8화: 7화 절단 직후 — 무혁이 아는 것의 한계 명시(그도 소문+정황만, 전지적 해설자 방지). 유민재 유품 의뢰 접수(일상 톤 전환, 리듬 조절).
- 9~10화: 유민재의 게이트 사망 경위 = 길드의 미끼 운용(신참 착취 고발 코드) → 분노 축적.
- 11~12화: 정산금 소송전 준비(도윤의 규정 지식 합류 계기) + 제천 회수팀 2차 압박.
- 13~14화: 소액이지만 완전한 승리(김치냉장고 할부 완제) → **첫 완전 상속 + 첫 성불 연출** = 시리즈의 정서 코어 확립 회차. 유민재 잔영 퇴장 대사 확정해둘 것: "형, 우리 엄마 김치… 맛있는데. 한 번은 얻어먹지 그랬어요."
- 15화: 상속 완료 보상(신속 보법) 시연 + A3 훅(오갑수 선배의 부고).
