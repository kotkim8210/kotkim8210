# 플롯 아웃라인 + 연재 로그 — 「죽은 헌터의 유언을 집행합니다」

## 전체 구조 (3부) — 3차 편집에서 1부 단축(100→85화): 핵심 감정 보상(성불)을 뒤로 미루지 않는다
- **1부 「검성의 유언」 (1~85화)**: 백무혁 살해 사건. 진상 전달(44~55) → 실행자 처벌(56~75) → **완전 상속·성불(76~85)** + 서초 재개방 예고. "증거 찾기 반복" 체감 방지를 위해 각 구간마다 상대가 잃는 것을 명확히(회수팀장→부길드장→이사장 순 도미노).
- **2부 「수확자들」 (86~200화 내외)**: 게이트=수확 장치라는 세계의 진실. 시스템이 한겸을 '오류: 집행인'으로 인식, 회랑과의 전면전. 손목시계 봉인 해방(코어 각성). 염제강의 재평가(볼모였던 자).
- **3부 「서초, 열리다」 (201~최종)**: 은폐된 서초 게이트. 부모의 마지막 유언 대면. 수확 시스템의 주인과의 결전. 주제 회수: '떠나보내는 일'의 완성.

## 아크 설계 원칙
- 1아크 = 죽은 헌터 1인의 유언 집행(8~15화). 매 아크: 사연(눈물) + 집행(사이다) + 장기 떡밥 전진 1칸.
- 유언 집행이 곧 파워업(상속)이므로 **스토리 진행 = 성장**이 기계적으로 동기화된다. (AI 강점: 아크 템플릿 반복에 강함)
- **집행 방식 다양화(3차 편집 등재)**: 법률·서류전은 A1~A2까지만 주력으로. A3부터 로테이션 — ①위험 게이트 현장 수습형 ②고인이 숨긴 물건 추적형 ③유언 대상자가 수령을 거부하는 형 ④유언 자체가 도덕적으로 모순인 형 ⑤두 고인의 유언이 충돌하는 형.
- **고인 유형 다양화(3차 편집 등재)**: '착하고 억울한 피해자'(박정후·유민재) 연속 금지. 이후 필수 배치 — 듣기 싫은 악인의 유언 / 잘못된 유언(오해·거짓 포함) / 유족이 고인을 미워하는 사건 / 집행하면 산 자가 다치는 유언 / 능력은 탐나지만 조건을 받아들이기 힘든 유언. A3 오갑수부터 적용: 그는 순수 피해자가 아니라 **무언가를 숨긴 채 죽은 선배** — 유언이 '부탁'이 아니라 '사죄'인 첫 사례로 설계.
- **곽두철 만능 방지 제약**: 전투력은 있으나 지속 불가(옛 부상) / 과거 이력 때문에 협회에 직접 못 나섬 / 아는 것을 전부 말하지 못하는 이유(서약)가 있음 / 한겸 대신 문제를 해결해 주지 않는다.

## 화별 상세 (A1: 1~7화) — 집필 + 2차 구조 편집 완료분
- **001 「S급의 유품」**: 게이트 내부 수습 콜드오픈 → 시신 인도 + 유족(박정후 아내)에게 반지·정산 이관 약속(F17 씨앗) → 사무실(곽두철 1세대 복선: 단체 사진·쇠지팡이) → 백무혁 유품 낙찰(F02) → 백야 접촉 → 목소리. 절단A: 시스템 최초 기동.
- **002 「유언 청취」**: 무혁 잔영 첫 대화 → 모순된 유언(F01) → 상속 안내는 1~3항+유류분만 공개(4항은 5화로 이동) → 일섬 가상속, "어깨부터" 첫 등장 → 절단B: 침입자.
- **003 「회수팀」**: 제천 회수팀 3인 → 강파식의 하청 협박(고구마) → **전투: 승리 아님** — C급 1인 기습 성공 후 제압당함(갈비·손목 부상), 봉인 경보로 3분 벌어 철수 유도. 강파식이 궤적을 목격(F18). 출동반의 '관리 부주의' 종결(협회 불신 질감) → 수정구 발견 → 절단A: "이 게이트는… 비어 있다."(F12)
- **004 「비어 있는 게이트」**: 영상 분석(공략 일지 축약) + 공격대 40인을 물린 이유의 기억 봉인(F15) → 서린 등장·대치 → 무예서 메모 교류(F14 환기) → 무혁 침묵(F04) → 절단C: 백야 공명(F03)
- **005 「집행 조건」** (3차 편집 반영): 조건 1 산정 → 서린 동의서(+제1보고 조건) → 반출 → **박정후 유언 청취·집행·첫 성불(F17 회수)** → 곽 "또냐"(F05) + 4항 공개 → 문자 비트 → 절단C(신규): 보관고의 무혁 『부러운 죽음이군』 — 성불 여운 보존, 압류 팩스는 6화로 이월.
- **006 「사망 등급 F」** (3차 편집 반영): 오프닝 = 압류 팩스·이사장 전결(F06) → 밤샘 규정 준비 → 규정전: 하자 5건 인정받았으나 **차도윤의 43조 긴급 봉인 반격 — 이틀 유예만 획득, 유품 못 박힘** → 밤, 제3세력 방화(무혁: "셋째 패거리") → 곽두철 '철벽' 공개(1화 복선 회수) → 일섬 첫 완성+과부하 각혈, 시계 발열(F11 환기) → 절단B: 문양(F07)=8년 전 그 문양(F08)
- **007 「여덟 해 전」**: 문양 회상(0.5p) → 도윤의 재해 조항 지원(조력 씨앗) → 반찬통 생활 비트 → 서린의 질책 = **한겸의 결함(독단) 첫 대가 자각** → 무혁 "협회 안에 놈들의 귀" → 절단A: "서초 게이트는 아직 닫히지 않았다."(F10). ※대기열(F09)·40분 단서(F16)는 8화로 이월.

## 8~15화 (A2) 초안 메모
- **008 「대기열」 ✅집필 완료**: 무혁의 서초 근거 공개(미열 관측·좌천 관측관 F19, 소문 수준으로 한계 명시) → 수신 범위 확장·대기열 2건(F09) + '희망' 내면 문단 재사용 → 한겸의 '먼저 보고' 실천(결함 성장 1단계 조기 착수, 전화 못 끊는 티키타카) + 서린의 40분 단서(F16, 반쪽 증거) + 도윤의 사적 수사 전언 → 유민재 어머니 의뢰(청람길드의 유품 압류) → 절단A: 유민재 유언 활성화("유품 접촉 시 청취 개시" = 유품 회수가 선결 퀘스트).
- **009 「사라진 창」 ✅집필 완료**: 청람 교섭 — 표재만의 서류 벽(변호사 6, 녹취 주장)에 정면 돌파 실패 → 목록 대조라는 직업 기술로 개인 물품만 부분 회수(완승 금지 원칙) + 반환 확인서 독소 문구 적발 → '지급 창' 서류 모순 발견(협회=회수 vs 청람=분실, F20 심음) → 파편 청취("엄마… 김치냉장고… 할부…")와 파편 규칙 확립 → 절단C: 오금자의 전화 "뭐라도 남겼나요?" — 토씨 원칙 때문에 말할 수 없는 한겸. ※버팀 스킬의 일상 사용(계단), 서린 "21시 30분 통화" 예약이 10화 오프닝 고리.
- **010 「스물일곱 분」 ✅집필 완료**: 서린 통화 오픈(운행 일지 팁, "배웠군. 끊는 법을") → 열람: 후위 단독 배치 + 본대 철수~붕괴 27분 = 미끼 운용의 서류 물증. 무혁 『버틴 게 아니라 버려진 거다』 → 서기웅(26, 면허 반납) 문전박대 — 문 앞에서 파편이 '옆방처럼' 선명해짐 + "가요, 형" → 밤, 거리 규칙 역산 → 절단A: "창은, 그 반지하에 있습니다."
- **011 「김치」 ✅집필 완료**: 오금자의 김치통("아줌마가 한 번 보자더라")이 문을 여는 설득 — 취조 아닌 벽 옆자리 → 서기웅의 자백(27분의 진상: 부러진 검, 쥐여 준 창, "가요, 형", 입구에서 흔든 손) + 반출 서명 경위 + 표재만의 입막음(대여금 협박 — 12화 소송 탄약) → 창 인도(서류보다 사람 먼저) → 절단A: 완전 청취 첫마디 "─형." — 유언의 1순위 수신인이 엄마가 아니라 서기웅이라는 반전.
- **012 「먼저 갈게요」 ✅집필 완료**: 유언 전문(2단 — "형이라서 다행이었어요" / "김치냉장고 할부…" / "나 먼저 갈게요") → 조건 산정(①1단 원문 전달 ②정산금으로 할부 완제=소송이 곧 집행) → 조건 1 즉시 이행: 서기웅의 '나 때문에'를 죽은 애가 직접 지움 → 잔영 형성(너스레·검성 팬, 무혁과 세대차 케미) → 계란 일화 회수(라면 밥상) → 곽 사장 결재(사훈 액자 회수: "마지막 길에 등급은 없다") → 서린 역방향 문자("상의", "당신한테 먼저") → 절단B: 청람의 채권 양도 내용증명 — 증인 압박. 유민재 『우리 형, 건드린대요?』
- **013 「반격」 ✅집필 완료**: 도윤 합류(취소선·도장 양식이 제천 건과 '같은 법무 대행사' — F21 등재, 예산 초과 사유 기록) → 표재만 2라운드: 지급 확약+감찰 취하 조건 → 한겸 "지급은 의무, 감찰은 감찰대로" — 표재만이 제 손으로 조건 조항에 취소선(모티프 반전), 퇴장 대사 "서류엔 임자가 따로 있다"(F21) → 서린 회동: 사인 재감정 청구 전략(A4 진입로) + "오빠 목소리가 기억 안 나요"(F04 환기, 3미터의 침묵) → 지급 확정 + 서기웅이 먼저 오금자에게 전화(성장) → 절단C: 인도실 대면 직전, 유민재 『나 지금, 되게 떨려요.』
- **014 「따뜻한 방」 ✅집필 완료 (A2 클라이맥스)**: 대면 — 오금자가 먼저 손을 잡고 "밥은 먹고 다녀?"(등 두드리기 = 11화 관계 이식) → 유품 초상(스티커 8장·목장갑) → 유언 공식 전달 → 그 자리 폰뱅킹 완제(서기웅의 첫 형 노릇) → 성불: 각자 작별 + 저승 수소문 약속(F22) → 실제 퇴장 대사 "가끔 얻어먹어 줘요…" + "나 먼저 가요. 이번엔 진짜."(유언 인사 자기 회수) → 보상 [잰걸음—중급: 27분간 증명한 보법] → 온풍기 회수("방이 참 따뜻하네요") → 절단C(소프트): 무혁 『내 차례가 오면—』 삼켜진 부탁.
- **015 「장부」 ✅집필 완료 — A2 완결**: 백반집(계란 계승·서기웅 학원 등록·유민재 빈자리) → 잰걸음 첫 시연(D급 여진, "순서가 반대였다" — 힘=버릇=사람) → 여진 정리(표재만 대기발령·대행사 조사 확대=F21 전진, 재감정 접수=A4 개시 신호, 서린 "인사 안 하는 게 인사") → **유언 집행인의 개인 장부**(박정후 完/유민재 完, 무혁 『다음 줄은 내 차례겠군』=A7 예열) → 절단A: 오갑수 부고 — 안방에서 수습 장갑을 낀 채("그건 준비한 거다"). **A2 완결 = 연재 개시 조건 충족.**
