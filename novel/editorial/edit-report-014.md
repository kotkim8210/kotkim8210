# 편집 리포트 #014 — 1~36화 루즈함·철학 과잉 전수 점검

> ⚠ **역사 기록.** 이 리포트는 작성 시점의 판단·수치를 보존한다. **현재 캐논과 충돌하면 `bible/`(세계관·플롯 아웃라인)이 우선한다.** 특히 자수·회차 범위·이후 수정된 설정은 최신 플롯 아웃라인을 확인할 것.


- 편집일: 2026-08-03 / 트리거: 사용자 지시 — "너무 루즈해진 부분은 없는지" + "쓸데없이 철학적인 부분이 너무 치중되어 있지는 않은지"
- 방법: 체감이 아니라 **계측**. 화별 ①대사 비율 ②최장 서술 문단 ③120자 초과 문단 수 ④장면 수/장면당 자수 ⑤일반론 단정 패턴 정규식 스캔.

## 1. 결론 먼저
**이 원고의 최대 루즈함은 철학이 아니었다.** 철학성 문장은 실제로 12건뿐이었고, 진짜 범인은 **서술자가 인물에게 계속 라벨을 붙이는 습관**이었다.

## 2. 최대 결함 — "규정의 사람" 11회 반복
차도윤이 무언가를 할 때마다 서술자가 *"규정의 사람은 ~했다"*로 정리하고 있었다. 독자는 6화쯤에 이미 도윤이 어떤 사람인지 안다. 그 뒤 9회는 전부 **정보 0, 속도 -1**이다.

| 화 | 원문 | 처치 |
|---|---|---|
| 007 | "규정의 사람은 이럴 때 빨랐다" | **유지** — 첫 확립 |
| 008 | "규정의 사람이 규정 밖의 냄새를 맡기 시작했다는 뜻" | **유지** — 적·아군 판별이라는 기능 |
| 021 | "도윤이 규정의 사람답게 단서를 달았다" | → "도윤이 단서를 달았다" |
| 027 | "규정의 사람은 증거를 받을 때도 규정의 격식을 갖췄다" | **삭제** — 앞 문장(녹음기·접수 대장·인장)이 이미 다 보여 준다 |
| 027 | "규정의 사람은 커피를 한 모금…" | → "도윤은 커피를…" |
| 030 | "규정의 사람은 협박도 도면으로 이해했다" | → "네모와 네모, 그리고 화살표 하나."(사물로 대체) |
| 030 | "규정의 사람은 닫힌 문을 오래 붙들고 있지 않았다" | → 인물 묘사로 전환("닫힌 문을 오래 붙들지는 않는데, 언제 닫혔는지는 정확히 기억하는 얼굴") |
| 030 | "이길 수 없는 판에서도 종이 한 장을 남겨 두는 방식으로 싸웠다…" | **삭제** — 바로 뒤 한겸의 반응이 같은 일을 한다 |
| 031 | "규정의 사람은 반쯤 읽은 규정을 남기지 않았다" | → "끝까지 읽었다."만 |
| 031 | "규정의 사람이 규정 때문에 곤란해하는 목소리" | **유지** — 유일한 아이러니 용례 |
| 036 | "규정의 사람이 규정 밖의 배려를 하려고 할 때 나오는…" | → "반 박자의 멈춤이었다." |

**11회 → 3회.** 남긴 셋은 확립 1 · 기능 1 · 아이러니 1이다.

## 3. 철학 과잉 — 실측 결과
정규식 50건 적발 중 오탐 38건을 걷어내고, **실질 잠언 12건**을 판정했다.

**삭제·압축 6건**
| 화 | 문장 | 사유 |
|---|---|---|
| 015 | "먹어 주는 사람이 있어야 맛있어진다던 말은, 김치 말고도 다 맞는 말이었다" | 유민재의 대사를 **인생론으로 확대**. "맛있었다."에서 끊는 게 백배 강하다 |
| 017 | "벽에 금이 가는 소리는, 못 들은 척해 줘야 더 벌어지는 법이다" | 잠언 → 한겸의 경험으로 강등("이 집에서 삼 년 배웠다") |
| 021 | "비슷한 종류의 사람들은 서로를 알아보는 데 오래 걸리지 않는다" | 두 사람이 **웃는 장면이 이미 그걸 보여 줬다** |
| 016 | "이십 년 게이트 곁에서 산 사람은 죽음의 규칙에도 밝았다" | 직전 대사가 이미 증명 |
| 025 | "…알았을까. …알았을까." | **사색형 2연속 의문문.** 사실 한 문장으로 압축 |
| 023 | "말할 수 없는 죽은 사람은, 절을 받는 것으로…" | 서술자 정리 → 행동만 남김 |

**유지 6건 (기능 있음)**
- 004 *"이상한 것은 과정에 묻혀 있는 법이다"* — 짧고, 되감기 행동에 붙은 추리 리듬
- 006 *"밤에 우는 팩스는 대개 흉보다"* — 한 줄 분위기 조성, 다음 사건 예고
- 014 *"이 나라의 어른들은 슬픔 앞에서 밥부터 물었다"* — 일반론이지만 **장면 밀착 문화 관찰**, 오금자의 행동과 붙어 있음
- 033 *"새벽에 오는 답은 대개 사람이 직접 온다"* — 도윤 도착 예고라는 **기능**
- 035 *"죽은 사람은 더 나빠지지 않는다. 산 사람만 더 나빠진다"* — 안심을 불안으로 뒤집는 **긴장 유발형**
- 007·008·031 규정의 사람 3회

## 4. 문단 비대 — 001 도입부 168자
1화 사장실 단체 사진 문단이 **168자 한 덩어리**였다. 도입부는 이탈률이 가장 높은 구간이라 분할했다(사진 사실 / 묻지 않게 된 이유). 정보 손실 0, 호흡 2박자 확보.

## 6. 수치
16개소 수정. 삭제 총량 약 430자(전 화 유료 표준·무료 대역 모두 유지). **전체 36화 135,971자.**

## 7. 재발 방지 — style-guide 반영
`§7-1` 서술자 금지 3종에 **4번째 항목 추가**: **인물 라벨 반복 금지.**
> 같은 인물을 같은 수식으로 두 번 이상 정리하지 않는다("규정의 사람은…", "유품정리사의 눈으로…"). 캐릭터는 **행동으로 반복**되지, 서술로 반복되지 않는다. 3회 이상 발견 시 첫 1회만 남기고 전량 삭제.
