## 2. 증량 시 추가된 비트 (물타기 아님을 확인)
- 1화: 게이트 내부 수습 콜드오픈(직업 정체성+긴장) / 서재 목록 작업 확장 — 무혁의 사람됨을 유품으로 간접 빌드(사진 뒷면 글씨, 무예서 메모 = 신규 떡밥 F14)
- 2화: 무혁의 '세간 반응' 문답(성격·제천 복선) / 상속 4항 '미집행 영구 보존' 조항(한겸이 거부할 수 없는 정서적 이유) / "어깨부터" 첫 등장(3화 콜백 성립)
- 3화: 강파식의 하청 끊기 협박(고구마 적립·세계 질감) / 입회관의 공포(협회 불신 학습) / 수정구 앞 무혁 심경
- 4화: 흑요 진입부 영상(검성 전성기 시전 — 웹툰 각) + 공격대 40인을 물린 이유 봉인(신규 떡밥 F15) / 서린-무예서 메모 콜백(1화 회수 고리)
- 5화: 증거 확보 견적 회의(A4~6 로드맵 자연 예고) / 서린 문자 비트(냉온 리듬·케미)
- 6화: 밤샘 규정집 준비(사이다 개연성) / 곽두철 1세대 레전드 한 줄 / '멈추는 선을 고르는' 내면(불살 원칙 = 캐릭터 각인)
- 7화: 뒷수습 장면("물건이 아니라 돌아갈 곳") / 서린 탐문 — 회수팀 40분 전 도착(신규 떡밥 F16) / '희망이라는 건 무서운 물건' 내면(주제 명중)

## 3. AI티 점검 결과 (style-guide 체크리스트)
- 동일 어미 3연속: 미검출 ✓ / '마치·왠지·형용할 수 없는': 0회 ✓ / '그때(였다)' 계열: 화당 최대 1회 ✓
- 감정 직접 서술: 전량 신체 반응·행동으로 치환됨 ✓ (예: 서린의 떨리는 손끝, 한겸의 낮아지는 목소리)
- 시점 오류: 미검출 ✓ (무혁의 전지성은 '기억 봉인' 규칙으로 차단 — 해설자化 방지 장치 작동 확인)
- 반복 명사: 4화 '못 본 척했다' 2회 — 의도적 콜백('이번에도')으로 성립 판정, 유지

## 4. 상업성 평가 (냉정하게)
**강점**
- 1화 첫 문장 후킹("죽은 지 사흘 된 헌터의 몸에서는 쇠 냄새가 난다") + 1화 내 능력 발현 = 시장 규칙 준수
- 매화 절단 성립: 1A→2B→3A→4C→5A→6B→7A (유형 연속 3회 없음, 매뉴얼 준수)
- 사이다 배치: 3화(전투) / 6화(규정전) — 서로 다른 종류의 승리로 단조로움 회피
- 차별 포인트 안착: 법률 문체 시스템창, 죽은 자 존대, 묵례, 성불 예고(2화 4항) — '눈물+사이다' 이중 코어의 기초 완성
- 떡밥 16개 전부 장부 등록·회수 계획 존재 — 장기 연재 신뢰 구조 확보

**약점 (다음 세션 처리 지시)**
1. **분량**: 최종 평균 3,355자/화. 자유연재 통용 범위지만 유료화 기준(4,500~5,500) 미달. → 유료 전환 전 2차 증량 필수. 우선순위: 7화(2,976) > 6화(3,117) > 5화(3,285). 추가 비트 후보: 7화 서린-도윤 첫 조우, 6화 살수 전투의 곽두철 시점 컷, 5화 압류 공문의 법적 의미 해설 강화.
2. **여성 조연 등장 시점**: 서린 4화 등장은 남성향 기준 적정선이나, 2~3화가 남성 캐스트만으로 진행 — 웹툰화 대비 시각 밸런스는 A2에서 보완.
3. **적 실체 노출 속도**: 7화까지 '문양'만 노출 — 의도된 페이스지만 10화 전후로 중간 보스(강파식 재등장)를 세워 단기 타격감을 줄 것.
4. **유민재 아크(A2)가 성패 분수령**: 첫 완전 상속+성불 = 작품의 정서 코어 증명 회차. 8~15화에 최우선 품질 투입.
