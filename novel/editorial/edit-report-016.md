# 편집 리포트 #016 — 훈훈함 계측과 배치 (§12 신설)

- 편집일: 2026-08-03 / 트리거: 사용자 지시 — "독자가 훈훈한 장면, 따뜻함 감정을 느끼는 장면들도 중간중간에"
- ※ 루즈함·철학 과잉 점검은 **리포트 #014에서 완료**("규정의 사람" 11→3회, 실질 잠언 6건 삭제, 1화 도입부 문단 분할). 본 리포트는 신규 요청분만 다룬다.

## 1. 진단 — 온기도 15화에서 말랐다
유머와 **똑같은 패턴**이었다. 밥·물건·손의 온기가 A2(11~15화)에 몰려 있고, A3 오갑수 아크부터 급감.
- 훈훈 비트 0인 화 **19개**. 특히 **016~021 · 024~025 · 028~029 · 033~034 · 036**이 비었다.
- 원인 동일: **오금자·서기웅·유민재**라는 '따뜻한 사람들'이 A2에서 퇴장하고, 이후 등장인물이 전부 **직업인·수사관·노인**으로 채워졌다.

## 2. 규칙 등재 — `style-guide §12`
- **3~4화에 최소 1회, 4연속 0 금지**
- **이 작품의 훈훈함은 밥·물건·손으로 온다.** 먹이는 것 / 챙기는 물건 / 말없는 손 / 자리를 내주는 것
- **감정 명명 금지** — "따뜻했다" "고마웠다"로 쓰지 않는다. 행동으로만
- **최강 자산 = 떠난 사람들의 후일담** (아크당 1회, 과소비 금지)
- 배치 금지: 위기 한복판·절단 직전 / 사망 직후 3장면 / **훈훈함으로 갈등을 봉합하지 않는다**

## 3. 신규 배치 3건
| 화 | 내용 | 설계 |
|---|---|---|
| **017 발인** | 우산이 셋인데 사람이 여섯이다. 유 실장이 배정하고 자기는 우비 모자. *"막내는 상주 옆에 서야 하잖아요. 젖은 사람이 상주 옆에 서면 유족이 미안해합니다."* → 한겸이 우산을 반쯤 기울이고, 유 실장은 밀어내지 않는다. **둘 다 어깨 한쪽씩 젖은 채로 관을 배웅** | 저밀도 회차(#004 지침)에 온기를 채웠다. **예의가 곧 다정함**인 이 작품의 문법 그대로 |
| **028 성불 직후** | 유 실장이 아무도 안 시켰는데 **곰탕**을 시킨다. 방 기사 *"뭐 좋은 일 있냐."* / *"안 좋은 일 있었잖아요."* / *"…그러네."* 남정록이 내려와 **넷째 자리**에 앉고, 아무도 뭐라 하지 않는다 | 17화 화투판 '넷째 자리'의 회수. **회사에 사람이 하나 늘었다**는 사실만 남기고 감정 명명은 안 함 |
| **034 조사 회차** | **오금자의 김치 택배.** 수취인이 *'이문상조 한겸 씨(민재 형님)'*. 쪽지 — *"기웅이가 학원 다니느라 바쁜데, 이번 달에는 지가 먼저 전화를 했어요. 밥은 먹고 다니냐고. 그 소리를 지 입으로 하더라고. / 우리 민재 김치는 원래 두 통씩 담갔어요. 혼자 먹으면 안 익는다고."* | **최강 자산 가동.** 독자가 정든 두 사람이 잘 살고 있다 = 14화 집행의 결과 증명. A4 한복판, 독자가 가장 지친 지점에 배치. 냉장고 자리 실랑이로 웃음까지 겸함 |

## 4. 왜 이 셋인가
- 034는 **A4 조사 3연속의 한복판** — 지침이 지목한 '독자가 지칠 때'.
- 028은 **성불 회차에 온기가 0이었다.** 사람이 떠난 자리를 산 사람들이 채우는 장면이 없으면 성불이 손실로만 남는다.
- 017은 **의도적 저밀도 회차**라 온기를 넣을 여유가 유일하게 있는 자리였다.
- **금지 구간 준수**: 020(전투)·033(습격)·036(위령비 = 유족·고인 앞)에는 넣지 않았다.
