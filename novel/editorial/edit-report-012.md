# 편집 리포트 #012 — 지침 2건 신설 + 34~36화 집필 및 **자동 자가검수 1회차**

- 편집일: 2026-08-03 / 트리거: 사용자 지시 2건(①가독성 최우선 ②집필 후 자동 자가검수) + A4 추적 3부작 집필
- 성격: 외부 리뷰 대응이 아니라 **자체 발견·자체 수정**. `README §0-C`가 요구하는 자동 검수의 첫 실행 기록.

## 1. 신설 지침 2건

### 1-1. 가독성 최우선 (`style-guide §9`, `README §0-B`)
> **"무조건 술술 읽히는 맛이 있어야 한다."** — 취향이 아니라 상업 웹소설의 생사 조건.

우선순위를 명문화했다: **①다음 화를 보게 만드는 힘 → ②인물의 생동감 → ③주제·여운.** ③이 ①을 방해하면 **③을 버린다.**
- **주제는 아크당 1~2화 농축.** 매 화 철학 금지, 매 화 여운 금지.
- 즉시 잘라야 할 6가지: 사색 문단 / 잠언 / 좌표 설명 / 논쟁 늘이기(대사 6~8합 초과) / 같은 감정 두 번 / 결론 문단.
- 잘라 낸 자리는 **정보·위협·관계 변화·물리적 사건**으로 채운다. 판정 기준 = *"이 문단을 지우면 다음 화가 덜 궁금해지는가?"*

**원인 제거가 핵심이었다.** `theme-ethics §7`의 **"이 화에 질문이 있는가"** 항목이 매 화 철학 투여를 **구조적으로 강제**하고 있었다. 그 항목을 폐기하고, 체크리스트 전체를 §9에 종속시켰다 — *"항목을 채우려다 이야기가 멈추면, 항목을 버리고 이야기를 굴린다."*

### 1-2. 집필 후 자동 자가검수 (`README §0-C`)
회차를 다 쓰면 **요청 없이 즉시** 편집자 모드로 전환해 5단계를 돌린다: §9 가독성 → §7 정돈 방지 → §8 4대+1 스윕 → 잔여 체크리스트 → 절단·분량·장부. 적발 0건이어도 기록한다.

## 3. 증량은 전부 '사건'으로 (§9-4 준수 — 사색·설명 0자 추가)

|---|---|---|

## 4. 34~36화 설계 요지
- **034 「제출 시각」**(4,588) — 인과 역전. 사직서가 습격보다 **6시간 20분 빨랐다.** 한겸의 결정적 추론: *"안 올 사람이 왜 열 시라고 못을 박습니까."*
- **035 「등기」**(4,248) — *"새벽에 한 말은 취소합니다."* 같은 밤에 반환을 요구한 입과 봉투를 부친 손. 두 번째 봉투 = **딸에게, 만 25세**(F29). 금고 접촉 시 **시스템 무반응 = 생존 확인**(직업이 곧 생사 판별기).
- **036 「위령비」**(4,290) — 인도 거절하되 **조건 문서는 보여 준다**(선택권 반환). 명세연의 반격 *"저한테 한 번이라도 물어봤냐고요"* = 32화 한겸 대사의 딸 버전. **8년 전 서초 사망확인서 서명자 = 명순영**(봉인 나흘 뒤 '생존 가능성 없음'). 그리고 그녀는 **여덟 해 동안 매달 그 위령비에 왔다**(F30).

주제(알 권리 vs 알고 싶지 않을 권리)는 **036 한 장면에만** 집중 배치했고, 034·035는 사건으로만 굴렸다 — §9-2 아크 예산 준수.
