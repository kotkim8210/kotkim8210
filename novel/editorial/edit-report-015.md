# 편집 리포트 #015 — 톤 완급 점검: '피식' 지점 계측과 배치

> ⚠ **역사 기록.** 이 리포트는 작성 시점의 판단·수치를 보존한다. **현재 캐논과 충돌하면 `bible/`(세계관·플롯 아웃라인)이 우선한다.** 특히 자수·회차 범위·이후 수정된 설정은 최신 플롯 아웃라인을 확인할 것.


- 편집일: 2026-08-03 / 트리거: 사용자 지시 — "너무 어둡지만은 않게, 지루함을 느낄 때쯤 기분 좋게 웃을 수 있는 코믹 요소"
- 방법: 화별 웃음 표현 정규식 스캔 + **'웃지 않는 웃음' 분리 판정**.

## 1. 진단 — 유머 자산이 15화에서 끊겼다
| 구간 | 상태 |
|---|---|
| 1~14화 | 화당 1~5건. **유민재 잔영**(야구모자·검성 팬·너스레)이 웃음을 전담 |
| **15화 유민재 성불 이후** | **급감.** 16~36화 평균 1건 이하 |
| 남은 '웃음' 표현의 정체 | **8건이 "웃음을 부정하는 웃음"** — *"눈은 웃지 않았다" / "웃음소리가 아니었다" / "농담의 형식이었지만 농담이 아니었다" / "웃는 근육이 오래 안 쓴 티"*. 이건 유머가 아니라 **어둠을 강화하는 장치**다 |

**웃음 0인 화 10개**, 그중 유료 구간이 029·031·035. 코믹 캐릭터가 죽으면서 톤 조절 장치가 함께 사라진 것이 원인이다.

## 2. 규칙 등재 — `style-guide §11` 완급('피식') 설계
- **화당 진짜 웃음 1개 이상**(무거운 회차 0 허용, **3연속 0 금지**)
- **"웃지 않는 웃음"은 유머 카운트에서 제외**
- 배치 적지: 위기 직전 / 긴 조사 회차 초반 / 사무실·차 안·대기실 / 정보 폭탄 직후 3줄
- **절대 금지**: 유족·고인 앞, 시신 수습 중, 성불 장면과 그 직후, 사죄·고백 회차(23~25화), 누가 죽은 직후
  > 이 작품의 예의가 곧 품격이다. **웃음이 예의를 이기면 작품이 싸진다.**
- 담당 자산표 신설: 유 실장(건조한 독설·과잉 실무) / 곽두철(능청·화투) / **무혁(죽은 랭킹 1위의 자존심)** / 도윤(규정충) / 남정록(숫자 강박) / 서린(직설·서툰 손) / **방 기사(미개발 — 과묵한데 준비물이 이상함)**
  > **한겸은 웃기는 쪽이 아니라 받아치는 쪽.** 그의 유머는 정색한 직업 유머(견적·목록·규정)로만.
- 금지: 슬랩스틱 / 인물을 바보로 만들기 / 절단을 흐리는 유머 / 같은 개그 3회 반복

## 3. 신규 배치 4건 — 전부 유료 구간 또는 조사 회차
| 화 | 자산 | 내용 | 왜 여기인가 |
|---|---|---|---|
| **029** | 무혁 | 엘리베이터에서 직원들이 **검성 추모 다큐**를 품평한다("배우가 좀 안 닮지 않았냐"). 본인이 옆에 서 있다. 무혁의 항의는 연기력이 아니라 **책장 순서**다 — *"검술서가 왼쪽, 지리지가 오른쪽이다. 저건 반대로 해 놨어."* / 한겸 *"민원 넣으시겠습니까."* / *"죽은 사람은 민원을 못 낸다."* | 재감정이라는 **가장 무거운 장면 직전**. 낙차 확보 |
| **031** | 도윤 | 자판기가 컵 없이 커피만 쏟는다. 서린이 옆구리를 쳐서 고친다. 도윤 *"협회 기물입니다."* → 사진 찍고 시설관리팀에 접수. **기일 시작 18분 전** | 참관석 압박이 시작되기 직전 |
| **034** | 무혁 | 오갑수 성불 후 **혼자 남은 검성이 심심하다.** *"요즘 자네, 나한테 말을 잘 안 거는군."* / *"…질투하십니까."* / *"검성은 질투 안 한다."* / *"……화투는 칠 줄 아나."* | 조사 3연속의 첫 화. §11-2가 지목한 최적지. **웃기면서 동시에 아픈** 비트 |
| **035** | 유 실장 + 방 기사 | 개봉 입회 준비물이 과하다(예비 볼펜, 장갑 3켤레, **코팅한 유의사항 A4**). 곽 *"쟤가 원래 저래. 우리 회사 소화기 점검표도 쟤가 만들었다."* / 도윤 *"소화기 점검표는 법정 서식이 있습니다만."* / *"그것도 쟤가 고쳤어."* — 그리고 밤, **방 기사가 당직에 접이식 낚싯대를 들고 온다**("펴 놓고 보는 거야") | 등기 개봉이라는 정적 회차. 미개발 자산 2종 동시 가동 |

## 4. 지표의 한계 (기록)
추가한 4건은 **정규식에 잡히지 않는다.** 웃음·농담 같은 단어 없이 웃기는 **건조한 유머**이기 때문이다. 이 작품의 유머는 원래 그 결이므로, §11의 계측은 **자동 카운트가 아니라 수동 판정**으로 운용한다.
- 현재 최장 무웃음 연속 = **3화(023·024·025)** — 사죄·고백 회차로 **§11-2 금지 구간**에 해당. 정당.
- 잔여 무유머: 027(후반 감찰과)·033(습격)·036(위령비) — 셋 다 금지 구간 또는 준하는 긴급·유족 장면이라 **의도적 유지**.
