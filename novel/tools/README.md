# 집필 파이프라인 도구

`publish.sh` 하나가 계측 → 문서 빌드 → 뷰어 빌드 → **게이트 14종 검증**까지 돌린다.
게이트가 하나라도 걸리면 `❌ 검증 실패 — 배포 금지`로 끝난다.

```
bash novel/tools/publish.sh
```

경로는 실행 위치에서 자동으로 잡는다(`NOVEL_ROOT` = 저장소 루트, 스크립트 위치 기준).
산출물 디렉터리만 세션 스크래치패드를 기본값으로 쓰므로, 다른 환경에서는 지정한다.

```
NOVEL_OUT=/원하는/출력경로 bash novel/tools/publish.sh
```

⚠ **도구의 단일 출처는 이 디렉터리다.** 스크래치패드에 사본을 두지 않는다 —
두 벌이 되는 순간 어느 쪽이 진짜인지 모르게 되고, 그게 게이트 ⑪을 만든 사고의 원인이었다.

| 파일 | 역할 |
|---|---|
| `measure.py` | 회차별 자수·대화%·최장 서술·경구·웃음·훈훈 + **문체 게이트**(§13-1 파편 / §13-2 계사 3연속) + 경고열(반복*·체언·단문·**정지**) + 화수 메타 정규식 가드 |
| `build_downloads.py` | 원고 합본 MD/PDF, 제작문서 합본 MD/PDF 생성. 회차 범위·파일명·표지 자수·리포트 목록·떡밥 집계를 **전부 파일에서 자동 판독** |
| `build_viewer.py` | 원고 + 제작문서 통합 HTML 뷰어 |
| `publish.sh` | 위 셋을 순서대로 돌리고 산출물을 역검증 |

## 게이트 14종

1. 원고 표지 자수 · 2. 원고 표지 회차 · 3. 제작문서 STATUS 자수
4. 활성 플롯에 최신 회차 요약 반영 · 5. `bible/state.md`의 `<!-- 최종 반영: NNN -->`
6. 享年 값이 캐릭터 바이블과 일치 · 7. 폐기 문구 잔재(`bible/`) + **원고 금지 표기**(`manuscript/` 전 회차) — `editorial/`은 역사 기록이라 제외
8. 어미 규칙 · 9. 유료 분량 4,200~5,500자(030~) · 10. 활성 플롯 회차별 자수
11. 편집 리포트 전량이 제작문서 본문에 수록 · 12. 편집 리포트 헤더의 회차 자수
13. 사이다 장부 회차 수록 + 보상 간격(소승 3화 / 대리만족 6화 / 응징 10화)
14. 화면 호흡 — 장면 구분선 ⁂ 25개 이하

## 설계 원칙

> **사람이 숫자를 적는 자리를 없앤다. 없앨 수 없는 자리(서사 상태)는 틀리면 배포가 멈추게 한다.**

게이트를 늘려 온 것은 전부 **실제로 한 번씩 틀렸기 때문**이다.
게이트 ⑪은 표지의 리포트 범위가 glob 자동인데 본문 목록이 하드코딩이라
**리포트 #026이 통째로 빠졌던 사고**(28차 검수) 뒤에 만들었고, 동시에
하드코딩 목록 자체를 없앴다.
게이트 ⑫는 원고를 690자 늘려 놓고 **리포트 첫 줄만 구판 자수로 남은 사고**(29차 검수) 뒤에 만들었다.
게이트 ⑩이 강제하는 연재 로그는 고쳤는데, 게이트가 없는 리포트 헤더는 그대로였다 —
**게이트가 없는 자리의 숫자는 반드시 어긋난다**는 것이 다시 증명됐다.

게이트 ⑬은 *"다음 화가 궁금한가"* 만 관리하고 *"이번 화 읽어서 기분이 좋은가"* 는 관리하지 않는다는
지적(31차 검수) 뒤에 만들었다. **등급 판정은 사람이 하고 게이트는 산술만 본다** —
문학적 판단을 정규식에 맡기지 않으면서도 *"몇 화째 아무도 안 시원했는가"* 는 숫자로 막을 수 있다.

⚠ 새 게이트는 **틀린 값을 일부러 넣어 실제로 걸리는지 역검증**한 뒤에만 채택한다.
⚠ `editorial/`을 훑는 게이트는 **인용문 오탐**을 조심한다(⑪ 초안이 리포트 #022의 옛 표지 인용에 걸렸다).
⑫가 쓰는 ``novel/manuscript/NNN.md` (N,NNN자`` 표기는 리포트 **헤더 전용**이라 안전하다.

⚠ 문체는 게이트 2종(파편·계사)만 0건 강제하고, 나머지 3종(반복\*·체언·단문)은
**경고만** 한다. 전부 막으면 'AI식 반복' 대신 'AI식 장문'이 생긴다(21·22차 검수).

## 복구 절차 (컨테이너 리셋 시)

```
git fetch origin <branch> && git reset --hard origin/<branch>
pip install reportlab
apt-get install -y fonts-nanum
bash novel/tools/publish.sh
```

⚠ 2026-08-09에 실제로 한 번 겪었다. 작업 트리가 기본 브랜치로 되돌아가고 `reportlab`·나눔폰트가 사라졌다.
**도구가 저장소에 있었기 때문에 게이트 14종이 전부 살아남았다** — 스크래치패드에만 뒀으면 통째로 잃었다.

## ⚠ 자수 일괄 동기화 시 주의 (38차 검수)

리포트의 `| 자수 | **초고** | **최종** |` 같은 **전/후 대조 행**을 정규식으로 갱신할 때
`^\|\s*자수\s*\|\s*\*\*[\d,]+\*\*` 는 **첫 칸(초고)** 을 덮어쓴다. 실제로 한 번 그렇게 망가뜨렸다
(`| 자수 | 3,647 | 4,468 |` → `| 자수 | 4,766 | 4,468 |`).

**대조 행은 자동 치환 대상에서 빼고 손으로 고친다.** 게이트 ⑫는 *"한 행이라도 실제와 맞으면 통과"* 라
뒤집힌 표를 잡아 주지 못한다 — 이건 게이트로 못 막는 자리다.
