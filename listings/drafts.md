1. 위 7개 카드를 위에서부터 차례로 당근스토어에 등록.
2. **북마클릿 사용**: `bookmarklet/store_filler_install.html`에서 북마클릿을 북마크 바로 드래그 → 당근스토어 상품 등록 페이지 열고 클릭 → 모달에서 상품 선택 → 자동채움 + 클립보드 복사.
