🏪 당근스토어 상품등록 자동채움

상품 7종(참외 3 + 옥수수 3 + 콜라비 1)의 등록 초안을 임베드한 북마클릿. 등록 페이지에서 클릭하면 모달이 뜨고, 상품/옵션 선택 후 [자동채움] 또는 [복사].

1. 북마클릿 설치

아래 주황색 버튼을 북마크 바로 드래그하세요. (북마크 바가 안 보이면 Ctrl/⌘ + Shift + B)

🏪 당근스토어 자동채움

버튼을 그냥 클릭하면 동작하지 않습니다. 반드시 북마크 바로 드래그 (또는 우클릭 → "북마크에 추가").

2. 사용법

  1. 당근스토어 또는 임의 등록 페이지를 연다.
  2. 북마크 바의 🏪 당근스토어 자동채움 클릭.
  3. 모달에서 상품과 옵션(사이즈) 선택.
  4. [⚡ 자동채움] → 폼 필드 자동 채워짐 (상품명/설명/가격/태그 휴리스틱 매칭).
  5. 매칭 못한 필드는 우측 [복사] 버튼으로 클립보드 복사 후 직접 붙여넣기.
  6. [전체 복사]는 한 번에 전부 클립보드로.

3. 자동채움 동작 방식

  • 페이지의 모든 보이는 input/textarea를 수집.
  • 각 필드의 label, placeholder, name, aria-label, 부모/주변 텍스트에서 한국어 키워드 매칭 — 상품명/제목, 가격/판매가, 설명/내용, 태그/해시태그.
  • 매칭 안 되면 폴백: 첫 입력칸 → 상품명, 첫 textarea → 상세설명.
  • 리액트/Vue처럼 가상돔이라도 동작하도록 native setter + input/change 이벤트를 발화.
당근스토어 폼의 실제 구조에 따라 정확도가 달라질 수 있어요. 등록 페이지 스크린샷 1장을 주시면 셀렉터를 정확히 맞춰드립니다.

4. 임베드된 상품 목록

  1. 성주 가정용 참외 (혼합과) — 1/2/3/5kg
  2. 성주 가정용 참외 (중소과) — 1/1.5/3/5kg
  3. 성주 가정용 참외 (로얄과) — 3/5kg
  4. 제주 초당옥수수 (중품 9~14cm) — 5/10/15/20개
  5. 제주 초당옥수수 (특품 14cm+) — 5/10/15/20개
  6. 애플 초당옥수수 (특품) — 5/10/15/20개
  7. 제주 콜라비 (정품) — 3/5/10kg
