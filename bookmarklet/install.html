당근마켓 상품 페이지에서 클릭 한 번으로 데이터를 추출해 Google Sheet에 자동 기록합니다.

⚠️ 먼저 Apps Script Web App을 배포하고 URL/토큰을 받아두세요. (아래 설정 가이드 참고)

1. 북마클릿 설치

아래 주황색 버튼을 북마크 바로 드래그하세요. (브라우저에 북마크 바가 보이지 않으면 Ctrl/⌘ + Shift + B로 켜기)

📊 당근 시세 추적기

위 버튼을 클릭하면 동작하지 않습니다 — 반드시 북마크 바로 드래그 하세요. (또는 우클릭 → "북마크에 추가")

2. 사용법

  1. 당근마켓 상품 페이지를 연다.
  2. (선택) 옵션 영역(수량/가격 적힌 부분)을 마우스로 드래그해 선택. 더 정확하게 추출됨.
  3. 북마크 바의 📊 당근 시세 추적기 클릭.
  4. 최초 1회만: Apps Script Web App URL과 토큰을 묻는 프롬프트가 뜸 — 시트 메뉴 🔐 Web App URL/토큰 보기에서 복사해 붙여넣기.
  5. 자동 추출된 값을 모달에서 확인/수정 → [전송].
  6. 시트의 [시세기록]에 자동 기록되고 [대시보드]가 자동 갱신됨.

3. Apps Script Web App 배포 (최초 1회)

  1. 구글 시트에 당근_시세추적기_v3.gs 코드를 붙여넣고 저장.
  2. 함수 setup 실행 → 권한 승인.
  3. 우측 상단 [배포] → [새 배포] 클릭 → 유형 "웹 앱" 선택.
  4. 액세스 권한: "모든 사용자(Anyone)", 실행: "나" 선택 → 배포.
  5. 표시된 URL을 복사 → 시트 메뉴 🔐 Web App URL/토큰 보기로 토큰도 함께 확인.
  6. 처음 북마클릿을 누를 때 그 두 값을 입력하면 끝.
토큰이 노출되면 메뉴의 🔁 토큰 새로 발급으로 무효화하세요. 북마클릿은 자동으로 다시 토큰을 물어봅니다.

5. 문제 해결

  • "전송 실패" — Web App URL이 올바른지, "모든 사용자" 액세스로 배포됐는지 확인.
  • 토큰 불일치 — 메뉴 🔐 Web App URL/토큰 보기의 토큰과 일치해야 함. 모달의 [설정] 버튼으로 다시 입력.
  • 상품명/평점이 잘못 추출됨 — 모달에서 직접 수정 후 전송 (페이지 구조가 자주 바뀜).
  • 옵션이 비어있음 — 옵션 영역을 마우스로 드래그한 뒤 다시 북마클릿 클릭.
