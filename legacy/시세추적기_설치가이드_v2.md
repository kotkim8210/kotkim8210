# 당근 시세 추적기 v2 — 설치 & 사용 가이드

무료(Google Sheets + Apps Script)로 당근 상품의 **단위당 단가·평점·찜수를 기록하고, 가격 변동·신규 상품을 매일 메일로 알림**받는 시스템입니다.
**v2 변경점:** 단위 **개/박스/kg** 지원, 입력을 **구조화(수량/단위/가격)** 로 전환해 가격 오기록 버그 제거, 대시보드 단위별 분리, 신규상품 감지 추가.

---

## A. 설치 (최초 1회, 약 5분)

1. **새 구글시트** 생성 → [sheets.new](https://sheets.new)
2. **확장 프로그램 → Apps Script**
3. 기존 코드 삭제 후 **`당근_시세추적기_v2.gs` 전체 붙여넣기**
4. (권장) 코드 상단 `const ALERT_EMAIL = '';` 따옴표 안에 **본인 이메일 입력** → 매일 알림 누락 방지
5. 💾 저장 → 함수 **`setup`** 선택 → **▶ 실행** → 첫 실행 시 **권한 승인**(본인 계정 → 고급 → 허용)
6. 시트로 돌아오면 상단 **📊 시세추적기** 메뉴 생성됨
7. **확장 > Apps Script > ⚙️ 프로젝트 설정**에서 **시간대를 (GMT+9) 서울**로 설정 (알림 시각 정확성)
8. 메뉴 **→ 최초 1회: 매일 알림 설치**

---

## B. 매일 사용 (1상품당 약 30초)

당근 상품의 **옵션 화면**을 보면서 [입력] 시트를 채웁니다.

1. **상품 정보**: B1 검색어 / B2 상품명 / B3 판매자 / B4 평점 / B5 후기수 / B6 찜수
2. **옵션**: 9행부터 한 옵션 = 한 줄로 입력
   | 수량 | 단위 | 가격 |
   |---|---|---|
   | 5 | 개 | 9,820 |
   | 10 | 개 | 14,820 |
   - **단위는 드롭다운(개/박스/kg)** 에서 선택 — 옥수수=개, **복숭아=kg**, 묶음=박스
   - 복숭아 예: `4.5` / `kg` / `30,000` → kg당 단가 자동 계산
   - 가격은 콤마 있어도 됩니다(자동 정리)
3. 메뉴 **📊 시세추적기 → ① 입력 → 기록 추가**
   - → [시세기록]에 적재 + **단위당단가 자동 계산**, [대시보드] 자동 갱신
   - 같은 날 같은 값은 **중복 자동 차단**(건너뜀 안내 표시)

다른 상품은 B1~B6과 옵션을 바꿔 ①을 다시 누르면 됩니다.

---

## C. 결과물

- **[시세기록]** : 모든 기록의 원본(시간순) — 추이·차트의 원천
- **[대시보드]** (메뉴 ②):
  - **검색어 × 단위 요약**: 단위(개/박스/kg)별 최저·평균 단위당단가, 최저가 상품
  - **상품별 최신 스냅샷**: 단위별로 단위당단가 낮은 순 + 평점·후기·찜
  - ⚠️ 단위가 다른 상품은 **섞어 비교하지 않습니다**(개 vs kg는 무의미하므로 분리)
- **알림 메일** (매일 8시 / 메뉴 ③ 수동):
  - **가격 변동**: 같은 상품·옵션의 가격 변화(▲인상/▼인하 + 단위당단가 변화)
  - **신규 상품**: 마지막 점검 이후 새로 등록한 상품
  - *첫 점검에는 현재 상품 전체가 '신규(기준선)'로 표시됩니다. 이후부터 진짜 신규만.*

---

## D. 한계 & 확장

- **데이터 '수집'만 수동**(의도된 설계): 당근은 공개 API가 없고 자동수집(스크래핑)은 약관 위반 소지 + 봇차단으로 불안정. 그래서 *입력 30초 + 나머지 100% 자동* 구조입니다.
- **확장:** 추후 **API가 있는 플랫폼**(예: 스마트스토어 커머스 API)으로 옮기면 `addEntries`를 API 호출로 교체해 **수집까지 완전 자동화** 가능. [시세기록]·[대시보드]·알림 로직은 그대로 재사용됩니다.
- 필요 시 **단위당단가 추이 꺾은선 차트**를 시트에 자동 생성하는 기능을 추가해 드릴 수 있습니다.
