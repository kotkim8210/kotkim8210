# research/ — 실측 검증 코드 (재현 가능)

`docs/08-backtest-results.md`와 `docs/09-buffett-system.md`의 모든 수치를 생성한 코드다.
결과를 믿기 전에 코드를 읽고 직접 돌려볼 수 있도록 그대로 커밋했다.

## 파일

| 파일 | 역할 |
|---|---|
| `download.py` | 생존편향 없는 유니버스 구성 + 일봉 수집 (현재 상장 + 과거 상장폐지) |
| `engine.py` | 백테스트 엔진 — DQ 정제, 피처, 이벤트 드리븐 루프, 성과지표 |
| `final.py` | 최종 검증 — 전략 비교 + 랜덤 대조군 200회 |
| `buffett_check.py` | 버크셔 vs S&P500 실증 분석 (1980~2025) |
| `results_2015_2025.log` | 주 결과 원본 출력 |
| `results_2010_2025.log` | 전체 기간 결과 원본 출력 |

## 실행

```bash
pip install pandas numpy pyarrow finance-datareader
python download.py        # ~7분, 3,155종목 × 18년 (약 93MB)
python final.py           # ~5분 (랜덤 대조군 200회 포함)
python buffett_check.py   # ~1분
```

## 이 코드가 지키는 것

| 원칙 | 구현 |
|---|---|
| **생존편향 제거** | `KRX-DELISTING` 4,172건에서 2008년 이후 폐지 664건을 유니버스에 포함 |
| **선견편향 방지** | 신호는 월말 종가까지만 사용, 체결은 **익일 시가** |
| **데이터 품질** | 100원 미만 가격·10거래일 초과 공백·가격제한폭 초과 → 마스킹 (170만 건) |
| **비용 반영** | 수수료 0.015%(편도) + 매도세 0.20% + 슬리피지 0.10%(편도) |
| **상장폐지 처리** | 가격 소멸 시 마지막 가용가로 청산 (0원 처리 아님, 무시도 아님) |
| **우연 배제** | 동일 조건 랜덤 포트폴리오 200개와 백분위 비교 |

## 알려진 한계 (코드 수준)

1. `turnover = 수정주가 × 원거래량` — 액면분할 종목의 과거 거래대금이 과소 계상된다.
   정확히 하려면 분할 계수가 필요한데 무료 소스로는 확보하지 못했다.
2. 2010~2014 구간은 유니버스가 작아(147종목) 신뢰도가 낮다. 주 결과는 2015년 이후를 쓴다.
3. 배당 미반영 — 가격 수익률만 계산했다. 실제 총수익은 연 1~2%p 높다.
4. 재무 데이터 없음 — F·D축은 이 코드로 검증할 수 없다. DART API 키가 있으면 확장 가능하다.
