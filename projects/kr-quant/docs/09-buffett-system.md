# 9. 버핏 방식의 기계적 시스템화

> **목표:** 일반인이 실행해도 **동일한 종목 리스트와 동일한 매매 판단**이 나오도록,
> 버핏이 실제로 문서에 남긴 기준만 사용해 완전히 기계화한다.

---

## 9.0 먼저 정직하게: "완전히 동일한 결과"는 불가능하다

요청은 "일반인이 투자해도 완전히 동일한 결과가 나오게"였다. 그 부분은 **구조적으로 불가능**하다.
이유를 숨기지 않고 먼저 밝힌다. 그 다음에 **가능한 최대치**를 만든다.

### 버크셔 실적의 실측 (본 프로젝트에서 직접 계산, 1980–2025)

| | CAGR | MDD | 변동성 | Sharpe | 최종 배수 |
|---|---|---|---|---|---|
| 버크셔(BRK-A) | **18.74%** | −51.5% | 22.5% | 0.70 | **2,605배** |
| S&P500 (가격지수) | 9.63% | −56.8% | 17.9% | 0.37 | 67배 |
| S&P500 (배당 포함 근사) | 11.63% | | | | |

전체 기간 초과수익 **연 +7.11%p**. 46년간 2,605배 — 이건 실제로 일어난 일이다.

### 그런데 그 우위는 이미 사라졌다

| 기간 | 버크셔 | S&P500(배당포함) | 초과 |
|---|---|---|---|
| 1980–1984 | 36.22% | 12.81% | **+23.40%p** |
| 1985–1989 | 46.87% | 18.44% | **+28.43%p** |
| 1990–1994 | 18.82% | 7.02% | +11.81%p |
| 1995–1999 | 22.47% | 28.25% | −5.78%p |
| 2000–2004 | 9.92% | −1.60% | +11.52%p |
| 2005–2009 | 2.64% | 0.51% | +2.13%p |
| 2010–2014 | 17.85% | 14.72% | +3.13%p |
| 2015–2019 | 8.73% | 11.45% | **−2.72%p** |
| 2020–2024 | 14.76% | 14.55% | +0.21%p |

**롤링 10년 초과수익**: 전체 430개 구간 중 80.5%가 (+). 평균 +6.31%p.
그러나 **최근 10년(2016–2025) 기준 초과수익은 −0.59%p** — 버핏 본인이 시장을 못 이겼다.

```
초과수익(%p/년)
 +25 │ ██
 +20 │ ██ ██
 +15 │ ██ ██
 +10 │ ██ ██ ██    ██
  +5 │ ██ ██ ██    ██    ██ ██
   0 ├────────────────────────────────────
  −5 │          ██          ██
     └─────────────────────────────────────
      80 85 90 95 00 05 10 15 20  (5년 구간)
      ◄──── 알파의 대부분이 여기 ────►  ◄─ 사실상 소멸 ─►
```

**결론 1: "버핏 방식이면 안전하게 시장을 이긴다"는 전제 자체가 데이터로 지지되지 않는다.**
버핏의 초과수익은 압도적으로 1980–1994년에 발생했고, 2000년대 이후로는 시장 수익률에 수렴했다.

### 왜 그런가 — 복제 불가능한 구조적 우위

| 우위 | 내용 | 일반인 복제 |
|---|---|---|
| **보험 플로트 레버리지** | 보험료를 먼저 받고 보험금은 나중에 지급 → **비용이 사실상 음수인 차입금**으로 약 1.6배 레버리지 | ❌ 불가능. 개인의 신용대출·미수는 비용이 (+) |
| **영구 자본** | 실측 MDD −51.5%를 두 번 겪고도 환매 없음. 펀드였다면 청산됐다 | ⚠️ 이론상 가능하나 대부분 실패 |
| **사적 협상 거래** | 2008년 골드만삭스·GE에 10% 우선주 + 워런트 조건으로 투자 | ❌ 불가능 |
| **경영권 인수** | 자회사 현금흐름을 배당세 없이 재배치 | ❌ 불가능 |
| **규모·평판** | 유동성 위기 때 상대방이 먼저 찾아옴 | ❌ 불가능 |
| **세금 이연** | 미실현이익에 법인 단계 과세 이연 | ⚠️ 부분적(장기보유) |

학술적 분해(Frazzini·Kabiller·Pedersen, *Buffett's Alpha*, Financial Analysts Journal 2018)는
버크셔 수익률의 대부분이 **저베타 + 퀄리티 + 밸류 팩터 노출에 약 1.6배 레버리지**를 적용한 것으로
설명되며, 이를 통제하면 알파의 통계적 유의성이 크게 낮아진다고 보고했다. `[출처 확인 권장]`

본 프로젝트 실측도 이와 일치한다 — **버크셔 베타 0.50(1980–99) / 0.64(2000–25)**. 저베타 노출이 실재한다.

**결론 2: 복제 가능한 것은 "종목 선정 기준"이고, 복제 불가능한 것은 "레버리지·자본구조·거래 조건"이다.**
따라서 아래 시스템은 **버핏의 선정 기준을 100% 기계화**하되, 수익률이 버크셔와 같아질 것이라고
약속하지 않는다. 레버리지 1.6배가 빠지면 기대수익은 구조적으로 낮아진다.

## 9.1 설계 원칙 — 재현성이 최우선

두 사람이 같은 날 이 시스템을 돌리면 **반드시 같은 종목 리스트**가 나와야 한다.
따라서 다음을 금지한다.

- ❌ "훌륭한 경영진", "좋은 사업" 같은 주관적 판단 → 전부 정량 대용치로 치환
- ❌ 재량적 예외 ("이번엔 특별하니까")
- ❌ 애널리스트 목표주가·컨센서스 (유료·비공개·수시 변경)

사용 데이터는 **DART Open API(무료)** 로 누구나 얻을 수 있는 것만 쓴다.

## 9.2 게이트 A — 지속적 수익력 (Consistent Earning Power)

버핏의 인수 기준 원문은 "**consistent earning power**(future projections are of no interest to us,
nor are 'turnaround' situations)"이다. 미래 추정이 아니라 **과거 10년의 실적 일관성**을 본다.

```
A1. 상장 경과 ≥ 10년                              (검증할 이력이 있어야 한다)
A2. 최근 10년 영업이익 흑자 = 10회                 (단 1회의 적자도 허용하지 않는다)
A3. 최근 10년 ROE 평균 ≥ 15%  AND  최솟값 ≥ 8%
A4. 최근 10년 매출 CAGR ≥ 0%                      (역성장 기업 배제)
A5. 영업이익률 10년 변동계수 ≤ 0.5                 (이익의 예측 가능성)
```

> **A2가 가장 강력한 필터다.** 한국 상장사 대부분이 여기서 탈락한다.
> 버핏이 "턴어라운드에는 관심 없다"고 명시한 것을 그대로 옮긴 것이다.
> 이 항목은 KR-Quant 본 시스템의 KP-01(턴어라운드 패턴)과 **정면으로 배치된다** — 의도된 차이다.

## 9.3 게이트 B — 재무 안전성

버핏은 "우리는 큰 부채를 쓰는 기업을 좋아하지 않는다"를 반복해 왔다.

```
B1. 부채비율 ≤ 100%                    (금융업은 이 시스템 대상에서 제외)
B2. 이자보상배율 ≥ 5배
B3. 순차입금 / 영업이익 ≤ 3배
B4. 유동비율 ≥ 1.5
```

## 9.4 게이트 C — 이익의 질 (소유주 이익)

버핏은 1986년 주주서한 부록에서 회계상 순이익 대신 **소유주 이익(Owner Earnings)** 을 쓴다고 밝혔다.

```
소유주이익 = 당기순이익
           + 감가상각비 + 무형자산상각비 + 기타 비현금비용
           − 유지보수 CAPEX(maintenance capex)

※ 유지보수 CAPEX는 공시되지 않으므로 대용치를 쓴다:
   maint_capex ≈ min(당기 CAPEX, 감가상각비)
   (성장 CAPEX를 제외하려는 의도. 보수적으로 감가상각비를 상한으로 둔다)
```

```
C1. 10년 누적 영업활동현금흐름 / 10년 누적 순이익 ≥ 0.9
C2. 소유주이익 > 0 인 연도 ≥ 9 / 10
C3. 발생액 비율 = (순이익 − OCF) / 평균총자산 이 업종 상위 20%가 아닐 것
```

## 9.5 게이트 D — 경영진의 자본 배분 능력 (1달러 테스트) ⭐

버핏이 주주서한에서 직접 제시한 기준이다:
> "유보한 1달러가 최소한 1달러의 시장가치를 창출했는가."

주관적인 "유능한 경영진"을 **완전히 객관적인 수식**으로 바꾸는 항목이다.

```
one_dollar_test = (시가총액_현재 − 시가총액_10년전) / (10년간 누적 유보이익)
                   ※ 누적 유보이익 = Σ(당기순이익 − 배당금총액)

D1. one_dollar_test ≥ 1.0
D2. 발행주식수 10년 증가율 ≤ 0%     (희석 없음. 자사주 소각이면 가점)
D3. 배당 또는 자사주 소각이 존재     (이익을 주주에게 돌려주는 경로가 있는가)
```

> D1은 이 시스템에서 **가장 버핏다운** 항목이다. 경영진이 번 돈을 잘 재투자했는지를
> 사람의 인상이 아니라 시장가치 증가분으로 채점한다.
> 단, 시장가치는 밸류에이션 변동에 좌우되므로 **10년이라는 긴 창**을 써서 노이즈를 줄인다.

## 9.6 게이트 E — 합리적 가격

버핏의 인수 기준 5번은 "**an offering price**(we don't want to waste our time... without a price)"다.
가격 없이는 좋은 사업도 좋은 투자가 아니다.

```
E1. 이익수익률(E/P) ≥ 국고채 10년 수익률 × 1.5
E2. 소유주이익 수익률 = 소유주이익 / 시가총액 ≥ 6%
E3. 다음 중 하나 이상:
      · PER × PBR ≤ 22.5                        (그레이엄 기준)
      · 10년 DCF 내재가치 대비 ≥ 30% 할인        (아래 산식)
```

### 내재가치 산식 (완전 고정 — 재량 개입 불가)

```
1) 기준 소유주이익 = 최근 3년 소유주이익의 평균          (일회성 평활화)
2) 성장률 g = min(최근 10년 소유주이익 CAGR, 10%)        ★상한 10% 강제
3) 1~10년차: 기준값을 g로 성장시켜 현가화
4) 11년 이후: 영구성장률 2.5% 가정한 잔존가치
5) 할인율 r = 국고채 10년 + 4%p                          ★고정
6) 내재가치 = Σ현가 + 잔존가치현가
7) 안전마진 = 1 − (시가총액 / 내재가치) ≥ 30%
```

> **성장률 상한 10%와 할인율 고정이 재현성의 핵심이다.**
> DCF가 "원하는 답을 만들어내는 도구"가 되는 이유는 g와 r을 자유롭게 정하기 때문이다.
> 두 값을 규칙으로 못 박으면 누가 계산해도 같은 숫자가 나온다.

## 9.7 포트폴리오 운용 규칙

버핏 방식의 핵심은 종목 선정보다 **거래를 거의 하지 않는 것**에 있다.

| 항목 | 규칙 | 근거 |
|---|---|---|
| 보유 종목 수 | **10~15** | "분산은 무지에 대한 방어" — 집중하되 파산 리스크는 회피 |
| 비중 | 안전마진 순 가중, 종목당 최대 15% | |
| 리밸런스 | **연 1회** (사업보고서 공시 후 4월) | 회전율 최소화 |
| 최소 보유기간 | **3년** | 논리 붕괴가 아니면 팔지 않는다 |
| 현금 | 조건 충족 종목이 10개 미만이면 **나머지는 현금** | ★강제 매수 금지 |
| 신규 자금 | 매월 적립, 조건 충족 시에만 투입 | |

### 매도 규칙 — 단 3가지뿐

```
S1. 사업 훼손:  게이트 A·B·C 중 하나라도 위반          → 전량 매도
S2. 극단 고평가: 시가총액 ≥ 내재가치 × 2.0              → 절반 매도
S3. 기회비용:   더 높은 안전마진 종목이 있고 보유 3년 경과 → 교체 허용

※ 주가 하락은 매도 사유가 아니다.
   게이트를 계속 통과하는데 가격만 내렸다면 → 안전마진 상승 → 추가 매수 대상
```

**이 한 줄이 시스템 전체에서 가장 지키기 어렵고, 가장 중요하다.**
버크셔조차 −51.5% 낙폭을 두 번 겪었다. 그때 팔았다면 2,605배는 없었다.

## 9.8 KR-Quant 본 시스템과의 차이

| | KR-Quant 7축 | 버핏 시스템 |
|---|---|---|
| 대상 | 개선 중인 기업(턴어라운드 포함) | **이미 훌륭한 기업만** |
| 적자 이력 | 흑자 전환을 기회로 봄 (KP-01) | **10년 중 1회 적자도 탈락** |
| 보유기간 | 12~36개월 | **최소 3년, 사실상 무기한** |
| 리밸런스 | 주 1회 | **연 1회** |
| 종목 수 | 8~15 | 10~15 |
| 수급·기술 | 36점 (S+T) | **사용하지 않음** |
| 매도 | 6개 룰 | **3개 룰** |
| 후보 수(예상) | 수십 개 | **한 자릿수** ⚠️ |

> ⚠️ **버핏 시스템의 실무적 문제:** 게이트 A2(10년 연속 흑자) + A3(ROE 평균 15%)를
> 한국 시장에 적용하면 통과 종목이 극히 적을 가능성이 높다. 한국 상장사의 이익 변동성은
> 미국보다 크고, 경기민감 업종 비중이 높기 때문이다.
> → 후보가 5개 미만이면 **강제로 채우지 말고 현금을 들고 있는 것**이 규칙이다.
> → 또는 대상 시장을 미국으로 확대하는 선택지를 검토한다(§9.10).

## 9.9 이 시스템의 백테스트 — 아직 못 했다 (정직한 고지)

**본 세션에서는 이 시스템을 백테스트하지 못했다.** 이유는 하나다:

> 게이트 A~E는 전부 **과거 10년치 재무제표**를 요구하는데,
> 이 실행 환경에서 한국 주식의 과거 시점 재무 데이터를 확보할 수 없었다.
> (KRX 정보데이터시스템은 로그인 필수로 차단, 네이버는 최근 3년치 + 재작성본만 제공)

### 사용자가 직접 검증하는 방법

DART Open API 키는 **무료**이고 5분이면 발급된다. 키가 있으면 아래로 검증 가능하다.

```bash
# 1. https://opendart.fss.or.kr 에서 인증키 발급 (무료)
export DART_API_KEY=...

# 2. 10년치 재무 수집 → PIT 저장 (rcept_dt 필수)
krq collect --financials --years 12

# 3. 버핏 게이트 백테스트 (연 1회 리밸런스, 2010~2025)
krq backtest --strategy buffett --from 2012-01-01 --to 2025-12-31 \
             --rebalance annual --min-holdings 10
```

**검증 시 반드시 확인할 것:**
1. 통과 종목 수가 매년 10개 이상인가 (아니면 전략이 성립하지 않는다)
2. 생존편향 제거됐는가 (상장폐지 종목 포함)
3. PIT 준수 — 사업보고서는 익년 3~4월에야 존재. **4월 리밸런스가 그 이유다**
4. 재작성(restatement) 데이터를 쓰지 않았는가

## 9.10 냉정한 기대치

| 버크셔와 동일한 수익률 | ❌ 불가능 (레버리지 1.6배 부재) |

**가장 정직한 결론:**
버핏 방식의 재현 가능한 부분은 "시장을 이기는 기계"가 아니라
**"덜 잃고 오래 버티는 규율"** 이다. 그 규율의 값어치는 초과수익이 아니라
**중도 이탈 확률을 낮추는 것**에서 나온다. 46년을 버틴 것이 2,605배의 진짜 원인이며,
그 46년을 버티게 한 것은 종목 선정 기준이 아니라 영구 자본 구조였다.

**저비용 인덱스 적립 + 이탈하지 않는 규율**이다.
