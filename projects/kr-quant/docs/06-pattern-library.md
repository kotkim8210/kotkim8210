# 6. 패턴 라이브러리 초안

## 6.0 이 문서의 지위 — 반드시 먼저 읽을 것

여기 적힌 패턴은 **가설이지 검증된 사실이 아니다.**

- 각 패턴의 조건값(임계치)은 **초기 추정치**이며, `krq mine` + `krq backtest`로 재도출해야 한다.
- "대표 사례"는 그 패턴이 어떤 모습인지 보여주는 **예시**이며, 수익률 수치를 주장하지 않는다.
- 검증 상태를 각 패턴에 표기했다: `가설` → `검증중` → `검증됨` → `기각`.
- **`가설` 상태 패턴은 매수 판단에 가중치를 주지 않는다.** 리포트에 참고 표시만 된다.

이 원칙이 없으면 패턴 라이브러리는 "그럴듯한 이야기 모음"으로 전락한다.
스토리가 데이터를 대체하는 순간이 이 시스템이 실패하는 지점이다.

### 패턴 기술 형식

```yaml
id: KP-XX
name: 패턴명
thesis: 왜 작동한다고 보는가 (경제적 논리)
trigger:      # 탐지 조건 (기계 판독)
confirm:      # 진입 전 반드시 확인할 것
invalidate:   # 이 신호가 나오면 패턴 무효
horizon:      # 예상 보유 기간
status:       # 가설 | 검증중 | 검증됨 | 기각
```

## 6.1 KP-01 · 실적 턴어라운드 (Turnaround)

| 항목 | 내용 |
|---|---|
| **논리** | 적자 기업이 흑자로 전환하는 구간은 시장의 이익 추정이 가장 크게 바뀌는 지점이다. 애널리스트 커버리지가 끊긴 상태라 정보 반영이 느리고, 커뮤니티 감성은 여전히 최악이라 역발상 조건이 동시에 성립하기 쉽다. |

| **confirm** | ✅ OCF도 함께 (+)로 전환 (이익만 흑자면 회계적 착시 가능) · 일회성 이익 제외 후에도 흑자 · 외인 또는 기관 60일 순매수 (+) |

| **관련 축** | F2·F4 강세, C3(감성-펀더멘털 괴리) 만점 구간 |
| **horizon** | 12~24개월 |
| **status** | **가설** |

> 가장 흔한 실패 원인: **"흑자 전환"만 보고 현금흐름을 안 본 경우.** confirm의 첫 항목이 핵심이다.

## 6.10 KP-10 · 액면분할 이벤트 (컨텍스트 의존) ⭐

> **요구사항 §5 직접 구현.** 액면분할은 호재도 악재도 아니다.
> **현재 밸류에이션과 수급 위치에 따라 해석이 뒤집히는 이벤트**로 처리한다.

### 왜 부호를 고정할 수 없는가

액면분할은 기업 가치를 **전혀 바꾸지 않는다**(주식 수 × 주가 = 동일). 바뀌는 것은 접근성과 유동성뿐이다.
따라서 주가 반응은 분할 자체가 아니라 **"분할을 결정한 시점에 그 회사가 어디에 서 있었는가"** 가 만든다.

### 해석 매트릭스

| 직전 3년 수익률 | 밸류에이션 백분위 | 감성 | 해석 | 조치 |
|---|---|---|---|---|
| < 50% | 하위 40% | 중립~부정 | **접근성 개선형** — 저평가 국면에서 저변 확대 | 중립~약한 가점 (+3) |
| 50~200% | 중간 | 중립 | **중립형** | 이벤트 무시. 유동성 개선만 반영 |
| > 200% | 상위 80% | 과열 | **정점 신호 경계형** — 대중 참여 극대화 시점 = 기대의 정점 | `SELL_EVENT_PEAK` 활성화 |

### 두 대표 사례의 대비 `[검증필요 — 방향성 서술]`

| | **삼성전자 (2018년 5월, 50:1)** | **카카오 (2021년 4월, 5:1)** |
|---|---|---|
| 분할 전 장기 상승폭 | 상대적으로 완만 | 수년간 대폭 상승 후 |
| 분할 시점 밸류에이션 | 상대적으로 낮은 수준 | 높은 수준 |
| 분할 시점 시장 관심 | 보통 | 매우 과열 |
| 매트릭스 분류 | **접근성 개선형** | **정점 신호 경계형** |
| 이후 경로(방향성) | 단기 조정 후 중장기 재평가 국면 진입 | 이후 주가 약세 국면 |

> ⚠️ 위 표는 **두 사례가 서로 다른 컨텍스트에 있었다**는 점을 보여주기 위한 것이며,
> 구체적 수익률을 주장하지 않는다. 시스템은 이 대비를 규칙으로 일반화한다:
> **"분할 자체가 아니라, 분할 시점의 위치와 그 이후의 사업·실적·수급"** 을 본다.

### 사후 판정 (분할 후 60일)

분할 시점의 분류는 **잠정**이며, 다음으로 확정한다:

```
IF 분할 후 60일 외인·기관 누적 순매수 > 0 AND 이후 분기 실적 개선
   → 접근성 개선형 확정 (유동성 증가가 실제 수급 유입으로 연결됨)
IF 분할 후 60일 외인·기관 누적 순매수 < 0 AND 개인 순매수 집중
   → 정점 신호 확정 (유동성 증가가 개인 물량 이전에만 기여)
```

이 사후 판정 결과는 패턴 라이브러리에 라벨로 축적되어 매트릭스 임계값을 데이터에서 갱신한다.
**무상증자·주식배당 등 다른 "주식 수 증가 이벤트"에도 동일 로직을 적용한다.**

## 6.11 시나리오 패턴 (§10 대응)

### KP-11 · 정책 실현형 (Policy Realization)

| 항목 | 내용 |
|---|---|
| **논리** | 정책 발표만으로는 아무것도 바뀌지 않는다. **예산이 배정되고 발주가 나가고 수주가 공시될 때** 비로소 재무제표가 바뀐다. 시장은 ①단계(발표)에 과잉 반응하고 ③단계(수주)에 과소 반응하는 경향이 있다 — 그 시차가 기회다. |
| **trigger** | 시나리오 `lifecycle_stage ∈ {budgeted, contracted}` · E1 ≥ 60 · E2 ≥ 55 |
| **confirm** | ✅ 실제 수주 공시(`contract_impact ≥ 0.10`) · 해당 **사업부문** 매출 YoY (+) · 외인·기관 60일 순매수 (+) · 월봉/주봉 추세 조건 |
| **invalidate** | ❌ 예산 삭감·정책 철회 · 발표 후 12개월간 수주 0건 · E3(선반영) ≥ 70 |
| **⚠️** | **①②단계에서는 절대 매수하지 않는다.** 상태머신이 `WATCH`/`CONFIRM_PENDING`에서 매수를 물리적으로 차단 |
| **horizon** | 12~36개월 |
| **status** | **가설** — 표본 부족. E축 15점 상한 유지 근거 |

### KP-12 · 지연상승형 공시 (Delayed Drift)

| 항목 | 내용 |
|---|---|
| **논리** | §10-2의 핵심. 어떤 공시는 즉시 급등 후 소멸하고(A형), 어떤 공시는 수주~수개월에 걸쳐 초과수익이 누적된다(B형). **B형만이 중장기 투자 대상이다.** |
| **trigger** | 공시 유형의 과거 CAR 곡선이 B형으로 분류됨 · CAR(1주) 대비 CAR(3개월)이 유의하게 큼 |
| **confirm** | ✅ 공시 후 외인·기관 순매수 전환(조건부 CAR에서 격차 확인된 그룹) · 후속 실적 확인 |
| **invalidate** | ❌ CAR(1주) 급등 후 CAR(1개월)에서 되돌림 = A형 |
| **비고** | 이 패턴은 `krq eventstudy` 결과로 **자동 갱신**되는 유일한 패턴이다. 공시 유형별 분류표가 곧 패턴 본체 |
| **status** | **검증중** — 엔진 구현 후 즉시 산출 가능 |

## 6.12 회피 패턴 (ANTI) — 사용자 §8 구현

이 패턴들은 **점수를 깎고 거부권을 발동시키는 용도**다.

### ANTI-01 · 테마 급등 후 실적 미실현
```yaml
trigger:   20일 수익률 >= 40% AND 거래량배수 >= 3 AND 최근 2분기 실적 개선 없음
signal:    과열 거부권 V1 + E4 대폭 상승
tell:      "사업목적 추가"·MOU·LOI 공시는 있으나 부문별 매출은 0
horizon:   대개 3~6개월 내 되돌림
status:    가설
```
> **KP-06(신사업 전환)과의 유일한 구분선은 부문별 매출 계상 여부다.** 이 한 줄이 테마와 전환을 가른다.

### ANTI-02 · 반복 희석
```yaml
trigger:   3년 내 유상증자 2회 이상 OR 미상환 CB/BW 잠재주식/시총 >= 15%
signal:    SG1·SG2 소프트게이트 + F7 감점
tell:      증자 자금 용도가 "운영자금"·"채무상환" (설비·R&D가 아님)
status:    가설
```

### ANTI-03 · 기술적 반등 + 재무 악화 (§8 명시 요구)
```yaml
trigger:   T >= 65 AND F < 45
signal:    4중 동시충족 게이트 ②에서 자동 탈락 → 매수 불가
설계:      별도 룰이 필요 없다. 게이트 구조 자체가 이 조합을 배제한다.
status:    구조적 차단 (검증 불필요)
```

### ANTI-04 · 정책 기대 선반영 소멸
```yaml
trigger:   E3 >= 70 AND E2 < 40 AND 촉매 후 누적수익률 > 30%
signal:    과열 거부권 V5 + SELL_EXPECTATION_EXHAUSTED
tell:      정책 발표 직후 급등, 이후 수주·예산 근거 없이 횡보
status:    가설
```

## 6.13 패턴 우선순위 및 충돌 처리

여러 패턴이 동시에 매칭될 수 있다. 충돌 시 규칙:

1. **ANTI 패턴이 KP 패턴을 항상 이긴다.** 하나라도 ANTI가 걸리면 매수 후보에서 제외되거나 사이징이 축소된다.
2. `검증됨` 패턴이 `가설` 패턴보다 우선한다.
3. 동급이면 `horizon`이 긴 패턴을 채택한다(중장기 지향).
4. **패턴 매칭은 점수를 만들지 않는다.** 점수는 7축이 만들고, 패턴은 리포트 설명과 우선순위 가점(최대 +5)에만 쓰인다.

4번이 중요하다. 패턴이 점수를 직접 만들면 "그럴듯한 스토리"가 데이터를 압도하게 된다.
**패턴은 해석 도구이지 판단 근거가 아니다.**
