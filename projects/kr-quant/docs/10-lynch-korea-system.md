# 10. 피터 린치 기반 한국형 실행 시스템

> **목적:** 버핏 시스템(`docs/09`) 중 **일반 한국 성인이 실행할 수 없는 항목**을 걷어내고,
> 그 자리를 **피터 린치의 기법 중 실행 가능한 것**으로 대체한다.
> 판정 기준은 하나다 — **평범한 직장인이 주말 2시간으로 할 수 있는가.**

---

## 10.1 실행 가능성 감사 — 버핏 시스템의 어디가 막히는가

버핏 시스템의 각 요소를 세 가지 기준으로 심사했다:
**① 구조적 복제 가능성 ② 한국 법·제도상 가능성 ③ 일반인의 실행 난이도.**

| 버핏 요소 | 막히는 이유 | 판정 |
|---|---|---|
| 보험 플로트 레버리지 (약 1.6배, 음(−)의 비용) | 개인은 음의 비용 차입이 불가능. 신용융자는 연 5~9% | ❌ **구조적 불가** |
| 사적 협상 거래 (2008 GS·GE 우선주 10%+워런트) | 개인에게 그런 조건이 제시되지 않는다 | ❌ **구조적 불가** |
| 경영권 인수 후 자회사 현금흐름 재배치 | 개인은 지배주주가 될 수 없다 | ❌ **구조적 불가** |
| 영구 자본 (환매 없는 구조) | 개인은 생활자금·주택자금 인출 압력을 받는다 | ⚠️ 부분 가능 |
| **게이트 A: 10년 연속 흑자 + ROE 평균 15%** | **한국은 경기순환 업종(반도체·화학·철강·조선·정유)이 시총의 큰 비중.** 이 게이트는 시장의 대부분을 통째로 배제한다 | ❌ **한국 시장 부적합** |
| **게이트 D: 1달러 테스트** (10년 시총 증가 / 누적 유보이익 ≥ 1.0) | **코리아 디스카운트** — 지배구조·낮은 배당성향 탓에 시장이 재평가하지 않는다. 경영진 능력과 무관하게 실패 | ❌ **한국 시장 부적합** |
| 게이트 C·E: 소유주이익 · 10년 DCF | 유지보수 CAPEX가 공시되지 않고, 일반인이 매 종목 DCF를 돌리는 건 비현실적 | ⚠️ **실행 난이도 과다** |
| "영원히 보유해 세금 이연" | **한국 개인은 상장주식 양도차익이 비과세** → 이연할 세금 자체가 없다 | ❌ **논리 무효** |
| "유능하고 정직한 경영진" 정성 판단 | 재량 개입 → 재현성 파괴 | ⚠️ 객관화 필요 |

### 세금 차이가 설계를 바꾼다 ⭐

미국과 한국의 개인 투자자 과세는 방향이 반대다. `[확인필요 — 세법은 개정이 잦다]`

| | 미국 | 한국 (개인 소액주주) |
|---|---|---|
| 상장주식 양도차익 | **과세** (장기보유 시 우대세율) | **비과세** |
| 배당소득 | 과세 | **15.4% 원천징수** (금융소득 연 2천만원 초과 시 종합과세) |
| 매도 시 거래세 | 없음 | **있음** |

**결론 세 가지:**
1. 버핏의 "절대 팔지 않는다"는 **세금 이연** 논리가 한국에는 적용되지 않는다.
   한국에서 회전율의 비용은 세금이 아니라 **수수료·거래세·슬리피지뿐**이다.
2. 따라서 **린치식의 "스토리가 끝나면 판다"가 한국에서 세제상 불리하지 않다.**
3. 배당은 과세되고 자사주 소각은 주가로 실현되어 비과세다 →
   **세후 기준으로 자사주 소각 기업이 배당 기업보다 유리하다.** 이건 미국보다 한국에서 더 강한 선호다.

## 10.2 대체 매핑

| 버핏 (실행 불가) | → | 린치 대체 (실행 가능) |
|---|---|---|
| 보험 플로트 1.6배 레버리지 | → | **레버리지 포기 + 적립식 매수**로 시간 분산 |
| 사적 협상 거래 | → | **소외 종목 발굴** — 기관 지분율 낮고 애널리스트 커버리지 적은 종목 (개인이 대형기관보다 유리한 유일한 영역) |
| 경영권 인수·자본 재배치 | → | **6가지 유형 분류 + 유형별 매도 규칙** (자본 재배치를 본인이 수행) |
| 게이트 A: 10년 연속 흑자 | → | **린치 6분류** — 경기순환주·회생주에 각각의 매매 규칙을 준다 |
| 게이트 D: 1달러 테스트 | → | **PEG ≤ 1.0** — 시장의 재평가에 의존하지 않는 지표 |
| 게이트 C·E: 소유주이익 DCF | → | **PEG + 배당조정 PEG** (사칙연산만으로 계산 가능) |
| "영원히 보유" | → | **스토리 기반 보유** — 스토리가 유효한 동안 보유, 끝나면 매도 |
| "훌륭한 경영진" 정성 판단 | → | **내부자 매수 + 자사주 소각** (DART 공시로 객관 확인) |
| "이해 가능한 사업" 정성 판단 | → | **2분 스피치 테스트** (설명 못 하면 매수 금지) |

## 10.3 린치 6분류 — 한국형

린치의 핵심 통찰은 **"모든 주식에 같은 잣대를 대지 마라"** 다.
유형을 먼저 정하고, 유형에 맞는 규칙을 적용한다. 버핏의 단일 게이트가 한국에서 막히는 문제가
바로 여기서 풀린다 — 경기순환주를 배제하는 대신 **경기순환주 전용 규칙**을 준다.

### 분류 순서 (반드시 이 순서로)

```
1. 경기순환 업종인가?  ──예──▶ ④ 경기순환주  (다른 분류 적용 금지)
   (반도체·디스플레이·화학·정유·철강·비철·조선·해운·건설·자동차·기계)
   또는 10년 영업이익 변동계수 > 0.8
        │아니오
        ▼
2. PBR < 0.7 이고 (순현금+투자부동산)/시총 > 0.5 ? ──예──▶ ⑥ 자산주
        │아니오
        ▼
3. 최근 3년 내 영업적자 있었고 최근 2분기 연속 흑자? ──예──▶ ⑤ 회생주
        │아니오
        ▼
4. 3년 매출 CAGR ≥ 20% 이고 영업흑자? ──예──▶ ③ 고성장주
        │아니오
        ▼
5. 시총 상위 20% 이고 3년 이익 CAGR 8~15%? ──예──▶ ② 대형우량주
        │아니오
        ▼
                                          ① 저성장주
```

> **순서가 중요한 이유:** 경기순환주는 **사이클 정점에서 고성장주처럼 보이고, 저점에서 회생주처럼 보인다.**
> 업종으로 먼저 걸러내지 않으면 반드시 오분류한다. 린치가 반복해서 경고한 함정이다.

### 유형별 규칙

| 유형 | 매수 조건 | 매도 조건 | 목표 비중 |
|---|---|---|---|
| **③ 고성장주** | PEG < 1.0 · 부채비율 < 100% · **확장 초기**(매장/생산능력 증가 진행 중) · 시총 하위 70% | 성장률 20% 미만 둔화 2분기 연속 · PEG > 2.0 · 확장 종료 | **30~40%** |
| **② 대형우량주** | PEG < 1.0 · 52주 저점권 · 10년 중 적자 ≤ 1회 | 30~50% 수익 시 교체 · PEG > 1.5 | **20~30%** |
| **④ 경기순환주** | **PER이 높을 때**(이익 바닥) · 재고 감소 전환 · 제품가격/스프레드 반등 · 부채비율 < 150% | **PER이 낮을 때**(이익 정점) · 재고 증가 전환 · 신규 증설 발표 러시 | **10~20%** |
| **⑤ 회생주** | 부채 상환 계획 확정 · OCF 흑자 전환 · 유상증자 계획 없음 | 정상화 완료 시 **다른 유형으로 재분류** | **0~10%** |
| **⑥ 자산주** | **가치 실현 촉매 존재 시에만**(자사주 소각·배당 확대·자산 매각 결의) | 자산 실현 완료 | **0~10%** |
| **① 저성장주** | 원칙적으로 제외. 배당 목적만 | 배당 삭감 | **0~10%** |

> **④ 경기순환주의 "PER이 높을 때 사라"** 는 직관에 반하지만 린치의 핵심 규칙이다.
> 이익이 바닥이면 PER이 치솟고, 이익이 정점이면 PER이 낮아 보인다. **PER의 방향을 거꾸로 읽어야 한다.**
> 한국 시장은 이 유형의 비중이 크므로, 이 규칙 하나가 버핏 시스템 대비 가장 큰 차이를 만든다.

## 10.4 PEG — DCF의 대체

버핏의 10년 DCF를 **사칙연산 한 줄**로 바꾼다. 재량이 개입할 여지가 없어 재현성이 더 높다.

```
PEG = PER ÷ 연평균 이익성장률(%)

  · 성장률 = 최근 3년 EPS CAGR      (단년 왜곡 방지)
  · 성장률 상한 25%로 절단          ★그 이상은 지속 불가로 간주
  · 성장률 ≤ 0 이면 PEG 계산 불가 → 고성장주 분류에서 탈락

배당조정 PEG = PER ÷ (이익성장률 + 배당수익률)
```

| PEG | 판정 |
|---|---|
| < 0.5 | 매우 매력적 |
| < 1.0 | **매수 검토** |
| 1.0 ~ 1.5 | 보유는 가능, 신규 매수 아님 |
| > 2.0 | **회피** |

**적용 금지:** ④ 경기순환주(이익이 사이클에 따라 요동쳐 성장률이 무의미), ⑤ 회생주, ⑥ 자산주.
이 세 유형은 각각 재고·부채·자산 기준으로 판단한다. 린치 본인이 명시한 제약이다.

## 10.5 발굴 — 린치의 "아는 것에 투자하라"를 한국에 맞추기

린치의 원칙은 한국에서 **절반만 통한다.** 한국 시총 상위는 반도체·자동차부품·화학 등
**B2B 수출기업**이 많아 소비자로서는 관찰할 수 없기 때문이다.

그래서 **2트랙**으로 나눈다.

### 트랙 A — 소비 트랙 (일상 관찰)
대상 업종: 내수 소비재 · 유통 · 식음료 · 화장품 · 의류 · 게임 · 엔터 · 프랜차이즈 · 통신

```
매주 기록할 것 3가지
  1. 이번 주 내가 실제로 돈을 쓴 곳 (영수증을 보라)
  2. 최근 3개월 사이 갑자기 자주 보이기 시작한 브랜드·매장·앱
  3. 품절·대기·예약이 걸린 제품
```

### 트랙 B — 직업 트랙 (업계 관찰) ★한국에서 더 중요
린치도 "당신이 일하는 업계에서 찾아라"를 강조했다. B2B 비중이 큰 한국에서는 이쪽이 주력이 된다.

```
본인 업계에서 관찰할 것
  · 우리 회사에 주문이 늘고 있는 거래처
  · 납품 단가를 올려 받는 회사 (= 협상력이 생겼다)
  · 경쟁사가 못 따라오는 회사
  · 신규 설비를 짓고 있는 회사
  · 인력을 공격적으로 뽑는 회사 (채용 공고는 공개 정보다)
```

> **이것이 개인이 기관보다 유리한 유일한 영역이다.** 애널리스트는 실적 발표 후에 알지만,
> 그 업계에서 일하는 사람은 **주문서와 채용 공고에서 몇 달 먼저 본다.**
> 버핏의 사적 협상 거래를 대체하는 것이 바로 이 정보 우위다.

### 소외 종목 필터 (린치의 "아직 발견되지 않은 주식")
```
· 기관 보유 지분율 낮음        (DART·거래소 공시로 확인)
· 애널리스트 리포트 거의 없음  (증권사 리서치 검색으로 확인)
· 시총 하위 70%
· 업종이 지루함 (린치: 지루한 이름일수록 좋다)
```

## 10.6 실행 절차 — 주말 2시간 루틴

일반 직장인이 실제로 지킬 수 있는 분량으로 설계했다. 이걸 못 지키면 시스템이 아니다.

### 신규 종목 (1종목당 약 2시간)

| 단계 | 시간 | 내용 |
|---|---|---|
| 1. 발굴 | 30분 | 트랙 A·B에서 후보 3개 추출 |
| 2. 1차 숫자 확인 | 20분 | 네이버 금융에서 **5개 숫자**: 시가총액 · PER · 3년 이익성장률 · 부채비율 · 최근 3년 흑자 여부 → **PEG 계산** |
| 3. 유형 분류 | 10분 | §10.3 분류 순서도를 따라 6유형 중 하나로 확정 |
| 4. **2분 스피치 작성** | 20분 | 아래 템플릿. **쓰지 못하면 매수 금지** |
| 5. DART 리스크 점검 | 30분 | §10.7 체크리스트 |
| 6. 결정 | 10분 | 유형별 매수 조건 충족 여부 → 매수 or 관찰 목록 |

### 2분 스피치 템플릿 (린치의 핵심 규율 장치)

```
1) 이 회사는 ______ 을 팔아서 돈을 번다.
2) 지금 ______ 이 좋아지고 있다.  (반드시 숫자로: 매출 __%, 마진 __%p, 수주 __억)
3) 이 종목은 [고성장주 / 대형우량주 / 경기순환주 / 회생주 / 자산주 / 저성장주] 다.
4) 내가 지금 사는 이유는 PEG가 ____ 이기 때문이다.  (경기순환주는 재고/스프레드로 대체)
5) ______ 이 일어나면 내 판단이 틀린 것이고, 그때 판다.   ← 무효화 조건
```

**5번을 못 쓰면 그 종목은 사지 않는다.** 무효화 조건이 없는 투자는 손절 기준도 없다.

### 분기 점검 (종목당 30분, 실적 발표 후)

```
□ 2분 스피치의 (2)번 숫자가 여전히 개선 중인가?
□ 유형이 바뀌었는가? (고성장주 → 대형우량주로 둔화되지 않았나)
□ (5)번 무효화 조건이 발생했는가?
□ PEG가 매도 구간에 들어왔는가?
□ 재고 증가율 > 매출 증가율 인가?   ← 린치의 조기 경보 지표
```

## 10.7 한국 특수 리스크 체크리스트 (린치가 겪지 않은 것)

미국에는 없거나 드문, **한국 고유의 주주가치 훼손 경로**다. DART에서 확인한다.

| 항목 | 확인 방법 | 해당 시 |
|---|---|---|
| **물적분할 이력·가능성** | 사업보고서 사업부문 구성. 핵심 사업부가 별도 법인인가 | **자산주·고성장주에서 특히 치명적.** 해당 시 제외 |
| 지주회사 여부 | 회사명 "홀딩스"·"지주", 사업보고서 | 지주사 할인 감안. 자산주 논리 적용 금지 |
| 미상환 CB/BW | 주요사항보고서 | 잠재주식/시총 ≥ 15% → 제외 |
| 유상증자 이력 | 3년 내 2회 이상 | 제외 |
| 최대주주 지분·변동 | 최대주주 현황 | 15% 미만 + 3년 내 2회 이상 변경 → 제외 |
| 관계사 거래 비중 | 특수관계자 거래 주석 | 매출의 30% 초과 → 감점 |
| 관리종목·불성실공시 | KIND | 해당 시 제외 |
| 감사의견 | 감사보고서 | 적정 아니면 제외 |

> **⑥ 자산주에 대한 경고:** 린치의 자산주 논리는 "숨은 자산이 언젠가 주가에 반영된다"는 전제 위에 있다.
> 한국에서는 **물적분할·지주사 구조·터널링**으로 그 자산이 소액주주에게 도달하지 않을 수 있다.
> 따라서 한국형에서는 **가치 실현 촉매가 이미 공시된 경우에만** 자산주를 매수한다.
> 촉매 없는 저PBR은 영원히 저PBR일 수 있다.

## 10.8 포트폴리오 운용

| 항목 | 규칙 | 근거 |
|---|---|---|
| 종목 수 | **20~30** | 린치는 분산을 옹호했다. 다만 개인이 관리 가능한 상한이 30 |
| 유형 배분 | 고성장 30~40% / 대형우량 20~30% / 경기순환 10~20% / 나머지 0~10%씩 | |
| **리밸런스** | **연 1회** (사업보고서 공시 후 4월) | 중소형주 유니버스에서 월 1회 대비 연 +2.9~3.3%p (§10.9). 대형주만 다루면 이 이득은 사라진다 |
| 신규 자금 | 매월 적립, 조건 충족 시에만 투입 | 레버리지 대체 |
| 현금 | 조건 충족 종목이 부족하면 현금 보유 | 강제 매수 금지 |
| 최대 비중 | 종목당 10%, 업종당 25% | |

### 매도 규칙 — 4가지
```
S1. 스토리 종료 : 2분 스피치 (5)번 무효화 조건 발생        → 전량
S2. 유형 전환   : 고성장주가 성장 둔화 → 재분류 후 규칙 재적용  → 부분
S3. 밸류 도달   : 유형별 PEG 상한 초과                      → 부분
S4. 더 좋은 기회: PEG가 현저히 낮은 대체 종목 존재            → 교체

※ 주가 하락 자체는 매도 사유가 아니다.
   스토리가 유효한데 가격만 내렸다면 → PEG 하락 → 추가 매수 검토
```

## 10.9 실측 검증 — 린치식 운용 방식은 효과가 있는가

재무 데이터가 없어 PEG·유형분류는 검증하지 못했다. 다만 **린치식 포트폴리오 운용 방식**
(분산 · 낮은 회전율 · 뜨거운 주식 회피)이 앞선 실패(`docs/08`)를 고치는지는 검증했다.
데이터·방법은 `docs/08`과 동일하다(2015~2025, 생존편향 제거, 비용 반영).

### ⚠️ 측정 오류 정정

첫 실행에서 "연 1회 리밸런스가 월 1회보다 연 1.3~4.9%p 우수"라는 결과가 나왔으나,
**이는 측정 오류였다.** 연 1회 전략의 평가를 연간 스냅샷으로만 기록해
① 기중 낙폭이 MDD에 반영되지 않았고 ② 시작·종료 시점이 월간 시리즈와 어긋났다.

**모든 전략을 월간 시가평가로 통일해 재측정한 결과가 아래다.** 이것이 정확한 수치다.

### 재측정 결과 (2015~2025, 월간 시가평가, 비용 반영)

| 전략 | CAGR | MDD | Sharpe | vs KOSPI | 연회전율 |
|---|---|---|---|---|---|
| **KOSPI 지수** | **7.32%** | −34.6% | 0.24 | — | — |
| 저변동성 대형주200 · 15종목 · 월 | 7.16% | −45.8% | 0.25 | −0.16%p | 3.69 |
| 저변동성 대형주200 · 15종목 · **연1회** | 6.93% | −40.2% | 0.23 | −0.38%p | 0.61 |
| 저변동성 대형주200 · 50종목 · **연1회** | 6.59% | −46.5% | 0.22 | −0.73%p | 0.48 |
| 저변동성 대형주200 · 50종목 · 월 | 6.13% | −40.5% | 0.18 | −1.19%p | 2.79 |
| 저변동성 전체60% · 50종목 · **연1회** | **4.58%** | −37.5% | 0.11 | −2.74%p | 0.67 |
| 저변동성 전체60% · 30종목 · **연1회** | **4.18%** | −32.8% | 0.09 | −3.14%p | 0.69 |
| 저변동성 전체60% · 50종목 · 월 | 1.70% | −42.2% | −0.09 | −5.62%p | 4.36 |
| 저변동성 전체60% · 30종목 · 월 | 0.85% | −40.4% | −0.17 | −6.47%p | 4.66 |

### H2. 낮은 회전율 — △ **소형주에서만 효과**

| 유니버스 | 종목수 | 월 1회 | 연 1회 | 차이 |
|---|---|---|---|---|
| **전체60%**(중소형 포함) | 30 | 0.85% | **4.18%** | **+3.33%p** |
| **전체60%** | 50 | 1.70% | **4.58%** | **+2.88%p** |
| 대형주200 | 50 | 6.13% | 6.59% | +0.46%p |
| 대형주200 | 15 | **7.16%** | 6.93% | −0.23%p |

**중소형주가 섞인 유니버스에서는 연 1회 리밸런스가 월 1회보다 연 2.9~3.3%p 우수하다.
반면 대형주만 다루면 차이가 사라지거나 오히려 월 1회가 낫다.**

경제적으로 자연스러운 결과다 — 거래비용(특히 슬리피지)은 유동성이 낮을수록 크므로,
회전율을 줄이는 이득도 소형주에서 크다. 대형주는 비용이 작아 리밸런스를 자주 하는
이득이 비용을 상쇄한다.

> **린치 시스템에 주는 함의:** 이 시스템은 소외된 중소형주를 발굴하는 구조이므로
> **연 1회 리밸런스가 맞다.** 다만 그 근거는 "낮은 회전율이 항상 좋다"가 아니라
> **"중소형주에서 거래비용이 크기 때문"** 이다. 대형주 위주로 운용한다면 이 규칙의 이득은 사라진다.

### H1. 분산(종목 수) — ❌ 효과 없음

종목 수를 늘려도 개선되지 않았다. 대형주 월 1회에서는 15종목(7.16%)이 50종목(6.13%)보다 나았고,
연 1회에서도 일관된 방향이 없었다.
**`docs/08`에서 세운 "15종목 집중이 문제"라는 가설은 기각된다.** 분산은 해법이 아니었다.

### H3. '뜨거운 주식 회피' 필터 — ❌ 효과 없음

### H3. '뜨거운 주식 회피' 필터 — ❌ 효과 없음

린치의 1순위 금기(모멘텀 상위 30% 배제)를 저변동성 전략에 추가로 적용해 봤다.

| 유니버스 | 종목수 | 주기 | 기본 | 핫 배제 | 차이 |
|---|---|---|---|---|---|
| 대형주200 | 30 | 월 | 5.69% | 4.31% | **−1.38%p** |
| 대형주200 | 50 | 연1회 | 7.96% | 7.86% | −0.10%p |
| 전체60% | 50 | 월 | 0.61% | −1.18% | **−1.79%p** |
| 전체60% | 50 | 연1회 | 5.54% | 4.49% | **−1.05%p** |

**8개 조합 전부에서 악화됐다.** 이유는 명확하다 — **저변동성 선택이 이미 뜨거운 주식을 배제하고 있다.**
급등주는 정의상 고변동성이므로, 별도 필터는 중복이며 좋은 종목까지 함께 잘라낸다.

> 이건 린치가 틀렸다는 뜻이 아니다. **린치의 "뜨거운 주식 회피"는 이미 다른 규칙에 흡수되어 있으므로
> 중복 적용하지 말라**는 뜻이다. 규칙을 더 넣는 것이 항상 나은 것은 아니라는 실증이다.

### 랜덤 대조군 — 종목 선정 자체는 실력이 맞다

동일 조건(대형주200 · 50종목 · 연 1회)에서 **무작위 선택 150회**와 비교했다.

```
랜덤 150회 CAGR: 5%ile −7.74% │ 중앙값 −3.78% │ 95%ile −1.37% │ 평균 −3.96%

  저변동성 50종목 연1회 : +6.59%  →  100.0%ile  ✅ 150개 전부 상회
  KOSPI 지수           : +7.32%  →  100.0%ile
```

**저변동성 선정은 무작위 대비 명백한 실력이다**(랜덤 평균 −3.96% vs 전략 +6.59%, 격차 10.5%p).
그럼에도 **KOSPI 지수를 넘지 못했다.** `docs/08`의 결론이 다시 확인된다 —
**"종목을 잘 고르는 능력"과 "지수를 이기는 것"은 다른 문제다.**

### 검증 요약

| 가설 | 결과 |
|---|---|
| H1 분산 확대 | ❌ 기각 |
| H2 낮은 회전율 | △ **중소형주에서만** (+2.9~3.3%p) |
| H3 뜨거운 주식 회피 | ❌ 기각 (중복 규칙) |
| 저변동성 선정의 유의성 | ✅ 랜덤 100%ile |
| **KOSPI 지수 초과** | ❌ **12개 조합 전부 실패** (최고 7.16% vs 7.32%) |

## 10.10 여전히 복제할 수 없는 것 (정직한 고지)

린치로 대체해도 남는 격차가 있다.

| 린치가 가졌던 것 | 개인의 현실 | 대체 |
|---|---|---|
| 연 수백 회의 기업 탐방·경영진 미팅 | 불가능 | IR 자료 · 사업보고서 · 뉴스 · **본인 업계 정보**(트랙 B) |
| 하루 종일 리서치 | 주말 2시간 | 종목 수를 20~30으로 제한, 연 1회 리밸런스 |
| 마젤란의 1,400 종목 관리 | 불가능 | 20~30 종목 + **나머지는 인덱스 ETF** |
| 애널리스트 조직 | 없음 | 소외 종목에 집중(기관이 안 보는 곳) |

### 기대치를 정직하게

- **검증한 12개 조합 전부가 KOSPI 지수에 미달했다.** 최고 조합(저변동성 대형주 15종목 월)이
  7.16%로 지수 7.32%에 0.16%p 못 미쳤다. `docs/08`의 결론과 완전히 일치한다.
- 다만 **저변동성 선정 자체는 무작위 대비 100%ile로 실력이 확인됐다.**
  즉 "고르는 능력은 있으나 지수를 넘기엔 부족하다"가 정확한 상태다.
- 린치 시스템의 검증 가능한 부분(운용 방식)은 효과가 확인됐지만,
  **핵심 부분(PEG·유형분류·발굴)은 재무 데이터가 없어 검증하지 못했다.**
- 따라서 이 시스템의 정직한 기대치는 **"시장을 확실히 이긴다"가 아니라
  "시장 수준의 수익을, 본인이 이해하는 종목으로, 낮은 회전율로 얻는다"** 이다.

### 권고 구조

```
핵심(60~70%)  : 저비용 인덱스 ETF 적립       ← 시장 수익률 확보
위성(30~40%)  : 린치 시스템 20~30종목        ← 본인의 정보 우위 활용
                (연 1회 리밸런스, 2분 스피치 필수)
```

**위성 부분이 인덱스를 못 이기면 비중을 줄인다.** 3년 단위로 본인의 성과를 KOSPI와 비교해
기록하고, 이기지 못하면 핵심 비중을 늘리는 것이 규칙이다.
자기 실력을 검증하는 절차를 시스템 안에 넣어두는 것 — 이것이 린치가 일반 투자자에게 준
가장 실용적인 조언이다.
