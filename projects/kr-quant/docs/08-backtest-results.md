# 8. 실측 백테스트 결과 — 이 시스템은 시장을 이기는가

> **한 줄 답:** 검증 가능했던 범위에서는 **이기지 못했다.**
> 가격·추세 기반 전략은 전부 KOSPI 지수에 크게 못 미쳤고, 다수는 파괴적으로 실패했다.
> 재무 기반 축(F·D)은 데이터 확보 실패로 검증하지 못했다 — 이 한계를 숨기지 않는다.

---

## 8.1 무엇을 실제로 돌렸나

| 항목 | 내용 |
|---|---|
| 데이터 | FinanceDataReader(네이버 경유) 일봉, **661만 행 / 3,155종목 / 2008-01-02 ~ 2025-12-30** |
| 유니버스 | 현재 상장 2,505 + **과거 상장폐지 664** → **생존편향 제거** |
| 리밸런스 | 월 1회 (월말 종가 신호 → **익일 시가 체결**) |
| 비용 | 수수료 0.015%(편도) + 매도세 0.20% + 슬리피지 0.10%(편도) |
| 보유 | 15종목 동일가중 |
| 벤치마크 | ① KOSPI 지수 ② **동일가중 평균 종목**(같은 유니버스, 무비용) |

### 확보에 실패한 데이터 (중요)

| 데이터 | 결과 | 영향 |
|---|---|---|
| KRX 정보데이터시스템 | ❌ 로그인 필수(`LOGOUT`/400) | PER·PBR·수급(외국인/기관) 시계열 확보 불가 |
| DART 재무제표 | ❌ API 키 없음 | **F축·D축 검증 불가** |
| 네이버 재무 | ⚠️ 최근 3년 + 재작성본만 | PIT 백테스트 불가 |

**따라서 이 문서가 검증한 것은 7축 중 T축(기술)과 그 파생 전략뿐이다.**
F(재무)·D(공시)·S(수급)·E(시나리오)·Q·C 축은 **미검증 상태**다.
"시스템 전체가 실패했다"가 아니라 **"검증 가능했던 절반이 실패했다"** 가 정확한 서술이다.

## 8.2 데이터 정제 — 이걸 안 하면 결과가 완전히 뒤집힌다

첫 실행에서 MDD −99%가 나왔다. 원인을 추적하니 **전략이 아니라 데이터 문제**였다.

| 발견 | 사례 |
|---|---|
| 이상 가격 | `008080`: 주가가 **1원**으로 기록된 구간 → 67,000원으로 점프 (66,999배) |
| 거래정지 공백 | `101970`: **2015-03-16 → 2025-03-28 사이 10년 공백**을 `pct_change`가 하루 수익률로 계산 |
| pandas 기본 패딩 | `pct_change()`가 NaN을 앞값으로 채워 공백 구간에 가짜 수익률 생성 |

**정제 규칙 3가지를 적용해 170만 건(전체의 약 20%)의 이상 수익률을 마스킹했다.**

```python
1. 100원 미만 가격 → 결측 처리
2. 직전 유효 관측이 10거래일 초과 → 수익률 무효 (거래정지 공백)
3. 가격제한폭 초과(2015-06-15 이전 ±18%, 이후 ±33%) → 데이터 오류로 간주
4. 기술적 지표는 전부 정제된 총수익지수(TRI) 위에서 계산
5. 유니버스 자격에 '최근 300거래일 중 270일 이상 거래' 연속성 요건 추가
```

> 이것이 설계 문서 `docs/02` §2.9의 **DQ-04 검사**다. 설계에는 있었지만 엔진에 구현하지 않아
> 첫 실행이 통째로 틀렸다. **데이터 품질 검사를 건너뛴 백테스트는 결과가 아니라 소음이다** —
> 이 프로젝트가 얻은 가장 값비싼 교훈이다.

## 8.4 왜 이렇게 처참한가 — 모멘텀이 고른 종목을 직접 확인했다

데이터 오류가 아니라 **진짜 종목**을 고른 결과였다. 2018-06-29 기준 모멘텀 상위 15종목:

| 종목 | 12개월 모멘텀 | 다음 1개월 |
|---|---|---|
| HLB | +752.1% | **−30.2%** |
| 퓨처코어 | +713.4% | +27.7% |
| 유에스티 | +593.9% | +32.9% |
| 네이처셀 | +502.4% | **−52.9%** |
| 프리티 | +471.0% | −19.2% |
| 안트로젠 | +429.2% | −17.9% |
| 에이프로젠 | +390.2% | −22.6% |
| 셀트리온제약 | +341.2% | −22.4% |

**한국 시장에서 "12개월 급등 종목 상위 15개"는 사실상 바이오·테마 버블 바스켓이다.**
이 종목들은 실제로 폭등했고, 실제로 폭락했다. 전략이 산 것은 알파가 아니라 **버블의 꼭짓점**이었다.

이 발견은 설계 문서 §8의 제약 조건("단기 테마 추격매매만 추천하지 않는다")과 `ANTI-01` 회피 패턴이
**왜 필요한지를 데이터로 증명한 것**이기도 하다. 다만 그 방어 장치는 재무 축(F·D)에 의존하는데,
바로 그 축을 이번에 검증하지 못했다.

## 8.5 KRQ_T — 설계 문서의 T축도 실패했다

설계 문서에서 정의한 T축(월봉 MA12 상회 + 기울기 양(+) + 주봉 추세 + 거래량 확인 +
RSI 45~78 과열 배제 + 이격도 140 이하)을 그대로 구현해 돌린 결과가 `KRQ_T`다.

**−15.11% CAGR**(전체 유니버스) / **−8.42%**(대형주). 과열 배제 필터가 있어도 순수 모멘텀보다 나을 뿐, 시장에는 한참 못 미쳤다.

| 시사점 |
|---|
| RSI·이격도 같은 **과열 필터는 손실을 줄이지만 방향을 바꾸지는 못한다** |
| 기술적 조건만으로 종목을 고르는 것은 한국 시장에서 마이너스 기대값이다 |
| 설계의 "4중 동시충족" 중 **기술 축 단독은 무가치**하다는 것이 실증됐다 |

이것은 설계를 부정하는 결과가 아니라 **설계의 핵심 전제를 지지하는 결과**다 —
"한 축만 좋은 종목은 통과할 수 없다"는 게이트 구조가 왜 필요한지를 보여준다.
다만 나머지 축이 실제로 그 구멍을 메우는지는 **여전히 미검증**이다.

## 8.6 유일하게 살아남은 것: 저변동성

LOWVOL(60일 변동성 하위 15종목)만이 평균 종목을 의미 있게 이겼다.

| | CAGR | 평균종목 대비 | IR | 월승률 |
|---|---|---|---|---|
| 전체 유니버스 | +1.09% | +2.20%p | 0.05 | 54.6% |
| **대형주 유니버스** | **+6.37%** | **+16.76%p** | **0.97** | **60.0%** |

대형주에서 IR 0.97, 월승률 60%는 **통계적으로 견고한 신호**다. 그러나
**KOSPI 지수는 여전히 못 이겼다**(+6.37% vs +7.32%). 더 낮은 위험으로 비슷한 수익을 냈을 뿐이다.

이는 우연이 아니라 잘 알려진 **저변동성 이상현상(low-volatility anomaly)** 이며,
버핏 수익률 분해의 핵심 요소인 **저베타(BAB) 노출**과 같은 것이다(`docs/09` 참조).
실제로 본 프로젝트에서 측정한 버크셔의 베타는 **0.50(1980–99) / 0.64(2000–25)** 였다.

**한국 실측과 버핏 실측이 같은 곳을 가리킨다** — 초과수익의 원천은
"많이 오를 것을 고르는 것"이 아니라 **"변동성이 낮은 것을 고르고 오래 들고 있는 것"** 이다.

## 8.7 랜덤 대조군 — 실력인가 우연인가 ★결정적 검증

같은 유니버스(대형주 200)에서 **무작위로 15종목을 골라 월 리밸런스하는 포트폴리오 200개**를
동일 조건·동일 비용으로 돌렸다. 전략이 이 분포를 못 이기면 "종목 선정 능력"은 없는 것이다.

```
랜덤 200개 포트폴리오의 CAGR 분포 (2015~2025, 대형주 15종목)
  5%ile −19.02%  │  중앙값 −12.45%  │  95%ile −6.07%  │  평균 −12.61%

        ▁▂▄▆█████▆▄▂▁
  −25%  −19%  −12%  −6%   0%        +6.4%
                                      ▲
                                   LOWVOL
                              (200개 전부를 상회)
```

| 전략 | CAGR | 랜덤 대비 백분위 | 판정 |
|---|---|---|---|
| **LOWVOL** | **+6.37%** | **100.0%ile** (200개 전부 상회) | ✅ **유의미한 선정 능력** |
| **KRQ_T_STRICT** | −0.43% | **99.5%ile** | ✅ 유의 (수준은 여전히 (−)) |
| KRQ_T | −8.42% | 88.5%ile | △ 미약 |
| MOM_12_1 | −20.24% | **4.0%ile** | ❌ **무작위보다 나쁨** |
| REVERSAL | −19.10% | 5.0%ile | ❌ 무작위보다 나쁨 |
| TREND_MOM | −21.80% | **2.0%ile** | ❌ **무작위보다 나쁨** |

### 여기서 세 가지가 동시에 드러난다

1. **저변동성 선정은 진짜다.** 랜덤 200개를 전부 이겼다. 우연으로 설명되지 않는다.
2. **모멘텀·추세·역발상 선정은 해롭다.** 하위 2~5%ile — **동전 던지기보다 못하다.**
   단순히 "알파가 없다"가 아니라 **적극적으로 가치를 파괴**한다.
3. **그런데도 KOSPI 지수(+7.32%)가 LOWVOL(+6.37%)을 이겼다.**
   → 선정 능력이 있어도 **15종목 집중의 대가**가 그것을 상쇄한다.
   랜덤 15종목 평균(−12.61%)이 같은 유니버스의 동일가중 전체(−10.39%)보다 나쁜 것이
   바로 **집중의 비용**(변동성 손실)이다.

> **이것이 이 프로젝트에서 가장 중요한 발견이다.**
> "좋은 종목을 고르는 능력"과 "시장을 이기는 것"은 다른 문제다.
> 저변동성 선정은 랜덤 대비 명백한 실력을 보였지만, 그 실력조차 지수를 넘기엔 부족했다.

## 8.8 이 결과의 한계 (반드시 함께 읽을 것)

| 한계 | 영향 |
|---|---|

| **거래대금 = 수정주가 × 원거래량** | 액면분할 종목의 과거 거래대금이 과소 계상 → 유동성 필터 왜곡 |
| **2010~2014 유니버스 과소** | 2010-06 통과 종목 147개(2025년 1,393개). 초기 구간 신뢰도 낮음 |
| **EW 평균종목의 절대 수준** | −6.7%/−10.6%는 위 왜곡의 영향을 받았을 가능성이 높다. **전략 간 상대 비교는 유효** |
| **배당 미반영** | 가격 수익률만 계산. 실제 총수익은 연 1~2%p 높다 |
| **다중검정** | 7개 전략을 시도했다. 최고 성과 하나만 보면 안 된다 |

**절대 CAGR 수치보다 순위와 부호를 신뢰하라.** 어떤 정제·유니버스 조합에서도
"모멘텀·추세·역발상 계열 < 평균 종목 < KOSPI 지수" 순서는 뒤집히지 않았다.

## 8.9 결론

1. **가격·추세 기반 자동투자는 한국 시장에서 시장 평균을 이기지 못했다.**
   유니버스(전체/대형주), 기간(2010~/2015~), 정제 방식을 바꿔도 순서가 뒤집히지 않았다.
2. **모멘텀·추세·역발상 선정은 무작위보다 나빴다**(하위 2~5%ile). 알파가 없는 정도가 아니라
   적극적으로 가치를 파괴한다. 원인은 한국 시장에서 기술적 상위 종목이 **테마 버블과 겹치기 때문**이다.
3. **저변동성 선정만이 진짜 실력을 보였다** — 랜덤 200개를 전부 상회(100%ile).
   **그럼에도 KOSPI 지수를 못 이겼다**(+6.37% vs +7.32%). 15종목 집중의 비용이 실력을 상쇄했다.
4. **설계 문서의 게이트 구조는 오히려 지지받았다** — "한 축만 좋은 종목은 통과 불가"라는 전제가
   실증됐다. 그러나 **다축 결합이 실제로 작동하는지는 DART 재무 데이터 없이 검증할 수 없다.**
5. 살아남은 요소(저변동성)는 버핏 팩터 분해의 저베타와 같은 것이다(`docs/09`).
   **한국 실측과 버핏 실측이 같은 방향을 가리킨다.**

### 다음에 검증해야 할 것 (사용자가 직접 가능)

DART Open API 키는 **무료**이고 5분이면 발급된다. 그것만 있으면 F·D축을 검증할 수 있다.

```bash
export DART_API_KEY=...                       # opendart.fss.or.kr 무료 발급
krq collect --financials --years 12           # PIT 저장(rcept_dt 필수)
krq backtest --strategy quality_value --from 2013-01-01 --rebalance annual
```

검증 순서는 **F축 단독 → F+저변동성 → 7축 전체**를 권한다.
가장 유망한 가설은 **"퀄리티 + 저변동성"** 이다 — 이번 실측에서 유일하게 살아남은 요소(저변동성)와
버핏 팩터 분해가 동시에 가리키는 방향이기 때문이다.
