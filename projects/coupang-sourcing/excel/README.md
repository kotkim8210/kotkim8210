# 마진계산기 V4 (일반사업자) + 자동 소싱기

원본 **마진계산기 V3.0(법인 기준)** 을 이어받아 **개인 일반사업자 기준**으로 고치고, 빈칸을 채우면 그대로 소싱 판정이 나오도록 확장한 워크북입니다.

📄 산출물: `마진계산기_V4_일반사업자.xlsx`
🔧 생성기: `build_calculator.py` (구조를 바꾸려면 이 파일을 고치고 다시 실행)
🤖 자동채움: `fill_sourcing.py` (크롤러 결과로 연두칸 자동 입력)

## V3(법인) → V4(일반사업자) 무엇이 달라졌나

| 항목 | V3 (법인) | V4 (일반사업자) |
|---|---|---|
| **소득세** | `1차합계 × 16%` 고정 | **종합소득세 누진세율 + 지방소득세 10%** 자동 (연 과세표준 입력 → 세율표에서 자동 결정) |
| **부가세** | `(판매가−비용) × 10%` (마진의 10%) | **매출세액 − 매입세액** 정밀 계산. 간이과세 선택 시 `매출×1.5%` |
| **수입 매입세액** | 반영 없음 | 정식통관이면 **수입부가세를 매입세액으로 공제**, 구매대행이면 공제 0 |
| **환율** | 셀마다 `=원가×300` 하드코딩 | **가정 시트의 환율 1칸**만 고치면 전체 반영 |
| **마케팅비** | `=판매가×15%` 하드코딩 | 동일 유지 + **광고믹스 모드**(CPC÷전환율×광고비중) 선택 가능 |
| **음수 이익 과세** | 적자에도 세금이 음수로 계산됨 | `MAX(0, 이익)` — 적자면 소득세 0 |
| **소싱 판정** | 없음 | **경쟁사가·리뷰·검색량·광고침투율 → 기회점수·GO/검토/SKIP** |

> ⚠️ **세율 참고**: 개인 종합소득세는 누진(6.6%~49.5%, 지방세 포함)이라 규모가 커지면 법인세(9.9%/20.9%)보다 불리해집니다. V3의 16%는 개인 기준 **1,400만~5,000만원 구간(16.5%)** 에 해당합니다. 4대보험·건강보험료는 미반영입니다.

## 시트 구성

### 1. `소싱현황` — 메인
- **노랑칸** = 직접 입력 (상품명·수량·판매가·배송비·원가(위안)·수수료%·물류비·포장비·URL)
- **연두칸(AA~AE)** = 소싱 조사값 → *여기를 채우면 소싱기가 됩니다*
  - `경쟁사 최저가` · `경쟁 리뷰중앙` · `이길만한 경쟁%` · `광고 침투율` · `월 검색량`
- **주황칸(AF~AI)** = 자동 판정
  - `손익분기가` — 마진 안전선을 지키는 최소 판매가
  - `가격여유` — 경쟁사 최저가 − 손익분기가 (음수면 그 가격대에선 못 이김)
  - `기회점수` — 0~100 (신호 없는 항목은 빼고 재정규화)
  - `판정` — **GO / 검토 / SKIP / 역마진** (조건부 서식으로 색상 표시)

하단에 요약(등록 수·GO 수·역마진 수·평균 마진율)과 원본의 **월 목표 → 일 필요 판매수** 계산이 있습니다.

### 2. `가정` — 모든 파라미터를 한 곳에서
사업자 유형·연 과세표준·환율·통관방식·수수료·마케팅·광고믹스(CPC·전환율·광고비중)·판정 기준·가중치·월 목표.
**여기만 고치면 200행 전체가 한 번에 바뀝니다.**

### 3. `세율표` — 종합소득세 누진표 (지방소득세 포함) + 법인세 비교

## 쓰는 순서

1. **`가정` 시트 먼저** — 사업자 유형(일반/간이), 예상 연 과세표준, 환율, 통관방식을 내 상황에 맞게
2. **`소싱현황` 노랑칸** — 후보 상품의 판매가·원가(위안)·수수료%·물류비 입력 → 마진·마진율이 바로 나옴
3. **연두칸** — 쿠팡에서 그 키워드를 검색해 경쟁사 최저가·리뷰수·광고 비중을 적음 → **판정 자동**
4. GO 뜬 것만 실제로 진행

### 연두칸을 자동으로 채우기
```bash
cd projects/coupang-sourcing
pip install "scrapling[fetchers]" && scrapling install   # 크롤러 준비(최초 1회)
export NAVER_AD_API_KEY=... NAVER_AD_SECRET_KEY=... NAVER_AD_CUSTOMER_ID=...  # 검색량(선택)

python excel/fill_sourcing.py excel/마진계산기_V4_일반사업자.xlsx --rows 8-30
```
상품명(C열)을 검색어로 쿠팡을 조사해 AA~AE를 채웁니다. 채운 뒤 엑셀에서 파일을 열면 판정이 자동 재계산됩니다.

## 계산식 (투명하게)

```
공급가 I   = 원가(위안) × 환율                     ← 가정!환율
마케팅 N   = 판매가 × 마케팅%   또는  광고믹스(CPC÷전환율×광고비중)
수수료 P   = 판매가 × 수수료%  +  배송비 × 배송수수료율
부가세 Q   = [일반] (판매가+배송비)/11 − (물류+포장+마케팅+수수료)/11 − 수입공제
             [간이] (판매가+배송비) × 1.5%
1차합계 R  = 판매가 + 배송비 − 공급가 − 물류 − 포장 − 마케팅 − 수수료 − 부가세
소득세 S   = MAX(0, R) × 소득세율(지방포함)         ← 가정!연 과세표준 → 세율표
기타   T   = 판매가 × 기타%
마진   U   = R − S − T
마진율 V   = U ÷ 판매가
```

**손익분기가 AF** = `(공급가+물류+포장) ÷ (1 − 수수료% − 마케팅% − 기타% − 마진안전선 − 1/11)`
> 부가세를 매출세액(1/11) 기준으로 보수적으로 잡아, 실제보다 약간 높게(안전하게) 나옵니다.

**기회점수 AH** = 수요·진입용이·저광고·마진의 가중합 × 100 (가중치는 `가정` 시트)

## 주의 / 한계

- **환율 300원**은 원본 V3의 관례를 그대로 뒀습니다. 실환율(≈195)이 아니라 **국제운임·관세·통관을 얹은 '체감환율'** 로 보입니다. 정식통관으로 정확히 계산하려면 `source.py import` 명령(CIF→관세→수입부가세 분해)을 쓰세요.
- **수수료 K열이 0.3(30%)** 인 행이 많습니다. 쿠팡 마켓플레이스 수수료는 보통 4~10.8%이니, 로켓그로스·위탁 등 다른 조건이 아니라면 실제 요율로 낮춰 잡는 게 정확합니다.
- **부가세 매입공제는 세금계산서 수취를 전제**합니다. 1688 직송금 등 증빙이 없으면 공제되지 않으니 `통관 방식`을 `구매대행`으로 두세요.
- 4대보험·건강보험료, 카드수수료 차감, 반품 재고손실은 미반영입니다.
