# 쿠팡 자동 소싱기 (경쟁강도 + 검색량 + 묶음 마진게이트)

"광고비 최소, 경쟁강도 낮고, 검색량 높고, 리뷰수 대비 순위 올리기 쉽고, 회전 빠른" 쿠팡 소싱 후보를 점수화하고, **도매꾹 묶음을 낱개로 파는 아비트라지에서 진짜 마진이 남는지** 마진계산기로 판정하는 도구입니다. `coupang-naver-crawler`(Scrapling)를 데이터 소스로 재사용합니다.

---

## 0. 먼저: "돈 안 드는 소싱"의 진짜 지렛대 (팩트체크)

이전 대화의 'DC 42V·건전지 저전압 = 인증 면제' 논리는 **방향은 맞지만 두 군데가 위험하게 부정확**합니다. 공식 근거로 정정합니다.

| 주장 | 사실 | 근거 |
|---|---|---|
| DC 42V/AC 30V 이하 = 전기안전 면제 | ✅ 대체로 맞음. **단 예외 품목 있음**(전기찜질기·전격살충기·공기청정기 등은 저전압이어도 대상) | [전안법 시행규칙 별표 비고](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=1651&ccfNo=2&cciNo=1&cnpClsNo=1) |
| USB 5V LED = 인증 불필요 | ⚠️ **전기안전은 면제, 전자파(EMC)는 조건부**. 단순 ON/OFF는 면제지만 제어보드·충전·무선통신 있으면 EMC 대상 | [소형 LED EMC](https://kcelectric.quv.kr/48) |
| (예시) 심리스팬티 = 저비용 | ❌ **속옷은 저전압과 무관하게 '공급자적합성확인' 대상 섬유제품**(팬티류 명시). 시험성적서 필요 | [안전기준준수/공급자적합성확인](https://www.safetykorea.kr/policy/targetsSafetyQuality) |

**진짜 지렛대는 '저전압 꼼수'가 아니라 국내 도매(도매꾹) 사입 재판매입니다.**
최초 수입자/제조사가 이미 KC(또는 공급자적합성확인)를 받은 제품을 **국내에서 사입해 되파는 것**이라면, 재판매자가 다시 인증받을 필요가 없습니다(원 인증번호·KC마크 승계). 즉 인증비 0원의 핵심은 **"국내에 이미 유통 중인 KC 완료품을 도매로 떼오는 것"**입니다. 단, 쿠팡 상품등록 시 KC 정보 입력을 요구할 수 있으니 **도매처에서 KC 인증번호/성적서를 받아두세요.** ([근거](https://www.certinara.co.kr/57/?bmode=view&idx=12851349))

> ⚠️ 어린이용(13세 이하)으로 표기·판매하면 저전압·건전지여도 어린이제품안전특별법으로 반드시 인증. 성인용 타깃 유지.

## 1. 무엇을 측정하나 (요청 → 지표 매핑)

| 사용자 요청 | 이 도구의 지표 | 소스 |
|---|---|---|
| 검색량이 높고 | 월간 검색량(PC+모바일) | 네이버 검색광고 API (무료, 키 필요) |
| 경쟁강도가 낮으며 | 1페이지 **리뷰수 중앙값**이 낮을수록 ↑ | 쿠팡 검색결과 크롤링 |
| 리뷰수 대비 순위 올리기 쉽고 | **이길만한 경쟁자 비율**(리뷰<50 비중) | 쿠팡 검색결과 |
| 광고비 최소한 | **광고 침투율**(상단 광고 비중)이 낮을수록 ↑ | 쿠팡 검색결과(`is_ad`) |
| (배송 경쟁) | **로켓 침투율**(높으면 셀러배송 불리) | 쿠팡 검색결과(`is_rocket`) |
| 진짜 마진 나는지 | **묶음 랜디드원가 vs 경쟁 시세**로 마진 판정 | 마진계산기(내장) |
| 판매회전율 | ⚠️ 쿠팡은 판매량 비공개 → 리뷰 증가속도로 근사(같은 키워드 반복 크롤로 추적) | (한계, 아래 참고) |

이들을 **기회 점수(0~100)** 로 합성합니다:
```
기회점수 = 100 × Σ(가중치 × 하위점수)
  demand(검색량) · entry(진입용이) · low_ad(저광고) · delivery(저로켓) · margin(마진게이트)
```
가중치·안전선은 `config/sourcing.json`에서 조정합니다. 신호가 없으면(예: API 키 미설정) 그 항목을 빼고 나머지로 재정규화합니다.

## 2. 핵심: 묶음 아비트라지 마진 판정

사용자 시나리오 그대로 — **도매꾹 5장 묶음을 택배 1번으로 사입 → 쿠팡에 1장씩 판매**:

```bash
# 5장 9,000원 + 사입배송 3,000원 → 개당 랜디드원가 2,400원. 낱개 9,900원에 팔면?
python source.py margin --sale 9900 --bundle-price 9000 --bundle-qty 5 --inbound 3000 --category 언더웨어
```
```
개당 랜디드원가 : 2,400원 (순매입 1,800 + 배송분담 600)
  - 쿠팡수수료   : 1,069원   - 고객배송비 : 3,000원   - 포장비 : 200원 ...
→ 순마진 : 3,087원 | 마진율 31.2% | ROI 130%   → [좋음]
```

**이 도구의 가치는 "안 되는 걸 안 된다고 말하는 것"입니다:**
```bash
# 같은 상품을 레드오션 최저가 5,900원에 낱개로 팔면?
python source.py margin --sale 5900 --bundle-price 9000 --bundle-qty 5 --inbound 3000
→ 순마진 : -481원 | 마진율 -8.2%  → [역마진] 팔수록 손해
```
→ 되게 하려면? **① 낱개 프리미엄(9,900원)** 또는 **② 대량사입으로 배송분담↓**(`--bundles 10` → 개당 배송 600→60원):
```bash
python source.py margin --sale 9900 --bundle-price 9000 --bundle-qty 5 --inbound 3000 --bundles 10
→ 순마진 : 3,632원 | 마진율 36.7% | ROI 195%  → [좋음]
```

> ⚠️ **택배비(outbound)는 무료배송이라도 셀러 실부담**입니다. 기본값 3,000원. 0으로 두면 마진이 과대평가됩니다.

### 2-1. 중국 1688 직수입 (환율·관세·수입부가세 포함)

국내 도매가 아니라 **1688 직수입**이면 원가 구조가 완전히 달라집니다. `import` 명령이 정식 통관 기준으로 분해합니다:

```
물품가(CNY) = 개당단가×수량 + 중국내륙배송  →  ×환율 = 물품가(KRW)
CIF(과세가) = 물품가 + 국제운임 + 보험
관세        = CIF × 관세율(HS코드별, 기본 8%)   ← 한중FTA 원산지증명(FORM E)이면 감면
수입부가세  = (CIF + 관세) × 10%                ← 일반과세자는 매입세액 공제 → 원가에서 제외
랜디드총액  = CIF + 관세 + 통관·포워더 수수료
```

```bash
python source.py import --sale 24900 --cny 20 --qty 500 --fx 195 --china-ship 300 \
    --weight 400 --per-kg 3500 --duty 0.08 --customs 30000 --outbound 4500 --category 홈인테리어
```
> 💡 **부피화물 주의**: 국제운임은 실중량이 아니라 **부피중량**으로 매겨집니다. 태양광등처럼 가볍고 큰 제품은 운임이 원가의 30~40%를 먹습니다.
> 💡 **환율**: 카드·송금 수수료를 얹어 보수적으로(`--fx`) 잡으세요.

### 2-2. 부가세 (기본값 = 일반과세)

`--vat` 기본값은 **`normal`(일반과세자)** 입니다.
- `normal`: 납부세액 = 매출세액(판매가/11) − 매입세액. 매입세액은 **국내 사입이면 매입가/11**, **수입이면 세관에 낸 수입부가세**입니다(구조가 다르므로 소싱 객체가 각각 계산).
- `simplified`: 간이과세 소매업 근사 ≈ 판매가 × 1.5%
- `none`: 미반영(비교용). **마진이 과대평가되니 실제 판단에 쓰지 마세요.**

### 2-3. 광고비 — "무광고로 팔 수 있나"의 정량적 답

광고비를 세 방식으로 넣을 수 있습니다:

| 방식 | 옵션 | 의미 |
|---|---|---|
| 직접 | `--ad 3000` | 개당 광고비를 원으로 지정 |
| CPC·전환율 | `--cpc 300 --cvr 0.02` | **건당 광고비 = CPC ÷ 전환율** (300÷2% = 15,000원) |
| 목표 ROAS | `--roas 5` | 판매가의 1/5을 광고비로 |

핵심은 **`--ad-share`(광고 기여 비중)** 입니다. 광고비는 광고로 팔린 건에만 붙으므로:
```
개당 평균 광고비 = 건당 광고비 × 광고 판매 비중
```
```bash
# 건당 15,000원이지만 광고로 파는 비중이 20%면 → 개당 평균 3,000원
python source.py import ... --cpc 300 --cvr 0.02 --ad-share 0.2
```
**전량을 광고로 팔면 거의 무조건 역마진입니다.** 오가닉 비중을 올려 `ad-share`를 낮추는 것이 수익의 핵심입니다.

## 3. 키워드 종합 평가 & 랭킹

```bash
# 한 키워드 종합 평가 (경쟁강도+검색량+마진 → 기회점수)
python source.py eval --query "심리스팬티" --bundle-price 9000 --bundle-qty 5 --inbound 3000 --category 언더웨어

# 샤오홍수 트렌드(레드오션 신제품 각도) 키워드를 일괄 평가
python source.py xhs --bundle-price 9000 --bundle-qty 5 --inbound 3000 --category 언더웨어
```
`eval`/`xhs`는 쿠팡 크롤링이 필요합니다(아래 설치). 크롤링이 막히면 경쟁 신호 없이 마진·검색량만으로 점수를 냅니다(크래시 없음).

## 4. 레드오션 신제품 발굴 (샤오홍수)

레드오션이라도 **샤오홍수에서 막 뜨는 후기 좋은 신상**은 쿠팡에 '신제품 각도'로 빈틈이 있습니다. 다만 샤오홍수는 **로그인월+반봇+중국리전**이라 자동수집이 불안정합니다. 두 경로를 제공합니다:

1. **수동(권장·안정)**: 앱에서 눈으로 본 트렌드 키워드를 `config/xhs_manual.json`에 적기 → `xhs` 명령이 쿠팡 기준으로 평가
2. **자동(불안정)**: `--query`로 StealthyFetcher 수집 시도(`__INITIAL_STATE__` 파싱). 실패하면 수동 목록으로 폴백

## 7. 정직한 한계

- **판매회전율**: 쿠팡은 판매량을 공개하지 않습니다. 리뷰수는 '누적 판매 근사'일 뿐, 회전(속도)이 아닙니다. 회전을 보려면 **같은 키워드를 며칠 간격으로 크롤해 리뷰 증가분**을 봐야 합니다(향후 확장 여지).
- **검색량 = 네이버 기준**: 쿠팡 자체 검색량은 비공개라 네이버 검색광고 수치를 프록시로 씁니다. 쿠팡 수요와 100% 일치하진 않습니다.
- **수수료율은 대표값**: `config/coupang_fees.json`의 카테고리 요율은 공개 자료 기반 근사입니다. 실제는 쿠팡 판매자센터(wing)에서 카테고리별로 확인해 교정하세요.
- **라이브 크롤링 미검증(이 저장소 기준)**: 개발 샌드박스 프록시가 스텔스 브라우저를 차단해, 실제 쿠팡 수집은 사용자 PC에서 검증해야 합니다(`coupang-naver-crawler` README 참고). 마진·점수 로직은 오프라인 테스트로 검증됨.
- **KC/법적 판단은 참고용**: §0은 공식 자료 요약이며, 최종 인증 여부는 품목별로 국가기술표준원·안전인증기관에 확인하세요.
