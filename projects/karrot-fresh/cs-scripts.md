# 💬 당근 농수산물 CS 자동응답 · 메일 템플릿 팩

> 목적: 채팅 지옥에서 벗어나기. **당근 비즈프로필의 자체 자동응답**에 그대로 붙여넣을 스크립트 +
> 주문/CS 상황별 응대 템플릿 + 이메일 템플릿 모음.
>
> ⚠️ **솔직한 한계 고지**
> - 당근은 외부 API가 없어 **채팅 실시간 자동봇은 불가**(매크로는 계정 정지 위험). 아래 ①은 **당근이 공식 제공하는 비즈프로필 자동응답** 기능에 *님이 직접 세팅*하는 용도다. 내가 하는 일은 **완성 문구 제공**.
> - 현재 연결된 Gmail 도구는 **라벨 기능만** 있고 **발송/초안 작성 기능이 없다.** 따라서 ③ 이메일은 *자동 발송이 아니라* 붙여넣기용 완성 템플릿이다. (진짜 무인 주문 흐름은 당근 자체 '상품 주문/결제' 기능을 쓰는 게 정답.)

## ① 당근 비즈프로필 자동응답 세팅 (붙여넣기용)

### 웰컴 메시지 (채팅 입장 시 자동 발송)
```
안녕하세요 😊 산지직송 [가게명]입니다.
당일수확 신선 농산물만 정직하게 보내드려요.
아래 자주 묻는 질문에서 바로 확인하실 수 있고, 추가 문의도 편히 남겨주세요!
※ 결제는 안심하실 수 있도록 '당근페이'로 도와드립니다.
```

### 자주 묻는 질문 버튼 3종

**버튼 1 — "언제 받을 수 있나요? (배송/수령)"**
```
당일 오전 11시 이전 주문 건은 산지 당일 직송으로 나갑니다.
· 택배: 오후 발송 → 보통 1~2일 내 수령 (도서산간 +1일)
· 직거래: [동네/장소]에서 [시간대]에 수령 가능
신선도 유지를 위해 아이스팩/완충 포장해 보내드려요.
```

**버튼 2 — "과일에 하자가 있어요 (교환/환불 기준)"**
```
불편을 드려 정말 죄송합니다. 신속히 도와드리겠습니다 🙏
생물 특성상 아래만 보내주시면 바로 처리해드려요.
[수령 후 24시간 이내]
① 운송장 사진 ② 박스 전체 사진 ③ 문제 부위 클로즈업
→ 불량 과수 비율만큼 부분환불 또는 교환해 드립니다.
(중량은 수분감량으로 ±10% 내외 차이가 자연스럽게 생길 수 있는 점 양해 부탁드려요.)
```

**버튼 3 — "위치/주문 방법이 궁금해요"**
```
· 직거래 위치: [지도 링크 / 동네 + 랜드마크]
· 주문: 이 채팅에서 '구매하기'를 누르시면 당근페이로 바로 결제·배송지 입력이 됩니다.
  (계좌번호·주소를 채팅으로 주고받지 않으셔도 돼요!)
```

## ② 채팅 상황별 응대 템플릿 (복붙)

**가격 흥정(네고) 요청 — 단, 강압 금지 / 친절 단호)**
```
좋게 봐주셔서 감사합니다 😊 이미 산지직송으로 마진을 최소화한 가격이라
추가 할인은 어렵지만, [무료배송 / OO 서비스]로 챙겨드릴게요!
```

**재고/마감 문의**
```
오늘 입고분은 [N]박스 남았어요. 신선도 때문에 당일 소진되면 마감되니 참고 부탁드려요 🙏
```

**노쇼/예약 취소 (생물 특성 안내 — 부드럽게)**
```
생물이라 예약 후 오래 잡아두면 신선도가 떨어져서요 🥲
결제(당근페이)까지 마쳐주시면 확정으로 잡아두겠습니다!
```

**구매 확정 → 안심결제 유도**
```
감사합니다! '구매하기'로 당근페이 결제해주시면 바로 준비해서 보내드릴게요.
배송지/연락처도 그 화면에서 한 번에 입력됩니다 😊
```

## ③ 이메일 템플릿 (붙여넣기용 — 자동발송 아님)

> 택배 운영 시 고객/공급처용. Gmail 자동발송 도구가 없으므로 복사해 사용하거나,
> 추후 발송 기능이 연결되면 그때 자동화한다. `{}`는 치환 변수.

**주문 확인**
```
제목: [가게명] 주문이 확인되었어요 ({주문번호})
{고객명}님, 산지직송 {품목} {수량} 주문 감사합니다!
오늘 {수확일} 수확분으로 준비해 {발송예정일}에 발송 예정입니다.
받으시는 곳: {주소} / 연락처: {연락처}
신선하게 보내드릴게요 😊
```

**발송 통지(운송장)**
```
제목: [가게명] 상품이 출발했어요 🚚 (운송장 {송장번호})
{고객명}님, 주문하신 {품목}이 방금 발송됐습니다.
택배사: {택배사} / 운송장: {송장번호}
도착 후 냉장보관 부탁드리고, {후숙/보관 팁} 참고하세요!
```

**하자 접수 안내**
```
제목: [가게명] 교환/환불 접수 안내
불편을 드려 죄송합니다. 수령 후 24시간 이내에 아래 3장을 회신해주시면
불량 과수 비율만큼 신속히 부분환불/교환 처리해드리겠습니다.
① 운송장 사진 ② 박스 전체 사진 ③ 문제 부위 사진
```

## ④ Gmail 라벨 자동 분류 (현재 도구로 가능한 부분)
연결된 Gmail 도구로 **라벨 생성/부착**은 가능하다. 주문/CS 메일을 받는다면:
- `당근-주문`, `당근-CS접수`, `당근-공급처` 라벨을 만들어 분류 자동화 가능.
- 단, 메일 **본문 자동 발송**은 현재 불가(별도 발송 도구 연결 필요).
