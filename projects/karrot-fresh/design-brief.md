# 🎨 당근 산지직송 농수산물 — Canva 자동생성용 디자인 브리프

> **벤치마킹 근거 & 한계:** 당근 앱 *내부*의 실시간 경쟁사 광고는 외부 수집 불가.
> 이 브리프는 ① 당근 공식 자료(브랜드 가이드·광고 심사 정책·비즈 자료실) + ② 한국 농산물
> 커머스(스마트스토어·마켓컬리) 일반 관습 + ③ 2026 상세페이지 트렌드를 종합한 것.
> 추측은 `[추측]`, 출처는 §7. **마음에 드는 경쟁사 스크린샷을 주면 직접 레퍼런스로 반영 가능.**

## 0. 최우선 제약 — 광고 심사 "글자 50% 룰"
**이미지 안 글자가 50%↑면 당근 광고 심사 거절.** → **사진이 주인공, 텍스트는 거들 뿐(실전 권장 면적 25~35%).**
당근에서는 "사진 중심 광고"가 더 잘 팔린다. (출처: §7 센스맘/당근 광고정책)

## 1. 무드 키워드 (6)
당근 공식 브랜드 핵심어 = **"따뜻함/꾸밈없음"** (Local·Connect·Life).
1. **따뜻함·푸근함** — 마트 아닌 "동네 이웃이 파는 느낌"
2. **정직·꾸밈없음** — 과대포장·필터떡칠과 반대(당근 서체 철학)
3. **산지직송 신뢰** — "○○도 직송", 농부/재배 스토리
4. **신선·생생함** — "당일수확/오전수확 오후발송"
5. **동네스러움·접근성** — 럭셔리보다 친근·편안
6. **자연·햇살감** — 인공조명보다 자연광

## 2. 컬러 팔레트 (HEX)
> 당근 공식 오렌지 HEX는 미공개 → 아래는 제3자 근사치 `[근사치]`. **오렌지는 배지·가격·CTA 포인트에만**, 메인 배경은 크림/식품 자연색.

| 용도 | HEX |
|---|---|
| 크림 아이보리(배경/여백) | `#FFF8F0` |
| 당근 오렌지[근사치] (배지·가격·강조) | `#E78111` |
| 다크 브라운(텍스트) | `#3D2B1F` |
| 잎채소 그린(신선·산지 배지) | `#4E7B3A` |
| 화이트(사진 위 텍스트) | `#FFFFFF` |

**상품 자연색 액센트(배지/가격 1색만 끌어와 통일):** 딸기·사과 `#D7263D` / 감귤·단호박 `#F2922C` / 포도·블루베리 `#6B3FA0` / 참외·메론 `#C9D14B` / 수박·오이 `#3FA34D`

## 3. 타이포그래피 (한글)
- **제목/배지:** 둥글고 굵은 고딕 — Pretendard Bold, 여기어때 잘난체, 배민 주아체 류
- **본문:** Pretendard / 나눔스퀘어 / 노토산스 KR
- **포인트(선택, 1곳만):** 나눔손글씨 류 — "오늘수확" 한 단어
- **크기 위계:** ① 가격(최대·당근오렌지) ② 상품명 ③ 산지·배지 ④ 당도·중량
- 규칙: **폰트 2종 이내**, 사진 위엔 흰 글씨+그림자 또는 반투명 칩, **글자 면적 50% 미만**

## 4. 레이아웃 규격
- **메인: 1:1 (1080×1080)** / **세로 강조: 4:5 (1080×1350)** / **상세: 폭1080 세로무제한**
- 안전영역: 가장자리 **5~8% 여백**
- 좌상단=`산지직송` 배지 / 하단 코너=**가격(최대)** 반투명 칩 위 / 당도·"오늘수확"=가격 근처 / 중앙 60~70%=상품 사진 / 모서리 살짝 둥글게

## 5. 잘 먹히는 오버레이 카피 패턴
- **신뢰:** `산지직송` `전북 완주 직송` `국내산 100%` `무농약`
- **신선(강력):** `오늘 수확` `오전수확 오후발송` `당일배송`
- **가격(최대):** `9,900원 /2kg`, 정직 비교 `마트 19,800 → 9,900`, `오늘만`/`선착순 100박스`
- **품질:** `당도 13Brix↑` `못난이라 더 저렴`(정직 콘셉트)
- **한정 배지:** `제철한정` `놓치면 내년`
- 핵심: **짧게·구체 숫자로**("맛있어요"❌ → "당도 13Brix"✅)

## 6. Do / Don't
**✅ Do:** 사진이 화면 대부분(텍스트<50%) · 자연광·실제 산지/농부 사진 · 구체 숫자 정직 · 크림배경+자연색 액센트+둥근모서리 · 진짜 인증마크만
**❌ Don't:** 글자 도배(50%↑=심사거절) · 필터떡칠 색왜곡(받으면 다름→평판붕괴) · 마트식 차가운 럭셔리톤 · 폰트3종↑·형광색 · 검증불가 최상급("국내 최고") · 당근오렌지 전면도배(공식 오인)

### Canva 자동생성 요약 파라미터
- 사이즈: 1080×1080(메인) / 1080×1350(세로 강조)
- 배경: `#FFF8F0` 크림 / 자연광 상품사진 풀블리드
- 포인트색: `#E78111`[근사치] + 상품 자연색 1색
- 텍스트: `#3D2B1F` 또는 흰색+그림자(반투명 칩)
- 폰트: 제목=둥근굵은고딕, 본문=Pretendard류, 2종 이내
- 레이아웃: 좌상=산지배지, 하단코너=가격(최대), 중앙=상품, 여백 5~8%, 둥근모서리
- 철칙: **글자 < 50%(권장 25~35%)**, 정직한 숫자, 자연색·따뜻함
