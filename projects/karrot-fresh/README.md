## 🧊 자동화 가능/불가 — 솔직한 경계
당근은 **외부 공개 API가 없다.** 따라서 자동화는 "당근 안"이 아니라 **양 끝단**에서만 가능:
- ✅ **올리기 전(입력 준비):** 리스팅 카피 생성(`/listing`), Canva 상품/광고 이미지(쿼터 가능 시)
- ✅ **팔린 후(출력 관리):** 주문·단골·마진 DB(Supabase), Gmail 라벨 분류
- ✅ **당근 자체 기능 세팅:** 비즈프로필 자동응답 문구(cs-scripts.md) — *세팅은 셀러가, 문구는 자동생성*
- ❌ **불가:** 당근 앱 직접 자동게시(북마클릿이 한계) · 채팅 실시간 봇(정지위험) · 광고 예산 프로그램제어 · 시세 자동수집 · **Gmail 자동발송**(현재 연결 도구는 라벨만)

## 📊 마진계산기 핵심 발견 (당근마켓_마진계산기.xlsx)
실제 공급가(사진 제공) 기준. **공급가에 택배비·박스포장 포함(직출고)** → 추가비용은 **건당광고비 + 당근 판매수수료 3.3%**뿐.
- 비용모델: `마진 = 판매가×(1−3.3%) − 공급가 − 건당광고비`(광고 일4만÷20건=2,000원/건 가정).
- 권장가 = `MAX(시세, (공급가+광고)/(1−3.3%−목표마진15%))` → **손해 0 + 목표마진 보장**.
- **성주참외 = 효자상품**: 가성비 5kg 시세 29,900원에 마진 **+18,413(61.6%)**, 로얄 5kg 38,800원 **+25,020(64.5%)**, 10kg 59,000원 **+38,153(64.7%)**.
- **대극천복숭아 = 2등 효자(36~40%)**: 로얄과 2kg 28,800원 +10,850(37.7%), 소과 2kg 22,800원 +9,048(39.7%).
- **홍감자 = 무난**: 대 5kg 19,900원 +4,743(23.8%), 특 5kg 22,900원 +4,644(20.3%).
- **⚠️ 보우짱 = 저마진/손해**: 공급가가 시세에 너무 근접(1kg 공급5,600 vs 시세5,900). 1~5kg은 시세로 팔면 손익분기 미달 → **10kg 위주 또는 시세보다 올려야** 함.
- 결론: **광고비는 마진 큰 성주참외·홍감자(대/특)에 집중**, 보우짱은 미끼/대용량만.

## 📍 광고 지역분포 핵심 (당근광고_지역분포.xlsx)
배송리스트 911건에서 기름·이불 등(`애착`류) 191건 제외 → **농수산과일 720건**을 우편번호로 시/도 전수 매핑.
- **수도권 집중 62%**: 경기 33.5%(241) + 서울 20.6%(148) + 인천 8.3%(60).
- 그 외: 부산 5.3% · 경남 4.4% · 충남 4.0% · 대구 3.6% · 전북/충북/경북 각 3%대.
- 시군구 핫스팟(주소 표본): 경기 용인·부천·고양·화성·수원, 충북 청주, 전북 전주, 서울 강동·서초, 인천 부평.
- → 당근 지역광고 1순위 = **경기(용인·부천·고양·화성·수원)+서울(강동·서초)+인천(부평)**. (단, 이 수요는 택배 온라인 기준 → 당근은 동네기반이라 셀러 배송권역과 교차해서 판단.)

## 🔧 권장 파이프라인
1. **`/listing`** 로 리스팅 카피 생성 → 당근에 게시(반자동)
2. `design-brief.md` 기준 **Canva**로 상품/광고 이미지 생성(쿼터 리셋 후)
3. **비즈프로필 자동응답**을 `cs-scripts.md` 문구로 세팅 → 채팅 응대 80%↓
4. 주문 들어오면 **Supabase**(`karrot` 스키마)에 기록 → 단골·마진·제철 재입고 추적
5. 제철 시작 전 `restock_reminders` 기준 **단골 알림/재게시**로 광고비 0원 완판
