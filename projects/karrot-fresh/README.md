## 🧊 자동화 가능/불가 — 솔직한 경계
당근은 **외부 공개 API가 없다.** 따라서 자동화는 "당근 안"이 아니라 **양 끝단**에서만 가능:
- ✅ **올리기 전(입력 준비):** 리스팅 카피 생성(`/listing`), Canva 상품/광고 이미지(쿼터 가능 시)
- ✅ **팔린 후(출력 관리):** 주문·단골·마진 DB(Supabase), Gmail 라벨 분류
- ✅ **당근 자체 기능 세팅:** 비즈프로필 자동응답 문구(cs-scripts.md) — *세팅은 셀러가, 문구는 자동생성*
- ❌ **불가:** 당근 앱 직접 자동게시(북마클릿이 한계) · 채팅 실시간 봇(정지위험) · 광고 예산 프로그램제어 · 시세 자동수집 · **Gmail 자동발송**(현재 연결 도구는 라벨만)

## 📊 마진계산기 핵심 발견 (당근마켓_마진계산기.xlsx)
업로드 파일(쿠팡 공급가·판매가)을 근거로 상품별 시트 구성. 당근은 **수수료 0**이지만 **광고비(일 3~5만원)를 건당으로 분배**(15건/일 → 약 2,667원/건)해 원가에 더함.
- **결정적 결론: 농수산물은 '직거래(택배비 0)'로 가야 시세 맞추며 마진이 남는다.** 택배(건당 3,500)+광고(2,667)=약 6,200원 고정비가 단가 낮은 상품을 잠식 → 택배 시 쿠팡 시세 매칭하면 손해 구간 다수.
- 직거래 기준 성주참외 2kg 17,900원=마진 +4,233(23.6%), 5kg 29,900원=+6,733(22.5%), 10kg 53,000원=+13,833(26%).
- '당근권장가'는 항상 `MAX(시세, 원가×1.15)` → **원가 밑으로 절대 안 내려감(손해 0 보장)**. 마진 음수면 빨간색.
- ⚠️ 공급가 미확정(성주참외·보우짱·홍감자)은 추정치 → 실제 매입가 입력 시 손익 확정.

## 🔧 권장 파이프라인
1. **`/listing`** 로 리스팅 카피 생성 → 당근에 게시(반자동)
2. `design-brief.md` 기준 **Canva**로 상품/광고 이미지 생성(쿼터 리셋 후)
3. **비즈프로필 자동응답**을 `cs-scripts.md` 문구로 세팅 → 채팅 응대 80%↓
4. 주문 들어오면 **Supabase**(`karrot` 스키마)에 기록 → 단골·마진·제철 재입고 추적
5. 제철 시작 전 `restock_reminders` 기준 **단골 알림/재게시**로 광고비 0원 완판
