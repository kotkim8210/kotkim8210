# 쿠팡 제습기 아이템위너 소싱 조사 (장마철 즉시판매용)

조사기준: 2026-07-08 (KST) · 데이터 소스: 다나와(실조회) + 웹 2차자료(인기신호)

## 0. 한 줄 결론

**"다나와 매입원가는 실제로 뽑았고, 쿠팡 위너·판매자·리뷰 데이터는 이 환경에서 취득 불가(봇차단)."**
따라서 이 조사는 **"다나와 실매입가 + 마진 자동계산 시트"** 까지 완성했고, 최종 등급(S/A/B) 확정에 필요한
쿠팡 실측값(위너가·신품 판매자수·배송형태·상품평)은 **사장님이 로그인 상태에서 5분 확인 → 노란칸 입력**하면
시트가 자동으로 마진·등급을 계산하도록 만들어 두었다.

## 1. 접근성 실측 결과 (왜 쿠팡을 자동으로 못 뽑았나)

| 대상 | 결과 | 근거 |
|------|------|------|
| 쿠팡 상품페이지 (사장님이 준 제외 URL) | ❌ **HTTP 403** | WebFetch 차단 |
| 쿠팡 검색/홈 | ❌ **HTTP 403** | curl 차단 |
| 쿠팡 (실제 Chromium 브라우저) | ❌ **CONNECTION_RESET** | Akamai 봇차단이 데이터센터 IP를 연결리셋 |
| 다나와 검색 | ✅ **HTTP 200** | 모델번호·최저가·판매처수 정상 추출 |

→ 쿠팡은 로그인 자격증명도 없고 IP도 차단되어, **위너가·신품 판매자수·배송형태·상품평은 자동취득 불가.**
→ 사장님 지침의 **제외조건3(판매자수 확인불가→제외/보류)**, **조사원칙(추정금지)** 에 따라 이 값들은 **지어내지 않았다.**

## 2. 산출물

- **`쿠팡_제습기_소싱_마진시트.xlsx`** — 메인 결과물 (3개 탭)
  - `소싱_마진시트`: 84개 후보. **앞쪽 A~G열 = 마진 관련(등급·예상마진·마진율·손익분기위너가·8%·12% 목표위너가)**, 화면 고정.
    노란칸(①위너가 ④판매자수 ⑤배송형태 ⑥상품평 ⑦최근리뷰 ⑧2위가 ⑨상품URL)만 쿠팡에서 확인해 채우면
    **마진·등급 자동 계산**(예상마진 ≥10원=초록, 손실=빨강 조건부서식).
  - `사용법_및_한계`: 계산식·등급로직·쿠팡 데이터 취득 3가지 방법.
  - `원본_다나와데이터`: 수집 원본 110개 모델.
- `build_xlsx.py` — 시트 생성 스크립트 / `data.json` — 수집 원본 데이터.

### 마진 계산식 (지침 §8, 보수적)
```
예상마진 = 쿠팡위너가 − 다나와매입가 − 쿠팡위너가×17%(수수료12+결제1+위험3+운영1) − 판매자부담택배비
손익분기 위너가 = (매입가+택배비) ÷ 0.83   |   8%목표 = ÷0.75   |   12%목표 = ÷0.71
```
> 시트의 **손익분기/8%/12% 목표 위너가는 다나와 매입가만으로 미리 계산되어 채워져 있다.**
> 쿠팡에서 실제 위너가를 본 순간, 그 값이 목표 위너가보다 높으면 진입 검토 → 즉시 판단 가능.

## 4. 냉정한 결론 (지침 §12 6대 질문)

1. **지금 등록하면 실주문 발생 가능성?** — 장마철 카테고리 수요는 높음(웹 신호 확인). 단, 개별 모델의 쿠팡 실판매 반응은 쿠팡 리뷰/구매표시 확인 전엔 확정 불가.
2. **일반 판매자배송으로 위너 승산?** — 쿠팡 현재 위너 배송형태·2위가 미확인 상태라 **현시점 확정 불가**. 노란칸 채워야 판단 가능.
3. **다나와 소매매입으로 수익?** — 매입원가는 확보됨. 쿠팡 위너가가 표의 '손익BEP'보다 높은 모델만 수익. 위너가 확인 필수.
4. **위너가 5% 하락해도 흑자?** — 위너가 미확인이라 계산 불가. 위너가 입력 시 시트가 '가격하락 허용한계'를 자동 산출.
5. **초도 재고 잔여 위험?** — 장마철 시즌성 큼. 미니형·비인기 색상·구형(2019~2021)은 잔여위험 상대적 높음.
6. **지금 사야 할 것 vs 사면 안 될 것?** — 쿠팡 위너 배송형태·판매자수 확인 전엔 **아무것도 "지금 매입"으로 확정하지 말 것.** 먼저 위 24개를 쿠팡에서 5분 검증 → 손익BEP 넘고 판매자 2명↑·위너 일반배송인 것만 소량 테스트.

## 5. 쿠팡 실측 데이터를 뽑는 정식 방법 (택1)

- **(a) 사장님 PC/폰(가정용 IP)+쿠팡 로그인** — 위 24개 모델번호로 검색 → 동일모델 상세 → '다른 판매자 보기'로 판매자수·위너배송·위너가·2위가 확인 → 시트 노란칸 입력. 가장 정확·무료.
- **(b) 셀러 분석 SaaS** — 아이템스카우트 / 판다랭크 / 셀러라이프. 아이템위너 경쟁·판매자수·리뷰추이 제공(유료).
- **(c) 주거용 프록시+로그인 크롤러** — 별도(비차단) 환경 필요. 이 클라우드 환경에선 불가.
