## 왜 등산인가 (러닝 대비)
- **종이의 명분:** 러닝은 Strava·NRC가 이미 디지털 기록 → 종이가 "이미 앱으로 함"과 싸움. 등산은 **수집·인증·소장**(도장깨기) 욕구라 종이가 이김.
- **해자:** "100대 명산/산군별 코스·스탬프·인증" 구조화 데이터는 모방이 번거로움. 러닝/단주는 양식이 단순해 복제 쉬움.
- **지속성:** 등산은 트렌드가 아니라 문화 → 5년 뒤에도 유효(에버그린). 콘텐츠(산·코스·풍경) 무한.
- **경쟁공백:** 전용 "등산 기록 저널" 지배 브랜드 사실상 없음.

> ⚠️ POD 자체 해자는 0. **6개월 내 카피 붙음 → 그 전에 '테마 계정(청중)+브랜드' 선점이 전부.**

## 1호 상품 스펙 — 100대 명산 도전 기록 저널

**구성(약 120~150p):**
- 표지: "100대 명산 도전 기록" + 미니멀 산 일러스트(브랜드 컬러)
- 인트로: 사용법 · 등산 안전수칙 · **100대 명산 전체 지도 + 체크리스트(도장깨기 보드)**
- 명산별 기록 양식(1산=1~2p): 산명/고도/날짜/동행/코스/소요시간/날씨/컨디션/**사진 부착칸**/한 줄 소감/**인증 스탬프칸**
- 부록: 누적 통계(등반 수·총 고도·총 거리) · 장비 체크리스트 · 등산 용어 · 다음 버킷리스트
- **소장성 요소**(해자): 완주 시 채워지는 성취 보드 = SNS 인증 유발

**POD 사양(국내):** A5, 양장 또는 스프링, 100~150p, 컬러 일부.
**가격:** 정가 **₩24,900** (검증 한정 ₩19,900) · 프리미엄(양장) ₩29,900.
**단위 경제(추정):** 원가 ₩6,000~12,000 → 순마진 권당 **₩8,000~16,000**(스마트스토어 수수료 ~6% 반영 후).
**SKU 로드맵:** 100대 명산 → 산행일지(재구매) → 지역판(영남알프스·지리산 종주·백두대간 섹션) → 둘레길 → 백패킹.

## POD 셋업 가이드 (무재고, 무자본)

1. **POD 업체 선택:** 레드프린팅(노트·제본 강점) / 마플(연동 편의) / 오즈프린팅. → **샘플 1권 반드시 검수**(품질·배송).
2. **판매 채널:** 스마트스토어(검색 유입) + 인스타·쓰레드 프로필 링크. (독립몰은 나중)
3. **흐름:** 주문 → POD 자동 제작·발송(또는 소량 사입 후 직접 발송으로 마진↑). 재고 0.
4. **디자인:** Canva로 내지 양식 제작 → PDF 입고. (양식·표지 우리가 제작 가능)
5. **손익분기:** 디자인·샘플 비용 ₩수만 → **10권이면 회수.**

## 검증 계획 & 합격선 (POD = 재고 0 → 실판매로 검증)

- **Stage 1(관심):** 테마 계정 2~3주, 게시물 **저장률·프로필 클릭·링크 클릭** 추적.
- **Stage 2(유료, 진짜):** **3주 내 실판매 ≥ 10권** 또는 매출 ≥ ₩20만 → **GO**.
  - KILL: 도달은 느는데 판매 0 → 가격/오퍼/표지/컨셉 1회 교정 → 또 0이면 컨셉 B(산행일지)로 전환.
- **Stage 3(복리):** 재구매·시리즈 교차판매·UGC 인증 → SKU 확장.
- 합격선은 테스트 전 [Tool 03](../gate-calculator.html)에 잠그기.
