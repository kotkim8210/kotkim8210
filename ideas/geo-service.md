# 1호 선정 아이디어 — 보이나(BOINA): AI 검색 가시성(GEO) 진단 → 실행 서비스

> **한 줄 정의:** 한국 DTC·이커머스 브랜드가 ChatGPT·Perplexity·구글 AI 개요·네이버 AI 브리핑에서
> **추천·인용되도록** 진단하고 고쳐주는 생산화(productized) 서비스.
> 진단(유료, 1회) → 월 실행/관리(리테이너)로 확장.

선정일: 2026-06-13 · 검증 랜딩: [`../geo-landing.html`](../geo-landing.html) · 검증 도구: Tool 02 → Tool 03

## 왜 이 아이디어인가 (선정 근거)

회원님 프로필 = **마케팅·이커머스·콘텐츠 전문성 + 솔로·풀타임·AI 레버리지 + 무자본(~100만원) + 빠른 유료검증 필요.**
이 4박자에 가장 잘 맞는 단 하나를 트렌드 리서치로 추렸습니다.

| 선정 기준 | GEO 진단 서비스 | 비고 |
|---|---|---|
| **창업자-시장 적합성** | ◎ GEO의 본질 = 콘텐츠·권위·비교노출·PR = 마케팅/콘텐츠 실무 | 불공정 우위 |
| **무자본 가능** | ◎ 재고·광고 0. 도구는 월 $25~89(Otterly/Peec)로 충분 | 진입비 거의 0 |
| **솔로+AI** | ◎ 진단·리포트·콘텐츠를 AI로 레버리지 | 1인 운영 가능 |
| **빠른 유료검증** | ◎ "진단"을 1회 유료 상품으로 즉시 판매 → 진짜 지불 신호 | Stage 2가 day 1부터 가능 |
| **트렌드 적합** | ◎ 2026 마케팅의 1순위 디스플린, 한국은 초기 | 선점 여지 |
| **B2B 지불의향** | ◎ ROI 직결, 해외 대행 월 $1.5k~10k 벤치마크 | 가격 방어력 |

### 탈락시킨 대안
- **AI UGC 영상광고 생성**: 이미 포화(한 도구로만 2,000+ 브랜드, 영상당 $11 commoditized, 펀딩 경쟁사 다수) → 가격 바닥 경쟁.
- **AI 콘텐츠/블로그 대량생성**: 레드오션, 차별화 약함.
- **GEO *추적 툴* 직접 개발**: 이미 자본 시장(Profound 기업가치 $1B, Peec $29M 펀딩). 무자본 솔로가 툴로 정면승부 ✗ → **툴은 경쟁자가 아니라 내 진단 도구로 활용.**

### Why now (리서치 근거)
- 2026년 검색의 **60%+에 AI 답변이 개입.** 검색이 "링크 10개"→"AI가 고른 1~3개 추천"으로 이동.
- 한국인 **10%+가 ChatGPT를 검색으로 사용**, 네이버 **AI 브리핑**·구글 **AI 개요** 기본 노출. → 한국도 GEO 필요 구간 진입.
- 기업 **92%가 2026 AI 마케팅 투자 확대.** 해외 GEO 대행 단가 **월 $1,500~10,000+**(이미 시장가 형성).
- 한국 GEO 시장은 **에이전시·블로그 담론 단계 = 초기** → SMB 대상 "대신 해주는" 서비스 공백.

> 출처: Search Engine Land(2026 이커머스 트렌드), Jasper/WebFX/Fuel Online(GEO·AEO 정의·단가), 오픈서베이 AI 검색 트렌드 리포트(한국), Surmado/Zapier(Profound·Peec·Otterly 비교). 링크는 세션 리서치 로그 참조.

## ICP (이상적 초기 고객)

- **한국 DTC·자사몰/스마트스토어 브랜드**, 월매출 수천만~수억, 마케팅 1~3인 또는 대표가 직접 마케팅.
- **검색 의존도 높은 카테고리부터 1개로 좁혀 레퍼런스 축적**: 예) 뷰티/이너뷰티, 건강기능식품, 패션, 리빙.
- 공통 페인: "광고비는 오르는데 전환은 빠진다", "AI한테 물어보고 산다는데 우리는 거기 없다."
- 부차 타깃: 콘텐츠 마케팅 하는 B2B SaaS·전문서비스(병원·법무·교육) — 객단가 높음.

**웨지 전략:** 한 카테고리에서 3~5개 레퍼런스 → "○○ 카테고리 GEO 전문"으로 포지셔닝 → 동종 확산.

## 오퍼 & 가격 사다리

| 단계 | 상품 | 가격 | 목적 |
|---|---|---|---|
| 미끼 | **무료 미니진단** (대표 질문 1개, 4대 AI 노출 여부 1장 리포트) | ₩0 | 리드·신뢰 확보 |
| **핵심(검증 상품)** | **정밀진단** (질문 10~15개 실측 + 경쟁사 비교 + 원인 + 30일 액션플랜 + 30분 콜) | **₩290,000** (정가 ₩490,000, 검증 한정) | **유료 니즈 확정** |
| 최저마찰 결제 | **예약금** (정밀진단비에서 차감·전액 환불) | ₩50,000 | revealed-preference 확정 신호 |
| 확장 | **월 관리 리테이너** (GEO 콘텐츠 실행 + 모니터링 + 월간 리포트) | ₩1,500,000~3,000,000/월 | LTV |

> **핵심:** 무료 미니진단은 미끼일 뿐. **검증의 본질은 정밀진단 ₩290,000(또는 예약금 ₩50,000)을 실제로 받는 것.** 그게 "유료 니즈" 증명이다.

### 진단 딜리버리(솔로+AI로 가능)
1. 카테고리 대표 질문 10~15개 세팅(구매검토형 프롬프트).
2. ChatGPT·Perplexity·구글 AI 개요·네이버에서 직접 질의 → 노출/인용/경쟁사 캡처(+ Otterly/Peec 트라이얼로 자동화).
3. AI 신뢰 출처(리뷰·커뮤니티·비교·G2/위키·구조화 데이터) 기준 빈틈 분석.
4. 30일 액션플랜(콘텐츠·스키마·비교페이지·커뮤니티 시딩 순서)을 슬라이드로.
5. 30분 콜로 전달 → 리테이너 업셀.

## 0원 Go-To-Market (무자본)

1. **콜드 아웃리치 (메인):** 타깃 카테고리 브랜드 30곳 선정 → 각사에 **무료 미니진단 결과 1장**을 먼저 만들어 DM/메일. "당신 브랜드는 ChatGPT에서 이렇게 나옵니다(스샷). 정밀진단 받아보실래요?" → 진단 페이지로.
2. **콘텐츠 마케팅 (복리):** 본인 SNS/블로그에 "○○ 카테고리 브랜드 10개 AI 노출 순위" 같은 진단형 콘텐츠 = 데모이자 미끼. (GEO를 본인에게도 적용 = 메타 증명)
3. **커뮤니티:** 셀러 커뮤니티에 사례·인사이트 공유 → 신뢰 → 진단 신청.

광고비 0. 도구비 월 $25~89(Otterly/Peec). 손익분기 = 정밀진단 1건이면 도구비 회수.

## 검증 계획 (우리 툴킷으로)

**Stage 1 — 수요 신호 (이번 주):** `geo-landing.html` 배포(GitHub Pages) + 위 GTM으로 트래픽.
측정: 방문→신청(리드) 전환, 콜드 DM 회신율.
- **GO:** 콜드 아웃리치 30곳 중 회신 ≥10% 또는 진단 신청 ≥3건.
- **KILL:** 30곳 접촉·회신 거의 0 → 메시지/타깃 교체 후 재시도, 2회 실패 시 폐기.

**Stage 2 — 유료 검증 (2주 내, 진짜 게이트):** 정밀진단을 실제 판매.
- **GO:** 14일 내 **정밀진단 유료 결제 ≥3건** 또는 **예약금 ≥5건.**
- **KILL:** 진지한 대화 30건에도 유료 결제 0 → 유료 니즈 미검증, 피벗/폐기.

**Stage 3 — 리텐션/확장:** 진단 고객 중 **≥1곳을 월 리테이너로 전환** → 반복매출 확인.

> 합격선은 **테스트 시작 전에** [Tool 03](../gate-calculator.html)에 숫자로 박고 잠그기. 표본 적을 땐 전환율 신뢰 금지.

## 14일 실행 플랜

- **D1–2:** 카테고리 1개 확정 → 타깃 30곳 리스트 + 대표 질문 10개 세팅.
- **D3:** Formspree(신청) + 결제링크(예약금 ₩50,000) 만들어 `geo-landing.html` CONFIG에 연결, Pages 배포.
- **D4–5:** 무료 미니진단 결과 30장 제작(AI 활용) → 콜드 DM/메일 발송.
- **D6–9:** 회신 대응 → 무료진단 콜 → 정밀진단/예약금 클로징.
- **D10:** 본인 채널에 "카테고리 AI 노출 진단" 콘텐츠 1편 게시.
- **D11–14:** Tool 03로 GO/KILL 판정. 결제 ≥3건이면 → 첫 정밀진단 딜리버리 + 리테이너 제안.
