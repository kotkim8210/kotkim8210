## 왜 일반 소비자 앱이 아니라 "마케팅 도메인"인가
- 무드리셋 같은 일반 앱: 빠르지만 **전문성 활용 0, 복제 쉬움, 팔로워·앱이 흩어짐.**
- 마케터·셀러 도메인: **founder-market fit + 콘텐츠 신뢰도 + 고객이 곧 미래 GEO 고객.** 앱마다 같은 청중에게 팔려 **복리.**

## 1호 앱 스펙 — 후킹 스코어러 ✅(이미 빌드됨)

- **무료(작동):** 후킹 붙여넣기 → 0~100점 + 5축(길이·구체성·파워워드·호기심·타깃) 막대 + 약점별 개선 제안.
- **PRO(₩, 잠금):** 같은 주제로 **검증된 후킹 공식 10개 자동 생성** + 복사 + (예정)업종별 템플릿팩.
- **구현:** 단일 HTML, 휴리스틱 스코어링(서버/AI 호출 없음). `CONFIG.paymentLink`(Gumroad 등) + `proCode`로 잠금해제.
- **가격안:** PRO 일회성 ₩9,900~19,900 또는 템플릿팩 묶음 ₩29,000. (검증 후 구독화 검토)
- **트레드밀 탈출 장치:** PRO를 *템플릿 구독*(매월 업종팩 추가)으로 전환 + #2~#6 앱으로 LTV 확장.

## 쓰레드(Threads) 콘텐츠 템플릿 (무자본 트래픽)

**원칙:** 카드뉴스/짧은 글로 가치 먼저 → 댓글에 도구 링크. 하루 1~3개, 후킹 자체를 본문으로(메타 증명).

1. **점수 챌린지:** "당신의 광고 첫 줄, 솔직히 몇 점일까? 내가 만든 무료 스코어러로 재봤다 → 결과 댓글에 🔗"
2. **비포/애프터:** "이 후킹 42점 → 한 줄 고쳐서 88점. 뭘 바꿨을까? (3가지)" + 캐러셀.
3. **공식 리스트:** "마케터가 훔쳐 쓰는 후킹 공식 7개" (마지막 줄: 자동 생성기 링크).
4. **실수 저격:** "이렇게 쓰면 무조건 스킵당하는 후킹 5가지" → 도구로 자가진단 유도.
5. **사례·데이터:** "후킹만 바꿔서 클릭률 X% 오른 케이스" (가능 시 실측).

> CTA는 항상 댓글 링크. 본문은 후킹 점수 S 받게 직접 다듬어 게시 = 도구 신뢰도 증명.

## 루프 SOP (앱 1개 = 1 사이클)

1. **문제(Tool 01):** 후보를 빈도×강도×지불가능성×경쟁공백으로 점수화 → 1개 선택.
2. **빌드(Claude):** 단일 HTML 미니앱. *서버·DB·API 가능한 한 배제*(비용·복잡도 0).
3. **판매(Stage 2):** 무료 코어 + PRO 결제링크(Gumroad/Lemon Squeezy/토스). **실제 결제가 검증.**
4. **트래픽:** 쓰레드 템플릿으로 매일 발행 → 댓글 링크.
5. **판정(Tool 03):** 테스트 전 합격선 잠금 → GO/KILL.

## 합격선 (Go/No-Go) — 팔로워❌ 매출⭕

- **Stage 1(관심):** 7일 쓰레드 운영 → 도구 방문 ≥ 300, 측정 실행률(방문→점수측정) ≥ 30%.
- **Stage 2(유료, 진짜 게이트):** 14일 내 **PRO 결제 ≥ 10건** 또는 매출 ≥ ₩100,000. (저가라 건수 기준)
- **Stage 3(복리):** 무료→PRO 전환율 ≥ 2~3%, 재방문/재구매 신호 → 구독화 또는 다음 앱 출시.
- **KILL:** 방문은 느는데 PRO 결제 0 → 가격/오퍼/PRO 가치 재설계 1회 → 또 0이면 다음 문제로.

> ⚠️ "잠자는 동안 돈복사"는 마케팅 문구일 뿐. 현실은 *콘텐츠 발행이 멈추면 트래픽도 멈추는* 모델. 진짜 자산은 **니치 청중 + 재사용 앱 부품 + PRO 구독.**
