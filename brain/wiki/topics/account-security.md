## 한 줄 요약
계정을 나눌수록 연좌제 위험은 줄지만 계정 분실 위험은 커지며, 실험기 확률상 분실이 연좌제보다 크므로 "앵커 계정 1개 + 순환 복구 금지"가 핵심 설계다.

## 핵심 내용

### 위험 역전 (핵심 판단)
- 계정 분리 ↑ → 연좌제 위험 ↓, **계정 분실 위험 ↑**.
- 실험기 확률상 **분실 >> 연좌제**. 따라서 보안·복구가 1순위 투자처. (2026-09-20-youtube-다계정-연좌제-전략.md)

### 순환 복구 데드락 금지 ⭐
- A의 복구를 B로, B의 복구를 A로 걸면 둘 다 잃었을 때 **영구 복구 불가**.
- 대신 **앵커 계정 1개**(하드웨어 키/패스키 보호)를 전 계정의 복구 지점으로 삼는다.
- [모순] 공통 앵커는 구글에 **연결 신호**를 준다. 숨길 필요가 없는 합법 운영이라면 분실 방지를 우선 — 트레이드오프는 인정하고 간다.

### 체크리스트
- [ ] 앵커 계정에 **하드웨어 보안키 또는 패스키** 등록
- [ ] 전 계정 **2FA 활성화**
- [ ] **백업 코드 오프라인 보관** (단일 최고가치 조치)
- [ ] 복구 이메일 = 앵커 계정으로 통일 (순환 금지)
- [ ] 비밀번호 관리자에 계정별 **서로 다른 강한 비밀번호**
- [ ] 각 브랜드 계정에 앵커 계정을 **공동 소유자로 등록** — 일부 기능은 **등록 후 7일 경과** 필요하므로 사고 전에 미리
- [ ] 계정 생성은 **천천히** (하루 몰아서 생성 시 인증 벽)
- [ ] 정기 로그인 점검 — 구글은 약 2년 미사용 계정을 삭제할 수 있음[확인필요]. 방치한 실험 계정 소실 위험

### 운영 상한
- 전화번호 1개당 구글 계정 **약 5개** 한도.
- 같은 기기·IP에서 단기간 다수 생성 시 추가 인증 요구 확률 급상승.
- → **현실적 운영 규모 3~5개**. 20개 플랜은 인증 단계에서 막힌다.

## 미해결/모순 (Open Questions)
- [확인필요] 구글 비활성 계정 삭제 정책의 정확한 기간(2년 추정)과 유튜브 채널 보유 계정에도 적용되는지.
- [모순] 앵커 계정 단일화는 복구 안전성 ↑ 이지만 **단일 장애점**이기도 하다. 앵커 자체의 이중화 방안 검토 필요.
