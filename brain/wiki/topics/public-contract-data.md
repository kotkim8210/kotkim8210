## 한 줄 요약
S2B(학교장터)는 사업자 공동인증서 로그인이 필요해 막히지만, 각 시·도교육청이 공개하는 계약체결 현황을 비로그인으로 긁으면 **실제 계약금액·계약방법·낙찰업체명까지 전수 확보**할 수 있다 — 사업 아이템 검증을 추정이 아닌 실측으로 바꾸는 도구.

## 핵심 내용

### 왜 중요한가 — 추정을 실측으로 바꾸는 유일한 지렛대
사업 후보를 평가할 때 가장 자주 틀리는 값이 **건당 단가**와 **수주 방식**이다.
이 두 값은 블로그·유튜브에 없고(있어도 D급 자기보고), LLM 추정은 체계적으로 과대하다.
공공계약 공개 데이터는 이 둘을 **A급 1차 자료로** 준다 — 정부가 법정 의무로 공개하는 실제 체결 내역이기 때문.

### 접근 경로 (검증됨)
| 소스 | 로그인 | 얻을 수 있는 것 |
|---|---|---|
| S2B `s2b.kr` | **필수**(공동인증서) | 견적공고·개찰결과 |
| **시·도교육청 계약공개** | **불필요** | 계약명·금액·계약방법·**낙찰업체명** |
| 행안부 인허가 데이터(data.go.kr) | 불필요 | 업종별 전국 사업자 수 = 경쟁자 수 |
| 찾기쉬운 생활법령정보(easylaw.go.kr) | 불필요 | 업종 진입 요건(인력·장비·벌칙) |

### 경상남도교육청 — 실제 동작하는 엔드포인트
```
목록: https://www.gne.go.kr/user/cntr/BD_cntrInfoList.do
      ?q_cntrNm=<계약명검색어>&q_rowPerPage=100&q_currPage=<N>
상세: https://www.gne.go.kr/user/cntr/BD_cntrInfoDetail.do?cmSeqNo=<seq>
```
- `q_rowPerPage`는 **100이 상한**(500은 빈 응답). 목록 행의 `opCntrView('<seq>')`에서 상세 키를 얻는다.
- 목록에는 없고 **상세에만 계약대상자(낙찰업체)명**이 있다 → 시장 집중도 계산의 핵심.
- 날짜 파라미터는 `YYYY-MM-DD` 형식이면 결과가 비므로 생략하고 전수 수집 후 필터가 안전.
- 재사용 스크립트: `tools/gne_contract_scraper.py`

### 반드시 걸러야 할 함정 — 동음이의어 오염
"청소"로 검색하면 **"청소년"**(청소년수련관·직업체험관)이 대량 혼입된다.
미제거 시 최상위 계약이 10.4억 "청소년 직업체험관 증축공사"로 잡혀 **시장 규모가 통째로 왜곡**된다.
또한 "청소기·청소용품 구입"(물품)이 용역보다 4배 많다 → 용역만 분리해야 단가가 나온다.
> 교훈: 키워드 검색 결과는 반드시 상위 금액 건을 눈으로 확인한 뒤 통계를 낸다.

### 🔓 돌파 경로 2개 추가 (2026-08-20)
**① 경기 — `cmSeqNo` 직접 접근.** 계약명 검색(`schCntrNm`)은 막혀 있지만 상세는 뚫린다.
```
POST https://www.goe.go.kr/goe/ir/selectCntrInfoDetail.do   body: cmSeqNo=<번호>&mi=10257
```
검증 완료(5건 전부 조회 성공): 구리남양주 19교 외부유리창 35,482,560원 · 평택 43교 체육관 4건 78,962,000원 — 전부 1인수의.

**② 나라장터 공고문 — 인증키 없이 HWP 직접 다운로드.** API는 401이지만 첨부파일은 열린다.
```
https://www.g2b.go.kr/pn/pnp/pnpe/UntyAtchFile/downloadFile.do
  ?bidPbancNo=<공고번호>&bidPbancOrd=000&fileType=&fileSeq=1&prcmBsneSeCd=03
```
`olefile`+`zlib`로 BodyText를 풀면 **기초금액·추정가격·예정가격 반영 보험료·낙찰하한율**이 전부 나온다.
→ 이것으로 **발주처가 상정한 직접임금**을 역산할 수 있다(국민연금보험료 ÷ 4.5%).
   서울남부 1권역: 2,948,625 ÷ 0.045 = 65,525,000원 = 추정가격의 **73.1%**.
→ **이 경로가 이전까지 못 보던 것을 보게 해준다: 입찰 건과 원가 구조, 그리고 참가업체 수.**

### 🔓 경쟁강도 측정 경로 확보 (2026-08-20) — 나라장터 낙찰정보 API
`apis.data.go.kr/1230000/as/ScsbidInfoService`. **엔드포인트는 살아 있고 서비스키만 필요하다**
(키 없이 호출하면 `SERVICE_KEY_IS_NULL`, 없는 오퍼레이션은 다른 에러 → 이 차이로 키 없이 검증했다).

유효 확인된 오퍼레이션:
| 오퍼레이션 | 용도 |
|---|---|
| **`getOpengResultListInfoServc`** | **용역 개찰결과 목록** ← 응찰자 수의 원천 |
| `getOpengResultListInfoServcPPSSrch` | 용역 개찰결과 (조달청 검색) |
| `getScsbidListSttusServcPPSSrch` | 용역 낙찰목록 |
| `getOpengResultListInfoCnstwkPPSSrch` | 공사 개찰결과 |
| `getScsbidListSttusThngPPSSrch` | 물품 낙찰목록 |

- 공식 설명: *"각 업무별로 최종낙찰자, **개찰순위**, 복수예비가격 및 예비가격 정보를 제공"*
- **심의유형 개발·운영 모두 자동승인** → data.go.kr 가입 후 활용신청하면 키가 바로 나온다(약 10분).
- **공고번호별 개찰결과 행 수 = 응찰자 수.** 이것이 경쟁강도의 유일한 실측 지표다.
- 수집기: `tools/g2b_opening_results.py` (키를 `G2B_SERVICE_KEY`에 넣고 실행. **Decoding 키** 사용)

**막힌 대안들** — 전부 확인함:
| 경로 | 결과 |
|---|---|
| g2b.go.kr 개찰결과 직접 URL | SPA라 서버 렌더링 없음, 모든 시도 "페이지를 찾을 수 없습니다" |
| 서울시 계약마당 `contract.seoul.go.kr` 개찰결과 | 열리지만 항목이 기관·사업명·투찰금액·투찰율·낙찰예정자뿐 — **응찰자 수 없음** |
| g2bplus.kr | "개찰·낙찰현황(용역)" 메뉴는 있으나 **로그인·유료** |
| pubdata.g2b.go.kr · pps.go.kr | 이 환경에서 접속 불가(HTTP 000) |

### ⚠️ 치명적 방법론 교훈 — 낙찰자만 세면 경쟁을 못 본다
수의계약 공개 데이터에는 **낙찰자만** 있고 응찰자가 없다. 그래서 HHI를 계산하면
"업체 17곳, HHI 1,107 = 경쟁적이나 독점 아님" 같은 결론이 나오는데, 같은 시장의
공개입찰 참가업체는 **411~1,010개사**였다. 낙찰 HHI가 낮은 것은 경쟁이 약해서가 아니라
**매번 다른 업체가 이기기 때문**이다.
→ **경쟁강도는 반드시 나라장터 개찰결과의 참가자 수로 재야 한다.** 계약공개 데이터로는 잴 수 없다.

### 시·도교육청별 접근성 (2026-08-15 실측)
| 지역 | 엔드포인트 | 통합검색 | 목록에 낙찰업체 | 판정 |
|---|---|---|---|---|
| **인천** | `ice.go.kr/contract/ir/selectCntrInfoList.do?mi=11307` | ✅ `schCntrNm` | ✅ **있음** | **최상** |
| 경남 | `gne.go.kr/user/cntr/BD_cntrInfoList.do` | ✅ `q_cntrNm` | 상세에서만 | 양호 |
| 경기 | `goe.go.kr/goe/ir/selectCntrInfoList.do?mi=10257` | ❌ `schCntrNm` 무시됨 | ✅ 있음 | 목록만 |
| 서울 | `open.sen.go.kr/fus/1/contractOpen/list0010v.do` | ❌ 기관별·월별 **파일** 공개 | ❌ | 사실상 불가 |

**인천이 가장 좋다** — 인천·경기는 같은 솔루션이라 필드명이 공통이다:
`schCntrNm`(계약명) `schCntrPrtnrNm`(계약상대자) `schCntrPodiv`(목적물: 1공사/**3용역**/2물품)
`schFsclY`(회계연도) `schInstClssDiv`(기관구분) `currPage`(페이지, 10건 고정)
→ `schCntrPodiv=3`으로 **용역만** 미리 거를 수 있어 물품 오탐 제거가 불필요하다.

### ⭐ 가장 중요한 교훈 — 단가를 결정하는 건 작업이 아니라 '발주 단위'
같은 저수조 청소가 **경남 1,014만원 vs 인천 36.3만원 — 28배** 차이가 났다.
원인은 난이도도 물가도 아니고, 경남은 교육지원청이 **관내 학교를 권역으로 묶어** 발주하고
인천은 **학교가 개별로** 발주하기 때문이었다.

→ 업종을 조사할 때 반드시 **발주 단위부터** 확인한다. 단가만 보고 지역을 일반화하면
   28배 틀린 사업계획이 나온다. 확인법: 발주기관명에 "○○교육지원청"이 있으면 묶음,
   개별 학교명뿐이면 낱개 발주다.

### 이 데이터로 답할 수 있는 질문
1. **건당 실제 단가** — 중앙값·사분위·구간별 분포 (평균은 대형 이상치에 오염되므로 중앙값을 쓴다)
2. **수주 방식** — 1인수의 / 2인이상수의 / 입찰 비율.
   1인수의 비중이 높으면 *입찰 최적화 전략이 무효*이고 영업·관계 게임이라는 뜻.
3. **계절성** — 월별 발주 분포로 실제 가동 가능 기간 산출
4. ~~**시장 집중도** — 낙찰업체명 집계 → HHI~~ 🔴 **이 용도로는 쓰면 안 된다** (위 방법론 교훈 참조).
   낙찰자만 담긴 데이터로 HHI를 내면 경쟁을 과소평가한다. 참가자 수는 나라장터 개찰결과에만 있다.
5. **발주 단위** — 개별 기관 발주인지, 상위기관이 권역별로 묶는지 (묶음이면 계약 규모가 10배)

### 판정 기준선
- HHI 기준(>2500 집중 / 1500~2500 중간 / <1500 경쟁적)은 **응찰자 데이터에만** 적용한다.
- 낙찰자 기반 HHI는 "누가 이겼나"의 분산일 뿐 경쟁강도가 아니다. 🔴 2026-08-20 교훈.
- 경쟁적 = 진입은 쉬우나 **초과수익 없음**. "규제 장벽이 있다"와 "돈이 된다"는 별개다.
