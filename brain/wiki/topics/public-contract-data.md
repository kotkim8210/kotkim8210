## 한 줄 요약
S2B(학교장터)는 사업자 공동인증서 로그인이 필요해 막히지만, 각 시·도교육청이 공개하는 계약체결 현황을 비로그인으로 긁으면 **실제 계약금액·계약방법·낙찰업체명까지 전수 확보**할 수 있다 — 사업 아이템 검증을 추정이 아닌 실측으로 바꾸는 도구.

## 핵심 내용

### 왜 중요한가 — 추정을 실측으로 바꾸는 유일한 지렛대
사업 후보를 평가할 때 가장 자주 틀리는 값이 **건당 단가**와 **수주 방식**이다.
이 두 값은 블로그·유튜브에 없고(있어도 D급 자기보고), LLM 추정은 체계적으로 과대하다.
공공계약 공개 데이터는 이 둘을 **A급 1차 자료로** 준다 — 정부가 법정 의무로 공개하는 실제 체결 내역이기 때문.

### 접근 경로 (검증됨)
| 소스 | 로그인 | 얻을 수 있는 것 |
|---|---|---|
| S2B `s2b.kr` | **필수**(공동인증서) | 견적공고·개찰결과 |
| **시·도교육청 계약공개** | **불필요** | 계약명·금액·계약방법·**낙찰업체명** |
| 행안부 인허가 데이터(data.go.kr) | 불필요 | 업종별 전국 사업자 수 = 경쟁자 수 |
| 찾기쉬운 생활법령정보(easylaw.go.kr) | 불필요 | 업종 진입 요건(인력·장비·벌칙) |

### 경상남도교육청 — 실제 동작하는 엔드포인트
```
목록: https://www.gne.go.kr/user/cntr/BD_cntrInfoList.do
      ?q_cntrNm=<계약명검색어>&q_rowPerPage=100&q_currPage=<N>
상세: https://www.gne.go.kr/user/cntr/BD_cntrInfoDetail.do?cmSeqNo=<seq>
```
- `q_rowPerPage`는 **100이 상한**(500은 빈 응답). 목록 행의 `opCntrView('<seq>')`에서 상세 키를 얻는다.
- 목록에는 없고 **상세에만 계약대상자(낙찰업체)명**이 있다 → 시장 집중도 계산의 핵심.
- 날짜 파라미터는 `YYYY-MM-DD` 형식이면 결과가 비므로 생략하고 전수 수집 후 필터가 안전.
- 재사용 스크립트: `tools/gne_contract_scraper.py`

### 반드시 걸러야 할 함정 — 동음이의어 오염
"청소"로 검색하면 **"청소년"**(청소년수련관·직업체험관)이 대량 혼입된다.
미제거 시 최상위 계약이 10.4억 "청소년 직업체험관 증축공사"로 잡혀 **시장 규모가 통째로 왜곡**된다.
또한 "청소기·청소용품 구입"(물품)이 용역보다 4배 많다 → 용역만 분리해야 단가가 나온다.
> 교훈: 키워드 검색 결과는 반드시 상위 금액 건을 눈으로 확인한 뒤 통계를 낸다.

### 이 데이터로 답할 수 있는 질문
1. **건당 실제 단가** — 중앙값·사분위·구간별 분포 (평균은 대형 이상치에 오염되므로 중앙값을 쓴다)
2. **수주 방식** — 1인수의 / 2인이상수의 / 입찰 비율.
   1인수의 비중이 높으면 *입찰 최적화 전략이 무효*이고 영업·관계 게임이라는 뜻.
3. **계절성** — 월별 발주 분포로 실제 가동 가능 기간 산출
4. **시장 집중도** — 낙찰업체명 집계 → 상위 N사 점유율, HHI로 "이미 포화인가" 판정
5. **발주 단위** — 개별 기관 발주인지, 상위기관이 권역별로 묶는지 (묶음이면 계약 규모가 10배)

### 판정 기준선
- **HHI > 2500** 매우 집중(소수 독점, 신규 진입 곤란) / **1500~2500** 중간 / **< 1500** 경쟁적
- 경쟁적 = 진입은 쉬우나 **초과수익 없음**. "규제 장벽이 있다"와 "돈이 된다"는 별개다.

## 미해결/모순 (Open Questions)
- [확인필요] 경남 외 시·도교육청은 폼 구조가 제각각. 인천(`ice.go.kr`)은 GET 파라미터가 노출되지 않아 실패.
  전국 비교를 하려면 시·도별 엔드포인트를 개별 확보해야 한다.
- [확인필요] 지자체(비교육) 계약공개·나라장터 낙찰정보 API로 같은 분석이 가능한지 미확인.
- [구식주의] 엔드포인트는 사이트 개편 시 깨진다. 실패하면 "계약체결 현황 / 수의계약 내역 공개"로 재탐색.
