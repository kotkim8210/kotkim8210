## 한 줄 요약
유튜브 다계정의 연좌제 결합은 "애드센스 연결 시점"에 발생하므로, 수익화 전에는 무료 계정 분리로 충분하고 수익화 후에는 결합이 불가피해 방어가 콘텐츠 컴플라이언스로 이동한다.

## 핵심 내용

### 결합 시점 원리 (핵심 통찰)
- 수익화 전에는 애드센스 연결선이 **존재하지 않는다** → 계정 분리 실익 **있음**(실패 채널이 혼자 죽음).
- 수익화 후에는 수취인으로 묶이므로 계정 분리 실익 **없음**.
- 최적 전략: **실험기엔 분리·미수익화 → 살아남은 채널만 애드센스 1개에 연결.** (2026-09-20-youtube-다계정-연좌제-전략.md)
- 한 구글 계정 아래 브랜드 채널 N개 = 가능한 구조 중 **가장 강하게 묶인 상태**(소유주 동일이 확정적).

### 애드센스 제약 (확인된 사실)
- **수취인 1명당 1계정** 원칙. 중복 판정 기준 = 동일 수취인 이름·주소·전화번호 등 식별정보.
- 반대로 **애드센스 1개 ↔ 유튜브 채널 다수 연결 가능, 공식 개수 제한 없음**. 채널별 YPP 개별 심사.
- 구글 공식 통합 경로 = **브랜드 계정으로 이전**.
- 연결 애드센스는 **32일에 1회만 변경 가능**.
- 한 채널 위반 → 애드센스 정지 → **연결된 다른 채널에 영향**. 이것이 수익화 이후 연좌제 경로.
- 애드센스 1개에 채널 수·수익 상한이 없으므로 **2번째 애드센스가 필요한 상황이 거의 없음**. 사업자/법인은 계정구조가 아니라 **세금** 문제.

### 도구 층위 구분 — "계정 분리" ≠ "안티브라우저"
| | 구글 계정 여러 개 | 안티브라우저 + 프록시 |
|---|---|---|
| 목적 | 위험 분산 | 다른 사람인 척 위장 |
| 정책상 | 허용(계정 수 제한 없음) | 우회(circumvention) 소지 |
| 비용 | 0원 | 구독료 + 프록시 |
| 실험기 실익 | 있음 | 추가분 거의 없음 |
- "계정 분리 YES · 안티브라우저 NO"가 **동시에 성립**한다. 크롬 프로필만으로 분리는 끝남.
- 유료 도구가 필요한 지점은 "분리"가 아니라 "위장"이고, 위장부터가 리스크 구간.

### 우회 정책 (연좌제의 실제 조문)
- 채널 종료 시 **기존 채널 전부 + 새로 만들거나 취득한 채널 전부**의 보유·사용·생성 금지.
- 2025년 7월 집행 강화, 대량 종료 발생. 정지 이력 없이 우회로 종료된 사례도 보고됨.
- 시사점: 다계정 **은폐 패턴 자체가 우회 신호**가 되어, 안티브라우저가 연좌제를 줄이기는커녕 부를 수 있음.

### 도구 분류 오류 (원 질문의 전제 결함)
- `멀티로그인(Multilogin) ⊂ 안티브라우저` — 제품 vs 카테고리라 병렬 비교 불가.
- 블루스택(에뮬레이터)·VMware(가상머신)는 **환경 격리**지 IP 분리가 아님(별도 프록시 필요).
- 안티브라우저가 가리는 것: IP·지문·쿠키. **못 가리는 것: 애드센스 수취인 정보·지급 계좌·콘텐츠 유사도·복구 이메일/전화.**

### 정직한 한계
- 계정 분리는 **정책상 면제가 아니라 탐지 확률 감소**일 뿐.
- 동일 기기·IP·복구 전화/이메일로 구글은 여전히 연결 가능.
- 전화번호 1개당 구글 계정 약 5개 한도, 단기 다수 생성 시 인증 벽 → **현실 규모 3~5개**.
- 진짜 격리 = **별도 법적 수취인**뿐. 기술로는 살 수 없다.
