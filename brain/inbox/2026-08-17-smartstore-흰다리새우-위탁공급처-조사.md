## 2. 마진 역산 — 공급가 상한선 (⭐ 가장 중요)

31,900원에 팔 때 실제로 남는 돈:

```
수취액       = 31,900 (상품) + 3,500 (배송비)        = 35,400원
네이버 수수료 = 35,400 × 약 6% (주문관리 + 매출연동)   = -2,124원
────────────────────────────────────────────────────
정산 실수령                                        ≈ 33,276원
```

여기서 **위탁 공급가(택배비 포함)** 를 빼면 순마진:

| 위탁 공급가(택배 포함) | 순마진 | 마진율 | 판정 |
|---|---|---|---|
| 24,000원 | 9,276원 | 29% | 매우 좋음 |
| 26,000원 | 7,276원 | 23% | 좋음 |
| **28,000원** | **5,276원** | **17%** | **손익 마지노선** |
| 30,000원 | 3,276원 | 10% | 광고비 태우면 적자 |
| 32,000원 | 1,276원 | 4% | 게임 불가 |

> **결론: 위탁 공급가가 택배비 포함 28,000원을 넘으면 이 키워드에서 이길 수 없다.**

### 이 숫자가 의미하는 것
- 흰다리새우 산지 시세는 kg당 대략 15,000~22,000원 선(크기·시기 변동 큼).
  노량진 선(생)흰다리새우 시세가 15,000원대로 조회됨.
- 여기에 급냉·진공포장·아이스박스·아이스팩 2,000~3,000원 + 냉동택배 4,500~5,500원.
- 즉 **산지 직계약이면 24,000~28,000원 위탁 공급가가 현실적으로 나온다.**
- 반대로 **오너클랜·도매매 같은 종합 위탁 플랫폼은 중간 벤더가 1~2단 더 끼기 때문에
  공급가가 29,000~33,000원으로 올라가 구조적으로 마진이 안 나온다.**

→ **종합 위탁 플랫폼은 이 상품에서 답이 아니다. 산지 직계약 or 수산물 특화 소싱이 답.**

## 4. 위탁배송으로는 못 넘는 벽 (냉정한 현실 체크)

벤치마킹 대상을 그대로 복제해도 **상위 노출이 안 되는 구조적 이유 3가지**:

1. **N배송(네이버배송) 배지**
   - 도착일 보장 + 지연 시 네이버가 1,000P 직접 보상 → 검색 랭킹·전환율에 큰 가산점.
   - 이걸 받으려면 풀필먼트 센터 입고(N배송 FBN) 또는 도착보장 물류사 연동이 필요.
   - **위탁배송은 공급사가 자기 창고에서 발송하므로 원칙적으로 N배송을 못 단다.**
   - 2026-07 출시된 `N배송 FBN`이 신선식품까지 확대되었으나, **재고를 물류센터에 입고해야 함 = 무재고 위탁과 양립 불가.**

2. **리뷰 6,796건**
   - 네이버 검색 랭킹에서 리뷰 수·최신성은 상위 가중치. 신규 스토어가 단기간에 못 따라감.

3. **브랜드스토어 + 자사몰**
   - 땡큐파머스는 브랜드 등록 사업자. 일반 스마트스토어와 노출 로직·신뢰 지표가 다름.

### → 그래서 실제로 이겨야 할 방식

| 전략 | 내용 |
|---|---|
| **키워드 우회** | "국산 흰다리새우 1kg" 대세 키워드는 정면 승부 불가. `신안 흰다리새우 500g`, `새우장용 생새우`, `아이 이유식 새우`, `감바스용 새우 손질`, `캠핑 새우구이 세트` 등 **세부 키워드 + 중량·용도 분화**로 진입 |
| **옵션 차별화** | 벤치마킹 대상은 1kg 35미 단일. → 500g 소포장 / 2kg 대용량 / 头 제거 손질새우 / 새우장 소스 동봉 세트로 **동일 산지, 다른 상품**을 만든다 |
| **초기 리뷰 확보** | 첫 1~2개월은 마진 포기하고 리뷰 300건 만드는 게 목표. 리뷰 쌓기 전 광고비 태우면 그냥 손실 |
| **중장기: 사입 전환** | 위탁으로 수요 검증 → 팔린다는 확신이 서면 **소량 사입 + N배송 FBN 입고**로 전환해야 진짜 상위권 진입 |
