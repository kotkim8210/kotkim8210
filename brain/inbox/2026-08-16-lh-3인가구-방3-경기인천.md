## 1. 먼저 바로잡을 전제

### SH는 서울 전용이다
- **SH**(서울주택도시공사) = 서울시 물량만. 인천·경기에는 SH 공급이 없음.
- 경기 → **LH + GH**(경기주택도시공사, apply.gh.or.kr)
- 인천 → **LH + iH**(인천도시공사, ih.co.kr) + 인천시 **천원주택**

### "임대주택만 가능한가?" → 아니다. 단 현실적으로는 임대가 답
- 공공분양(나눔형·선택형·일반형)도 LH/GH/iH가 공급하지만 수억 목돈 + 청약통장 가점 필요.
- **통합공공임대는 최대 거주 30년** → 사실상 정착 가능. 굳이 분양 고집할 이유 적음.

## 2. 전세사기 위험도 랭킹 (핵심)

| 등급 | 유형 | 임대인 | 위험 |
|---|---|---|---|
| ✅ 안전 | **건설임대** (국민임대·통합공공임대·영구임대·행복주택 아파트) | LH/GH/iH 공기업 | 사실상 0 |
| ✅ 안전 | **매입임대** (공사가 매입 후 임대) | LH/GH/iH 공기업 | 사실상 0 |
| ⚠️ 주의 | **전세임대** (본인이 민간 집 구해오면 공사가 대신 전세계약) | **민간 집주인** | 공사가 등기부·선순위·보증금비율 권리분석 해주므로 개인 전세보다 훨씬 안전하나 0은 아님 |

→ **"전세사기 걱정 없이 방3"이면 건설임대 아파트가 정답.**

## 3. 방 3개 = 전용 몇 ㎡?

| 전용면적 | 통상 구성 |
|---|---|
| 26㎡ | 방1 (원룸~1.5룸) |
| 37㎡ | 방1~2 |
| 46㎡ | 방2 |
| 51㎡ | 방2~3 (단지별 상이) |
| **59㎡** | **방3 + 거실** ← 타깃 |

- **국민임대는 전용 60㎡ 이하**가 상한 → 59㎡가 국민임대 최대 평형
- 통합공공임대는 59㎡ 초과(74㎡ 등)도 신규 단지에 존재

## 4. ⭐ 면적 칸막이 규제 폐지 (결정적)

- 과거: 세대원수별 면적기준으로 3인 가구는 전용 36~50㎡만 신청 가능(2024.3 기준 기준), 1인 35㎡ 이하 등
- **2024.07.29 저출산고령사회위원회 발표로 폐지** (경향신문 2024.07.29)
- **실증 확인**: 2026.08.13자 이천장호원 B2블록 통합공공임대 공고문 44p 전문을 검색한 결과 `세대원수별` / `면적기준` 조항이 **하나도 없음**
→ **3인 가구가 전용 59㎡ 신청 가능.** 예전 정보로 포기하면 안 됨.

## 8. 실행 계획

1. **LH청약플러스**(apply.lh.or.kr) + 모바일앱 → 관심공고 알림: 지역 경기·인천 / 유형 국민임대·통합공공임대
2. **GH 청약센터** apply.gh.or.kr (경기도 자체 물량)
3. **iH** ih.co.kr + 인천주거포털 → **천원주택**(인천시 자체, 하루 1,000원 수준)
4. **마이홈포털** myhome.go.kr → 3사 통합검색 + '주거복지 자가진단'으로 자격 사전 확인
5. **청약통장** 3명 모두 개설(국민임대 순위에 영향)
6. **어머니를 세대주**로 신청 — 세대 단위 심사이므로 신청자는 누구든 세대 전원 심사
7. 경쟁률 낮은 신규 택지 우선 공략: 이천·평택·양주·파주·화성, 인천 검단·영종

## 9. 전략 포인트
- 국민임대·통합공공임대는 **예비자(대기자) 명부** 운영 → 일단 등록해두고 순번 기다리는 게 정석
- **소득 낮을수록 유리**: 통합공공임대 우선공급(중위 100% 이하)이 물량의 60%
- 두 청년이 **취업 전인 지금이 소득기준상 가장 유리한 시기** — 3명 소득 전원 합산이므로 취업 후엔 기준 초과 가능
- 동일 공급유형(통합·국민·행복·영구) 내 중복신청은 가능하나, 예비자 선정 시 종전 지위 자동 상실
