# 🗑️ inbox — 무가공 데이터 투입 구역 (Data Dumping Zone)

여기에는 **무엇이든, 분류 없이, 그대로** 넣으세요.

- 폴더를 나누지 마세요. 파일 이름을 고민하지 마세요.
- 연구 자료, 웹 스크랩, 회의록, 메모, 아이디어 조각, PDF 발췌, 코드 스니펫… 전부 환영.
- 권장 파일명(선택): `YYYY-MM-DD-아무제목.md` — 하지만 정말 아무거나 괜찮습니다.

## 다음 단계
1. 자료를 이 폴더에 넣고 커밋/푸시한다.
2. 클로드 세션에서 `/ingest` 실행 → 자동으로 주제 문서·지식 지도 생성.
   (또는 `ANTHROPIC_API_KEY` 시크릿이 설정돼 있으면 push 시 자동 수집)
3. 밤이 되면 🌙 드림 시퀀스가 알아서 정제합니다.

> 원본은 처리 후에도 **삭제되지 않고 그대로 보존**됩니다. 처리 여부는 `../.state/processed.json`이 추적합니다.

*(이 README와 `.gitkeep`은 수집 대상에서 제외됩니다.)*
