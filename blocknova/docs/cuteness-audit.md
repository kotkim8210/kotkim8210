# Block Nova 귀여움 감사 보고서 (Cuteness Audit)

- 감사일: 2026-07-19 · 대상: PR #17 코드 전체 (브랜치 `claude/code-phase-1-start-tbo918`)
- 기준: 캐주얼 타깃("귀엽고 아기자기" 중시) 디자인 체크리스트 15항목
- 방법: 소스 코드 검사(파일:라인 근거) + 실측 스크린샷(380px 모바일 / 1280px 데스크톱)
- 파일 링크는 [PR #17 브랜치](https://github.com/kotkim8210/kotkim8210/tree/claude/code-phase-1-start-tbo918/blocknova) 기준.

## 종합 판정

**15항목 중 ✅ 10 · ⚠️ 5 · ❌ 0 — "귀여움 인프라"는 이미 상위권.**
다만 방향이 **파스텔 아기자기가 아니라 "코스믹 큐트"(다크 우주 + 보석)** 라는 점이 가장 큰 전략 판단 지점이다.
귀엽지 않다는 뜻이 아니라, 타깃이 "밝고 파스텔"을 기대한다면 스킨 옵션이 필요하다는 뜻.

## 개선 제안 Top 5 (효과 ÷ 작업량 순)

> **2026-07-19 추가 — 타깃이 미국이면 1번(파스텔 스킨)은 보류.**
> 미국 상위권 블록퍼즐은 다크+캔디 광택(Block Blast) 또는 코지 우드(Woodoku) 계열로, 파스텔 kawaii는 아시아向 감성에 가깝다. 근거와 대신 반영한 미국 적합화 5건은 [us-market-fit.md](us-market-fit.md) 참조.

| 순위 | 제안 | 채우는 항목 | 작업량 |
|---|---|---|---|
| 1 | **파스텔 스킨 1종 추가** — 토큰이 CSS 변수로 통일돼 있어 팔레트 교체 스킨("Cream Pop" 등)이 구조적으로 저렴. 설정에서 토글, 기본은 코스믹 유지 | #1 | 중 |
| 2 | **마스코트 표정 시스템** — 기존 펫 자산을 HUD 옆 상시 노출로 승격: idle 숨쉬기 / 콤보 환호 / 게임오버 시무룩→응원 3상태 | #11 | 중 |
| 3 | **게임오버 시트에 표정 아이콘** — 카피는 이미 강하므로 픽셀 표정 하나만 얹어도 체감 상승 (제안 2의 축소판, 먼저 적용 가능) | #11 | 소 |
| 4 | **스티커/배지 SVG 6종** — 퀘스트 완료·랭크 승급·실드에 리본/별/방패 자체 아트로 이모지 대체 | #12 | 소~중 |

## 결론

- 체크리스트의 **행동 요소(피드백·응원·접근성·이탈 방지)는 이미 구현 완료** — 이 부분은 추가 투자 불필요.
- 남은 갭은 전부 **"시각 정체성" 축**: 파스텔이냐 코스믹이냐(#1), 캐릭터 상시 감정(#11), 스티커 아트(#12).
- 권장 순서: 출시(PR #17 병합) 먼저 → 유저 반응 확인 → 위 Top 5를 v1.2로. 출시 전 필수 항목은 없음.
