# 게임 디자인 명세 — Block Nova (v1.1)

## 1. 한 줄 정의
9×9 블록 퍼즐(검증 메커니즘) + **노바 게이지·데일리 챌린지·심리학 기반 후킹/리텐션 레이어**.

## 2. 보드·조각
9×9, 회전 없음, 트레이 3개(소진 시 리필). 조각은 `data/pieces.json` 19종(가중치 스폰).
리필: 직전과 동일 3종 조합 금지 + 최소 1개는 배치 가능(재추첨 ≤20회, 동일 RNG 스트림).

## 3. 배치·클리어 (vitest 케이스)
가로·세로 동시 판정, 교차 셀 1회 제거.
① 8칸 행에 dot → 9셀 제거 ② 행+열 동시(교차1) → 17셀 ③ 트레이 3개 전부 배치 불가 → 게임오버.

## 4. 점수
배치 = 셀 수 ×1. 클리어 = 줄당 10 × 동시배수(1줄×1 / 2줄×2.5 / 3줄+×4, 반올림).
콤보: 연속 클리어 +1(무클리어 배치 시 0), 클리어 점수 ×(1+콤보×0.5).

## 5. 노바 게이지 (정체성 트위스트)
클리어 셀 수만큼 충전, 60셀 만충. 만충 후 다음 클리어 시 **폭발**: 교차점 중심 3×3 추가 제거
+ 그 턴 점수 ×3 + 게이지 0 + 전용 연출 + `happytime()`.

## 6. 데일리 챌린지
`dayNumber = floor((KST 오늘0시 − 2026-08-01T00:00+09)/86400000)`,
조각 시퀀스 = `mulberry32(20260801 + dayNumber)` 결정적. **50조각 서바이벌**,
별점 임계 800/1600/2600/3800/5200(가설 — 조정 시 문서화). 정식 기록 1회, 재도전은 리워드 훅.

## 7. 공유 포맷
`Block Nova Daily #{n}` / `⭐⭐⭐☆☆ {score}점` / `NOVA ×{k}` / URL → 클립보드+토스트.

## 8. 광고 훅 (adapter 경유)
인터스티셜: 게임오버 **2회당 1회**, 결과 화면 진입 후만. 리워드: 부활 1회/판(랜덤 12셀 제거),
데일리 재도전 1회/일. off 모드=즉시 성공 콜백.

## 9. localStorage (`bn:`)
`best{classic}` `daily{day,score,stars,novaCount,retried}` `streak{current,max,lastDay,shields}`
`stats{games,totalScore,novaTotal,linesTotal}` `meta{xp,level}` `quests{week,progress[3],done[3]}`
`flags{firstRunDone,mute,fx}` — 자정(KST) daily 리셋, 결손일은 실드 자동 소모 후 streak 유지.

## 10. 밸런스
평균 조각 3.78셀, 평균 판 3~6분, 세션당 3판+ 목표. 별점·가중치 조정은 근거 기록 의무.

## 11. 첫 60초 후킹 스크립트 (심사 가이드 "게임플레이 내 온보딩·스킵 가능·비주얼 우선" 충족)
**원리: 즉각 유능감(빠른 승리) + 부여된 진전(선충전) + 손실 없는 학습.**
- 메뉴 없이 **즉시 플레이 진입**(로딩 → 바로 보드). 첫 실행(`flags.firstRunDone=false`)에만:
  - 프리셋 보드: 7행은 (7,8) 제외 채움, 8행은 (8,8) 제외 채움(0-index).
  - 첫 트레이 고정: `[v2, sq2, l3]` — v2를 (7,8)에 세로 배치하면 **1수 더블 클리어**(17셀+콤보 연출).
  - **노바 게이지 50% 선충전**("보너스 충전 ⚡" 라벨) → 2~3수 내 노바 발동 체험 확률 극대화.
  - 코치마크 3개(드래그→배치→노바 바), 텍스트 최소·화살표/모션 위주, 우상단 Skip, 기기별 Tap/Click.
  - 3수 후 코치마크 종료, **같은 판이 그대로 본 게임으로 이어짐**(별도 튜토리얼 모드 없음).
- vitest: 프리셋+고정 트레이에서 v2@(7,8) 배치 시 제거 셀 수 = 17 성립.

## 12. 리텐션 시스템 — 게임심리학 매핑 (구현 수치 포함)
| 기능 | 심리 원리 | 구현 |
|---|---|---|
| 데일리 스트릭 🔥 + **실드** | 손실 회피(Loss aversion) + 이탈 완충 | 연속일 표시. 7일 달성마다 실드 1개 지급(최대 2), 결손일 자동 소모. 실드 소모 시 "지켜졌어요" 카피 |
| 레벨/XP/랭크 | 유능감(SDT) + 부여된 진전(Endowed progress) | 클리어 셀 1=1XP. L→L+1 = round(100×L^1.4). **L1은 30% 선충전 시작**. 랭크: L1 Spark/5 Comet/10 Star/20 Supernova/35 Quasar/50 Nova Master |
| 주간 퀘스트 3종 | 자이가르닉(미완 과제 유지) + 목표 설정 | ISO주 시드 `mulberry32(주번호)`로 템플릿 3개 결정: 줄 60개 / 노바 4회 / 데일리 3회(±스케일). 보상 = 실드 1 or 배지. 진행 바 **마지막 10% 글로우**(목표 구배) |
| 퍼펙트 클리어 | 변동 보상(희귀 이벤트) | 클리어 후 보드 완전 비움 → +1000 + 콘페티 + happytime |
| 근접실패 게임오버 | Near-miss 재도전 동기 | "Best까지 **-{diff}**" + **다음에 나올 조각 3개 공개**("이게 올 예정이었어요"). best의 15% 이내면 강조 카피 "한 판이면 넘어요" |
| PB 페이스 바 | 목표 구배(Goal gradient) | 점수/베스트 진행 얇은 바 + 100% 틱, 갱신 순간 금색 플래시 |
| 피크 강조 연출 | 피크엔드 규칙 | 결과 화면에 "하이라이트: NOVA ×3 · 최고 콤보 5" 요약 배지, happytime을 노바·신기록·퍼펙트에만 |
**건강 가드레일**: 가짜 타이머·인위적 압박 금지, IAP 없음, 광고 상한(§8) 고정, 실드는 스트릭 불안을 완화하기 위한 장치다(강화 아님).

## 13. vitest 추가 (Phase 3)
