# UI 명세 — Block Nova (v1.1 · 프리미엄 "Cosmic Glass")

컨셉: 값싼 네온이 아니라 **우주 유리 보석함** — 깊은 우주 그라디언트 위 글라스 패널, 젬(보석) 셀,
금빛 노바. 심사 가이드의 "고해상도·일관성·시각적 매력"을 정면 충족.

## 1. 토큰
```js
colors:{ bg:'#17171C', deep:'#232041', surface:'rgba(255,255,255,0.04)', line:'rgba(255,255,255,0.10)',
 ink:'#EDEAF7', mute:'#9A97AC', nova:'#F5C518', novaHi:'#FFE9A0',
 gem:['#22D3EE','#8B5CF6','#34D399','#F472B6','#F59E0B','#60A5FA'], danger:'#F87171' }
radius:{ cell:'7px', panel:'18px' }  font:{ sans:['Pretendard','system-ui','sans-serif'] }
```
- **배경**: `background: radial-gradient(120% 90% at 50% -10%, #232041 0%, #17171C 55%)` + 별밭 2레이어
  (CSS box-shadow 점 40+24개, 120s/200s drift — 파티클 아님, GPU 부담 0급).
- **글라스 패널**: `bg-white/[0.04] backdrop-blur-md border border-white/10 rounded-panel
  shadow-[inset_0_1px_0_rgba(255,255,255,0.06)]`.
- **젬 셀**: `background: linear-gradient(145deg, rgba(255,255,255,.28), transparent 42%), var(--gem)`
  + `border border-white/15` + 하이라이트 점(좌상 2px 흰 반점) + 외곽 글로우 `0 0 12px -3px var(--gem)`.
  빈 칸: `bg-white/[0.03] shadow-[inset_0_2px_6px_rgba(0,0,0,.45)]`(음각 소켓 느낌).
- **NOVA 로고/게이지**: 텍스트 골드 그라디언트(`from-nova to-novaHi bg-clip-text`), 만충 시
  게이지에 시머(shimmer) 키프레임(밝은 띠 1.6s 순환) + "NOVA READY" 골드 펄스.

## 2. 레이아웃 (모바일 세로 우선 + **데스크톱 규칙**)
- 모바일: 헤더48 → HUD(점수·PB바·노바) → 보드(폭−32px 정사각) → 트레이96 → 여백. 380px 무스크롤.
- **데스크톱(심사 요건)**: 가로 화면에서 중앙 세로 컬럼(max-w-md) + 좌우 **앰비언트 사이드**
  (deep 그라디언트+별밭+은은한 대형 젬 실루엣). 터치 전용 UI 숨김, 트레이 hover 시 조각 lift(2px↑+글로우),
  커서 grab/grabbing, 키보드 조작 힌트 1줄("← → 이동 · 1/2/3 선택 · Enter 배치 · P 일시정지").
- 문구 기기 분기: "Tap"↔"Click" i18n 키로 처리.

## 4. 사운드 (WebAudio 합성·일관 레벨)
배치=우드블록풍 짧은 톤(120ms), 클리어=상승 아르페지오, **콤보 피치업: 기본 440Hz × 2^(combo/12)**(12캡),
노바=저역 붐+글리터, 신기록=3음 팡파르. 마스터 게인 단일 노드(레벨 일관), M 토글·백그라운드 정지/복귀.

## 5. 주스 팩 (게임필 — 전 항목 transform/opacity만)
| 순간 | 연출 |

| 대기(배치 가능 조각) | **아이들 펄스** scale 1→1.03, 1.8s 루프 — 배치 가능한 조각만(어포던스 신호). 배치 불가 조각은 정지+회색. 저사양 모드에선 비활성 |

| 클리어 | 셀 팝(scale 1→1.25→0, 220ms, 행 stagger 18ms) + 파편 파티클 셀당 1(총 ≤24) + 햅틱 30ms |
| 멀티라인 | 화면 가장자리 글로우 플래시 120ms |
| 노바 | 백색 플래시 60ms → 골드 링 확산 480ms → 셰이크 ±3px 140ms + 햅틱 [20,30,60] (reduced-motion: 페이드만) |

## 6. 성능·접근성 (심사 방어)
4GB 크롬북 60fps: 파티클 상한·will-change 최소·reflow 금지, **프레임타임 1s 샘플링 → 45fps 미만 시
자동 '이펙트 라이트' 모드**(별밭·파티클 반감, 설정에서 수동 토글도 제공).
색+형태 이중 구분(조각별 미세 패턴 점), 터치 44px+, 탭-탭 보조 입력, 포커스 링, 폰트 최소 14px(크롬북 저해상도),
body `user-select:none`, 외부 폰트·이미지·오디오 0.

## 7. 커버/썸네일 스펙 (포털 상위작 공통 문법 — 실측 관찰 반영)
상위작 썸네일 3요소: ① **실제 게임 화면** ② **손가락 커서**(조작 암시) ③ **터지는 순간**(보상 암시).
- Block Nova 커버: 젬 보드 위 **노바 골드 폭발 순간** + 우하단 손 커서 + 낙하 중인 조각 1개.
- 텍스트 최소(포털이 제목을 별도 표기) — 로고 워드마크만 작게.
- 배경 저채도 딥 퍼플, 포인트는 골드 1색(썸네일 그리드에서 시인성).
- 규격: 16:9 + 정사각 2종. 제작·시안은 Phase 4 후 「제출 킷」 단계에서.
