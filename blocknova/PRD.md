# PRD — Block Nova v1.0

## 1. 한 줄 정의
검증된 9×9 블록 퍼즐(광고수익 1위 메커니즘)에 **노바 게이지 + 데일리 챌린지** 트위스트를 얹은
포털 배포용 웹게임. 비용 ≈ 0, 수익 = 포털 광고 배분.

## 2. 근거 (시장 데이터 요약)
- 퍼즐 장르 = 모바일 광고수익의 53%(2026.2~4). 블록퍼즐 Block Blast!는 5개월 광고수익 $1.27억,
  2년 연속 다운로드 세계 1위 — **메커니즘 자체가 검증 끝**.
- 포털(CrazyGames 월 5,000만+)이 트래픽·호스팅·광고를 제공 → 솔로·비개발자 제약과 정합.
- 순수 클론은 심사 탈락 → 노바·데일리가 심사용 정체성.

## 3. 타깃
포털 글로벌 캐주얼 유저(영어 UI 기본, Tier1 비중 큼) — 대기시간·자기 전 짧은 세션.
연령·성별 불문 규칙 인지 100%(지식 전제 없음 — 타로들의 실패 요인 제거).

## 4. 핵심 루프
접속(설치 0) → 클래식 플레이(3~6분) → 게임오버 → [부활(리워드)] → 결과+인터스티셜 →
데일리 도전(매일 1판·별점·공유) → 연속 기록 유지 위해 재방문.

## 5. 범위 (MoSCoW)
- **Must**: 9×9 배치·클리어·게임오버, 19조각 스폰 백, 점수·콤보, 노바 게이지·폭발,
  데일리 시드 모드, 부활·인터스티셜 훅(adapter), 공유, 통계, 영어 UI, 모바일+데스크톱+키보드 3입력,
  **첫 실행 골든 퍼스트 무브(후킹 스크립트), 근접실패 게임오버, PB 페이스 바, 스트릭+실드, 레벨/XP/랭크**,
  Cosmic Glass 비주얼·주스 팩, 심사 방어 규칙 전 항목(CLAUDE.md).
- **Should**: ko 로케일, 주간 퀘스트 3종, 퍼펙트 클리어, 사운드 3종+음소거, 별점 임계 튜닝 플래그.
- **Could**: 주간 리더보드(로컬), 테마 스킨, 자체 사이트판.
- **Won't(v1)**: 서버·계정·실시간 랭킹, IAP, 회전 조각, 타사 에셋.

## 6. KPI (가설 — 포털 대시보드 실측 · Basic→Full 승격 지표와 정렬)
게임플레이 전환율(승격 지표) 측정 / 첫 세션 스크립트 완주율 ≥ 70% / D1 ≥ 25% /
평균 세션 ≥ 6분 / 세션당 게임 ≥ 3판 / 근접실패 화면 재도전율 측정 / 리워드 옵트인 ≥ 15% / 데일리 참여 ≥ 20%.

## 7. 일정
Phase 1 코어(Claude Code 1~2일) → Phase 2 노바·데일리(1일) → Phase 3 포털 준비(0.5일)
→ CrazyGames 제출(발주자 30분) → Basic Launch 지표 확인 → 병행: 2호(마작 짝맞추기) 착수.
