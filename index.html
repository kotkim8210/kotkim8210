Validation-First Startup Toolkit

"좋아요"가 아니라 "지불"로 검증한다

아이디어 → 개발 전에 시장 검증 → 지불 신호가 터진 것만 실제 개발. 레딧 페인포인트 발굴부터 스모크 테스트, 단계별 통과/탈락 판정까지 한 흐름으로 묶은 1인 창업자용 도구 모음입니다. 설치·빌드 불필요 — 파일을 열거나 정적 호스팅에 그대로 올리면 됩니다.

핵심 원칙 한 줄. 관심(좋아요·조회수)은 공짜라 누구나 줍니다. 검증해야 하는 건 지불 신호(Commitment Signal) — 이메일 등록 < 결제버튼 클릭 < 사전결제. 그리고 합격선은 테스트 전에 숫자로 먼저 박아야 사후 합리화를 막습니다.
TOOL 01

페인포인트 점수화 시트

레딧·커뮤니티에서 모은 고객 불편을 빈도×강도×지불가능성×경쟁공백으로 점수화해 "이미 잘 풀린 문제"를 걸러내고 상위 2~3개로 압축합니다.
TOOL 02

검증용 랜딩 + 가짜 결제버튼

개발 0줄로 수요를 테스트하는 스모크 테스트 페이지. 1단계(관심)와 2단계(실제 예약금 결제) 신호를 분리 측정 — 퍼널 추적(조회→스크롤→클릭→등록→결제)이 내장된 실시간 미니 대시보드 포함.
TOOL 03

단계별 합격선 계산기

전환율·표본 충분성·단위경제(LTV:CAC)를 입력하면 단계마다 GO / KILL을 판정합니다. 합격선 잠금 기능 포함.

🚀 실전 적용 · 1호 선정 아이디어

IDEA 01 · GEO

보이나(BOINA) — AI 검색 가시성 진단 서비스

2026 트렌드 리서치로 선정한 1호 사업. 한국 DTC·이커머스 브랜드가 ChatGPT·Perplexity·구글 AI 개요·네이버 AI 브리핑에서 추천·인용되도록 진단·개선하는 생산화 서비스. 이 툴킷의 1·2단계 검증을 그대로 적용한 실제 검증 랜딩입니다.

검증 랜딩 열기 → 사업화 브리프 보기

전체 흐름 (Stage-Gate)

단계활동통과(GO) 기준탈락(KILL) 기준
0. 문제 선별페인 후보 10개 점수화 (Tool 01)상위 2~3개로 압축"이미 잘 풀린 문제" 제거
1. 수요 검증랜딩+가짜버튼, 개발 0줄 (Tool 02)CTA 클릭률 ≥ 합격선 + 등록 N건합격선 미달 → 즉시 폐기
2. 선판매 검증베타 유료 슬롯/사전결제실제 결제자 ≥ X명무료엔 몰려도 결제 0
3. 최소 제품결제 고객용 핵심기능만 AI로 빌드재방문/리텐션 유지출시 후 리텐션 붕괴
4. 운영·확장반복작업만 자동화, 판단은 사람LTV > CAC (≥3:1)단위경제 역전

모든 데이터는 브라우저 localStorage에 저장되며 서버로 전송되지 않습니다(외부 엔드포인트를 직접 설정하기 전까지). 자세한 사용법은 저장소의 README.md 참고.
